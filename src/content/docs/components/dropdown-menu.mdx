A DropdownMenu displays a list of actions or options triggered by a button. It supports items with icons and shortcuts, labels, separators, checkboxes, radio groups, destructive actions, and nested submenus.

<DropdownMenuDemo client:load />

## Anatomy

A DropdownMenu consists of 17 parts:

| Part | Required | Description |
|------|----------|-------------|
| DropdownMenuRoot | Yes | Controls open state and modal behavior |
| DropdownMenuTrigger | Yes | Button that toggles the menu |
| DropdownMenuPortal | No | Teleports content to `body` (default) |
| DropdownMenuContent | Yes | The pop-out menu panel |
| DropdownMenuArrow | No | Optional arrow pointing to the trigger |
| DropdownMenuItem | No | A menu item with select event |
| DropdownMenuGroup | No | Groups multiple items together |
| DropdownMenuLabel | No | Non-focusable section label |
| DropdownMenuCheckboxItem | No | Item that can be toggled |
| DropdownMenuRadioGroup | No | Groups radio items |
| DropdownMenuRadioItem | No | Item with single-select |
| DropdownMenuItemIndicator | No | Renders when parent item is checked |
| DropdownMenuSeparator | No | Visual divider between items |
| DropdownMenuShortcut | No | Keyboard shortcut hint |
| DropdownMenuSub | No | Nested submenu container |
| DropdownMenuSubTrigger | No | Item that opens a submenu (includes chevron icon) |
| DropdownMenuSubContent | No | The submenu pop-out panel |

## Composition

```
MizuDropdownMenuRoot
  MizuDropdownMenuTrigger
  MizuDropdownMenuPortal
    MizuDropdownMenuContent
      MizuDropdownMenuArrow (optional)
      MizuDropdownMenuLabel (optional)
      MizuDropdownMenuItem
        MizuDropdownMenuShortcut (optional)
      MizuDropdownMenuCheckboxItem
        MizuDropdownMenuItemIndicator
      MizuDropdownMenuSeparator (optional)
      MizuDropdownMenuRadioGroup
        MizuDropdownMenuRadioItem
          MizuDropdownMenuItemIndicator
      MizuDropdownMenuSub
        MizuDropdownMenuSubTrigger
        MizuDropdownMenuPortal
          MizuDropdownMenuSubContent
            MizuDropdownMenuItem
```

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|---------------|
| [Menu Button WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button) | Reka UI manages focus and keyboard navigation automatically |
| Roving tabindex | Arrow keys navigate between items |
| `role="menu"` | Applied to content by Reka UI |

### Keyboard Interactions

| Key | Description |
|-----|-------------|
| Enter / Space | Opens menu and focuses first item; activates focused item |
| ArrowDown | Opens menu on trigger; moves focus to next item |
| ArrowUp | Moves focus to previous item |
| ArrowRight / ArrowLeft | Opens/closes submenu |
| Esc | Closes menu and refocuses trigger |

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Check, User, CreditCard, Settings, Trash2 } from "@lucide/vue";
import {
  MizuDropdownMenuRoot,
  MizuDropdownMenuTrigger,
  MizuDropdownMenuPortal,
  MizuDropdownMenuContent,
  MizuDropdownMenuItem,
  MizuDropdownMenuGroup,
  MizuDropdownMenuLabel,
  MizuDropdownMenuCheckboxItem,
  MizuDropdownMenuItemIndicator,
  MizuDropdownMenuRadioGroup,
  MizuDropdownMenuRadioItem,
  MizuDropdownMenuSeparator,
  MizuDropdownMenuShortcut,
  MizuButton,
} from "@mizu/vue";

const bookmarks = ref(true);
const format = ref("json");
</script>

<template>
  <MizuDropdownMenuRoot>
    <MizuDropdownMenuTrigger as-child>
      <MizuButton variant="outline" size="md">Open</MizuButton>
    </MizuDropdownMenuTrigger>
    <MizuDropdownMenuPortal>
      <MizuDropdownMenuContent>
        <MizuDropdownMenuLabel>My Account</MizuDropdownMenuLabel>
        <MizuDropdownMenuSeparator />
        <MizuDropdownMenuItem @select="() => console.log('profile')">
          <User :size="16" />
          Profile
          <MizuDropdownMenuShortcut>⇧⌘P</MizuDropdownMenuShortcut>
        </MizuDropdownMenuItem>
        <MizuDropdownMenuItem @select="() => console.log('billing')">
          <CreditCard :size="16" />
          Billing
        </MizuDropdownMenuItem>
        <MizuDropdownMenuItem @select="() => console.log('settings')">
          <Settings :size="16" />
          Settings
        </MizuDropdownMenuItem>
        <MizuDropdownMenuSeparator />
        <MizuDropdownMenuCheckboxItem v-model="bookmarks">
          <MizuDropdownMenuItemIndicator>
            <Check :size="14" />
          </MizuDropdownMenuItemIndicator>
          Include Bookmarks
        </MizuDropdownMenuCheckboxItem>
        <MizuDropdownMenuSeparator />
        <MizuDropdownMenuRadioGroup v-model="format">
          <MizuDropdownMenuRadioItem value="json">
            <MizuDropdownMenuItemIndicator>
              <Check :size="14" />
            </MizuDropdownMenuItemIndicator>
            JSON
          </MizuDropdownMenuRadioItem>
          <MizuDropdownMenuRadioItem value="csv">
            <MizuDropdownMenuItemIndicator>
              <Check :size="14" />
            </MizuDropdownMenuItemIndicator>
            CSV
          </MizuDropdownMenuRadioItem>
        </MizuDropdownMenuRadioGroup>
        <MizuDropdownMenuSeparator />
        <MizuDropdownMenuItem @select="() => console.log('delete')" variant="destructive">
          <Trash2 :size="16" />
          Delete
          <MizuDropdownMenuShortcut>⌘⌫</MizuDropdownMenuShortcut>
        </MizuDropdownMenuItem>
      </MizuDropdownMenuContent>
    </MizuDropdownMenuPortal>
  </MizuDropdownMenuRoot>
</template>
```

## Implementation Notes

1. Each `MizuDropdownMenu*` component is a thin wrapper around the corresponding Reka UI `DropdownMenu*` primitive.
2. CSS follows the Mizu convention of `bp-dropdown-menu__*` BEM classes applied via computed property, appending user `class` from `useAttrs()`.
3. Components with positioning (Content, SubContent) accept `side`, `sideOffset`, `align`, `alignOffset`, `avoidCollisions`, `collisionPadding`, and `sticky` props.
4. `MizuDropdownMenuContent` includes open/close animations driven by `data-state` and `data-side` attributes.
5. `MizuDropdownMenuPortal` teleports content to `body` by default. Wrap Content in Portal to escape parent stacking contexts.
6. Submenus require their own `MizuDropdownMenuPortal` + `MizuDropdownMenuSubContent` inside `MizuDropdownMenuSub`.
7. `MizuDropdownMenuSubTrigger` includes a built-in chevron-right SVG icon.
8. Use `as-child` on Trigger to merge behavior into an existing element (e.g., `MizuButton`).
9. Checkbox and Radio items must be wrapped in `MizuDropdownMenuItemIndicator` to show the checked indicator.
10. `MizuDropdownMenuLabel` is not focusable via arrow keys — use it as a section header only.
11. Use `variant="destructive"` on `MizuDropdownMenuItem` for dangerous actions like delete.
12. `MizuDropdownMenuShortcut` displays keyboard shortcut hints aligned to the right of the item.
13. The `@select` event on `MizuDropdownMenuItem` fires on click or keyboard activation.
14. `MizuDropdownMenuCheckboxItem` accepts both `modelValue` and `checked` props, emitting both `update:modelValue` and `update:checked` events.
