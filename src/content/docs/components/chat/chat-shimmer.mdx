> **Nuxt UI Component:** This uses Nuxt UI's `UChatShimmer` component. Mizu provides a theme preset (`@mizu/vue/theme`) that applies consistent typography and spacing. See the [Theme](#theme) section for Mizu-specific defaults.

ChatShimmer applies an animated shimmer gradient over text, commonly used during AI streaming to indicate progress. Mizu uses Nuxt UI's `UChatShimmer` to provide visual feedback while content is being generated.

## API

Reference: [Nuxt UI ChatShimmer](https://ui.nuxt.com/docs/components/chat-shimmer)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | *Required* | The text to display with the shimmer effect |
| `duration` | `number` | `2` | Duration of the shimmer animation in seconds |
| `spread` | `number` | `2` | Spread multiplier for the shimmer highlight (actual spread = `text.length * spread` in pixels) |
| `as` | `string \| Component` | `"span"` | The element or component to render as |

### Slots

ChatShimmer has no slots.

### Example Usage

```vue
<UChatShimmer
  text="Generating a response based on your query..."
  :duration="3"
  :spread="2"
/>
```

## Implementation Notes

1. **Use `<UChatShimmer>` directly** — No Mizu wrapper needed.
2. **Duration** — Controls how long the shimmer animation takes to complete one cycle. Longer text benefits from shorter durations for a more pronounced effect.
3. **Spread** — The highlight spread is computed as `text.length * spread` pixels. Increase `spread` for a wider shimmer highlight band.
4. **Text is required** — The `text` prop is mandatory; without it, the component renders nothing.
5. **`as` prop** — Use the `as` prop to render the shimmer as a heading or paragraph element for semantic HTML.
