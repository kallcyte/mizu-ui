A dash list displays a collection of label-value pairs in a structured layout. Use it for metadata, specs, profile information, and analytics data.

## Examples

<DashListDemo client:only="vue" />

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `DashItem[]` | `[]` | Array of `{ label, value?, highlighted? }` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls typography and spacing |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | Layout direction |

### Example Usage

```vue
<template>
  <!-- Vertical (default) -->
  <MizuDashList
    :items="[
      { label: 'Name', value: 'Jane Doe' },
      { label: 'Role', value: 'Designer' },
      { label: 'Status', value: 'Active', highlighted: true },
    ]"
  />

  <!-- Horizontal -->
  <MizuDashList
    :items="productSpecs"
    orientation="horizontal"
    size="sm"
  />

  <!-- Sizes -->
  <MizuDashList :items="data" size="sm" />
  <MizuDashList :items="data" size="md" />
  <MizuDashList :items="data" size="lg" />
</template>
```

## Theme

### CSS Custom Properties

| Token | Default | Description |
|-------|---------|-------------|
| `--color-foreground-secondary` | `#4B5563` (light) / `#9CA3AF` (dark) | Label color |
| `--color-foreground-primary` | `#1B1B1D` (light) / `#F9FAFB` (dark) | Value color |
| `--color-brand-primary` | `#001C44` | Highlighted value |
| `--color-surface-muted` | `#F3F4F6` (light) / `#1E2030` (dark) | Row separator line |

### Variants

| Variant | Layout | Use Case |
|---------|--------|----------|
| Vertical | Rows stacked top-to-bottom | Detail views, profiles, metadata |
| Horizontal | Rows laid out inline left-to-right | Summary stats, spec sheets |

### Sizing

| Size | Label Font | Value Font | Row Padding Y (vertical) |
|------|------------|------------|--------------------------|
| **SM** | 11px | 12px | 6px |
| **MD** | 12px | 13px | 8px |
| **LG** | 13px | 15px | 10px |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Semantic structure | Native `<dl>` with `<dt>` / `<dd>` children |
| Screen reader | Correctly announced as term/definition pairs |

```html
<dl>
  <div>
    <dt>Email</dt>
    <dd>user@example.com</dd>
  </div>
</dl>
```

## Anatomy

A dash list consists of rows, each containing two parts:

| Part | Required | Description |
|------|----------|-------------|
| Label | Yes | The `<dt>` element (term) |
| Value | Yes | The `<dd>` element (definition) |

## Implementation Notes

1. **Native elements** -- Uses `<dl>`, `<dt>`, and `<dd>` for semantic definition lists.
2. **Highlighted items** -- The `highlighted` property sets the value color to `brand-primary` with semibold weight.
3. **Orientation** -- `vertical` stacks rows with separators; `horizontal` lays them inline.
4. **Class inheritance** -- Accepts `class` prop via `useAttrs()` for Tailwind overrides.
5. **Tree-shakeable** -- Exported as ESM + CJS via Vite library mode.
