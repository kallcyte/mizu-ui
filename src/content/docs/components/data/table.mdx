A table displays structured data in rows and columns with built-in support for sorting, selection, pagination, and virtualization. Use it for data grids, admin panels, and any tabular data. Mizu uses Nuxt UI's `UTable` backed by TanStack Table.

## API

Reference: [Nuxt UI Table](https://ui.nuxt.com/docs/components/table)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | Array of data objects to display as rows |
| `columns` | `TableColumn[]` | — | Column definitions. Minimum: `{ header: string, accessorKey: string }` |
| `caption` | `string` | — | Table caption rendered as `<caption>` |
| `loading` | `boolean` | `false` | Show loading state overlay |
| `loadingColor` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'error' \| 'neutral'` | — | Color of the loading indicator |
| `loadingAnimation` | `'carousel' \| 'carousel-inverse' \| 'swing' \| 'elastic'` | — | Animation style for the loading indicator |
| `sticky` | `boolean \| 'header' \| 'footer'` | — | Sticky header and/or footer |
| `virtualize` | `boolean \| VirtualizerOptions` | `false` | Enable row virtualization for large datasets |
| `empty` | `string` | — | Text displayed when the table has no data |
| `globalFilter` | `string` | — | Global filter value for client-side filtering |
| `sorting` | `SortingState` | — | Controlled sorting state |
| `columnFilters` | `ColumnFiltersState` | — | Controlled column filter state |
| `pagination` | `PaginationState` | — | Controlled pagination state |
| `rowSelection` | `RowSelectionState` | — | Controlled row selection state |
| `expanded` | `ExpandedState` | — | Controlled row expansion state |
| `onSelect` | `(e: Event, row: TableRow<T>) => void` | — | Callback when a row is clicked |
| `onHover` | `(e: Event, row: TableRow<T> \| null) => void` | — | Callback when a row is hovered |
| `onContextmenu` | `(e: Event, row: TableRow<T>) => void` | — | Callback when a row is right-clicked |

> **Note:** `UTable` supports all TanStack Table options through dedicated props (e.g., `sortingOptions`, `paginationOptions`, `rowSelectionOptions`). See the [TanStack Table docs](https://tanstack.com/table/latest) for advanced configuration.

### Slots

| Slot | Description |
|------|-------------|
| `expanded` | Custom content for expanded rows |
| `empty` | Custom empty state content |
| `loading` | Custom loading state overlay |
| `caption` | Custom caption content |
| `body-top` | Content inserted before table body rows |
| `body-bottom` | Content inserted after table body rows |

### Expose

| Name | Type | Description |
|------|------|-------------|
| `tableRef` | `Ref<HTMLTableElement \| null>` | Reference to the table DOM element |
| `tableApi` | `Table<T>` | TanStack Table API instance for programmatic control |

### Example Usage

```vue
<script setup lang="ts">
import { ref, h, resolveComponent } from "vue";
import type { TableColumn } from "@nuxt/ui";

const UBadge = resolveComponent("UBadge");
const UCheckbox = resolveComponent("UCheckbox");
const UButton = resolveComponent("UButton");

type Person = { id: number; name: string; title: string; email: string; role: string; status: string; };

const data = ref<Person[]>([...]);

const columns: TableColumn<Person>[] = [
  // Selection checkboxes
  {
    id: "select",
    header: ({ table }) => h(UCheckbox, {
      modelValue: table.getIsSomePageRowsSelected() ? "indeterminate" : table.getIsAllPageRowsSelected(),
      "onUpdate:modelValue": (v) => table.toggleAllPageRowsSelected(!!v),
    }),
    cell: ({ row }) => h(UCheckbox, {
      modelValue: row.getIsSelected(),
      "onUpdate:modelValue": (v) => row.toggleSelected(!!v),
    }),
  },
  { accessorKey: "name", header: "Name" },
  { accessorKey: "title", header: "Title" },
  // Sortable header with custom button
  {
    accessorKey: "email",
    header: ({ column }) => h(UButton, {
      color: "neutral", variant: "ghost", label: "Email",
      icon: column.getIsSorted() === "asc" ? "i-lucide-arrow-up" : "i-lucide-arrow-down",
      onClick: () => column.toggleSorting(column.getIsSorted() === "asc"),
    }),
  },
  // Custom cell with badge
  {
    accessorKey: "role",
    header: "Role",
    cell: ({ row }) => h(UBadge, { color: "primary", variant: "subtle" }, () => row.getValue("role")),
  },
];
</script>

<template>
  <!-- Basic -->
  <UTable :data="data" :columns="columns" />

  <!-- Loading -->
  <UTable :data="data" :columns="columns" loading />

  <!-- Empty -->
  <UTable :data="[]" :columns="columns" empty="No results." />

  <!-- With caption -->
  <UTable :data="data" :columns="columns" caption="Team members" />

  <!-- With sorting -->
  <UTable :data="data" :columns="columns" :sorting="[{ id: 'name', desc: false }]" />

  <!-- With selection -->
  <UTable v-model:row-selection="selected" :data="data" :columns="selectColumns" />

  <!-- Expandable rows -->
  <UTable v-model:expanded="expanded" :data="data" :columns="expandColumns">
    <template #expanded="{ row }">
      <div class="px-4 py-2 text-sm">Details for {{ row.original.name }}</div>
    </template>
  </UTable>

  <!-- Pagination -->
  <UTable v-model:pagination="pagination" :data="data" :columns="columns" />
</template>
```

## Anatomy

A table consists of several parts:

| Part | Required | Description |
|------|----------|-------------|
| Caption | No | Describes the table purpose (accessibility) |
| Header | No | Column headers rendered in `<thead>` |
| Body | Yes | Data rows rendered in `<tbody>` |
| Footer | No | Summary row rendered in `<tfoot>` |
| Empty | No | Placeholder shown when `data` is empty |
| Loading | No | Overlay shown when `loading` is `true` |

## Implementation Notes

1. **Use `<UTable>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **TanStack Table** — `UTable` is built on TanStack Table v8, providing headless table logic. All TanStack features (sorting, filtering, pagination, grouping, virtualization) are exposed via props.
3. **Columns** — At minimum, each column needs `header` (display name) and `accessorKey` (the property name in the data object). Columns support custom `cell` render functions for rich content.
4. **Two-way binding** — Use `v-model:sorting`, `v-model:pagination`, `v-model:rowSelection`, etc. for controlled state management.
5. **Performance** — Enable `virtualize` for datasets with thousands of rows. Use `watchOptions` to control reactivity depth.
6. **Native attributes** — Supports all native `<table>` HTML attributes (`cellpadding`, `cellspacing`, `summary`, `width`, etc.).
7. **Programmatic access** — Access the TanStack Table API via `useTemplateRef('table').tableApi` for imperative operations like `toggleAllRowsSelected()`.
