A data table displays structured data in rows and columns with built-in sorting, pagination, and row selection. Use it for lists, reports, and any tabular data.

### Multi-line Cells

Use slot-based columns to render rich, multi-line content within cells. Each cell is top-aligned by default.

```vue
<script setup>
import { h } from "vue";
import { MizuDataTable } from "@mizu/vue";
import type { ColumnDef } from "@tanstack/vue-table";

interface Contact {
  name: string;
  email: string;
  role: string;
  phone: string;
}

const columns: ColumnDef<Contact, unknown>[] = [
  {
    accessorKey: "name",
    header: "Contact",
    cell: ({ row }) => {
      const c = row.original;
      return h("div", [
        h("div", { style: "font-weight: 600; color: var(--color-foreground-primary)" }, c.name),
        h("div", { style: "font-size: 12px; color: var(--color-foreground-tertiary)" }, c.email),
      ]);
    },
  },
  {
    accessorKey: "role",
    header: "Role",
    cell: ({ row }) => {
      const c = row.original;
      return h("div", [
        h("div", { style: "font-weight: 600; color: var(--color-foreground-primary)" }, c.role),
        h("div", { style: "font-size: 12px; color: var(--color-foreground-tertiary)" }, c.phone),
      ]);
    },
  },
];
</script>
```

### Infinite Scroll

The DataTable does not have built-in infinite scroll, but you can implement it using `IntersectionObserver` and appending rows to the `data` prop.

```vue
<script setup>
import { ref, onMounted, onUnmounted, computed } from "vue";
import { MizuDataTable } from "@mizu/vue";

const PAGE_SIZE = 20;
const allData = ref([]);
const loading = ref(false);
const sentinel = ref(null);

const hasMore = computed(() => allData.value.length < totalRows.value);

async function loadMore() {
  if (loading.value || !hasMore.value) return;
  loading.value = true;
  const next = await fetchPage(allData.value.length, PAGE_SIZE);
  allData.value = [...allData.value, ...next];
  loading.value = false;
}

let observer;
onMounted(() => {
  observer = new IntersectionObserver(
    (entries) => {
      if (entries[0].isIntersecting && hasMore.value && !loading.value) {
        loadMore();
      }
    },
    { threshold: 0.1 }
  );
  if (sentinel.value) observer.observe(sentinel.value);
});
onUnmounted(() => observer?.disconnect());
</script>

<template>
  <div class="infinite-wrapper" style="max-height: 400px; overflow-y: auto">
    <MizuDataTable :columns="columns" :data="allData" :paginated="false" />
    <div ref="sentinel" style="padding: 16px; text-align: center">
      <template v-if="loading">Loading...</template>
      <template v-else-if="!hasMore">No more data</template>
    </div>
  </div>
</template>
```

## API

### Props

| Prop         | Type             | Default               | Description                                   |
| ------------ | ---------------- | --------------------- | --------------------------------------------- |
| `columns`    | `ColumnDef<T>[]` | required              | Column definitions (from @tanstack/vue-table) |
| `data`       | `T[]`            | required              | Array of row data                             |
| `sortable`   | `boolean`        | `true`                | Enable column sorting                         |
| `selectable` | `boolean`        | `false`               | Enable row selection with checkboxes          |
| `paginated`  | `boolean`        | `true`                | Show pagination footer                        |
| `loading`    | `boolean`        | `false`               | Show loading spinner                          |
| `emptyText`  | `string`         | `"No data available"` | Message when no data                          |
| `pageSize`   | `number`         | `10`                  | Rows per page                                 |
| `page`       | `number`         | `1`                   | Current page (v-model:page)                   |
| `totalRows`  | `number`         | `undefined`           | Total rows (for external pagination)          |

### Events

| Event           | Payload             | Description                        |
| --------------- | ------------------- | ---------------------------------- |
| `update:page`   | `number`            | Emitted when page changes          |
| `sortingChange` | `SortingState`      | Emitted when sort changes          |
| `rowSelect`     | `RowSelectionState` | Emitted when row selection changes |

### Example Usage

```vue
<script setup>
import { ref } from "vue";
import { MizuDataTable } from "@mizu/vue";
import type { ColumnDef } from "@tanstack/vue-table";

interface User {
  id: string;
  name: string;
  email: string;
}

const columns: ColumnDef<User, unknown>[] = [
  { accessorKey: "id", header: "ID" },
  { accessorKey: "name", header: "Name" },
  { accessorKey: "email", header: "Email" },
];

const data: User[] = [
  { id: "1", name: "John Doe", email: "john@example.com" },
  { id: "2", name: "Jane Smith", email: "jane@example.com" },
];

const page = ref(1);
</script>

<template>
  <MizuDataTable :columns="columns" :data="data" v-model:page="page" :page-size="10" />
</template>
```

### Accessibility

| Criterion        | Implementation                                                               |
| ---------------- | ---------------------------------------------------------------------------- |
| Table semantics  | Uses native `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` elements |
| Sortable columns | Click to toggle sort; visual indicator shows current sort direction          |
| Keyboard         | Tab to navigate between interactive elements; Enter/Space to activate        |
| Selection        | Checkbox in first column when `selectable` is true                           |

```html

      <td>$1,250.00</td>
    </tr>
  </tbody>
</table>
```

## Anatomy

A data table consists of six parts:

| Part   | Required | Description                                  |
| ------ | -------- | -------------------------------------------- |
| Table  | Yes      | The `<table>` element containing all rows    |
| Header | Yes      | Column headers with optional sort indicators |
| Body   | Yes      | Data rows with cell content                  |
| Row    | Yes      | A single data entry                          |
| Cell   | Yes      | Individual data value                        |
| Footer | No       | Pagination and selection info                |

## Composition

```
DataTable
  ├── Header (column headers with sort indicators)
  │     └── Sort Icon (asc/desc/none)
  ├── Body (data rows)
  │     └── Row (data entry)
  │           └── Cell (data value)
  └── Footer (optional)
        ├── Selection Info (when selectable)
        └── Pagination
```

## Implementation Notes

1. **@tanstack/vue-table** -- uses TanStack Table v8 for column definitions, sorting, pagination, and row selection logic.
2. **Generic component** -- uses Vue 3.4+ generic syntax `<script setup lang="ts" generic="T">` for type-safe column definitions.
3. **FlexRender** -- uses TanStack's `FlexRender` component to render cell and header content.
4. **Built-in pagination** -- integrates MizuPagination for page navigation; disable with `paginated="false"`.
5. **Row selection** -- when `selectable` is true, adds a checkbox column using MizuCheckbox.
6. **Loading state** -- shows a spinner overlay when `loading` is true.
7. **Empty state** -- displays `emptyText` when data array is empty.
8. **Multi-line cells** -- cells use `vertical-align: top` and wrap content naturally; use slot-based columns for rich layouts.
9. **Class inheritance** -- accepts `class` prop via `useAttrs()` for Tailwind overrides.
10. **Token-based colors** -- header, row, border, and selection colors use CSS custom properties for automatic light/dark theme support.
11. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode.
