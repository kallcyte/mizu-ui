Accordion displays expandable content panels. Use it to organize related information into collapsible sections, reducing visual clutter while keeping content accessible.

## API

### AccordionRoot Props

| Prop          | Type                         | Default      | Description                                  |
| ------------- | ---------------------------- | ------------ | -------------------------------------------- |
| `modelValue`  | `string \| string[]`         | `undefined`  | Controlled value for the open item(s)        |
| `type`        | `"single" \| "multiple"`     | `"single"`   | Selection mode                               |
| `collapsible` | `boolean`                    | `false`      | Allow collapsing the open item (single mode) |
| `disabled`    | `boolean`                    | `false`      | Disable the entire accordion                 |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Accordion orientation                        |

### AccordionRoot Events

| Event               | Payload                           | Description                         |
| ------------------- | --------------------------------- | ----------------------------------- |
| `update:modelValue` | `string \| string[] \| undefined` | Emitted when expanded state changes |

### AccordionItem Props

| Prop       | Type      | Default | Description                               |
| ---------- | --------- | ------- | ----------------------------------------- |
| `value`    | `string`  | —       | Unique identifier for the item (required) |
| `disabled` | `boolean` | `false` | Disable this item                         |

### AccordionHeader Props

| Prop | Type     | Default | Description           |
| ---- | -------- | ------- | --------------------- |
| `as` | `string` | `"h3"`  | Heading level element |

### AccordionTrigger Props

| Prop | Type     | Default     | Description                    |
| ---- | -------- | ----------- | ------------------------------ |
| `as` | `string` | `undefined` | Custom element for the trigger |

### AccordionContent Props

| Prop         | Type      | Default     | Description                     |
| ------------ | --------- | ----------- | ------------------------------- |
| `forceMount` | `boolean` | `undefined` | Keep content in DOM when closed |
| `as`         | `string`  | `undefined` | Custom element for content      |

### Type

MizuAccordion supports two selection modes controlled by the `type` prop:

| Type         | Behavior                                                                                      |
| ------------ | --------------------------------------------------------------------------------------------- |
| `"single"`   | At most one item can be open at a time. With `collapsible`, clicking the open item closes it. |
| `"multiple"` | Multiple items can be open simultaneously. Items toggle independently.                        |

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import {
  MizuAccordionRoot,
  MizuAccordionItem,
  MizuAccordionHeader,
  MizuAccordionTrigger,
  MizuAccordionContent,
} from "@mizu/vue";

const activeItems = ref(["faq-1"]);
</script>

<template>
  <!-- Single selection (default) -->
  <MizuAccordionRoot type="single" collapsible>
    <MizuAccordionItem value="faq-1">
      <MizuAccordionHeader>
        <MizuAccordionTrigger>Question one?</MizuAccordionTrigger>
      </MizuAccordionHeader>
      <MizuAccordionContent>Answer to question one.</MizuAccordionContent>
    </MizuAccordionItem>
    <MizuAccordionItem value="faq-2">
      <MizuAccordionHeader>
        <MizuAccordionTrigger>Question two?</MizuAccordionTrigger>
      </MizuAccordionHeader>
      <MizuAccordionContent>Answer to question two.</MizuAccordionContent>
    </MizuAccordionItem>
  </MizuAccordionRoot>

  <!-- Multiple selection -->
  <MizuAccordionRoot v-model="activeItems" type="multiple">
    <MizuAccordionItem value="faq-1">
      <MizuAccordionHeader>
        <MizuAccordionTrigger>Question one?</MizuAccordionTrigger>
      </MizuAccordionHeader>
      <MizuAccordionContent>Answer to question one.</MizuAccordionContent>
    </MizuAccordionItem>
    <MizuAccordionItem value="faq-2" disabled>
      <MizuAccordionHeader>
        <MizuAccordionTrigger>Disabled item</MizuAccordionTrigger>
      </MizuAccordionHeader>
      <MizuAccordionContent>This content is not accessible.</MizuAccordionContent>
    </MizuAccordionItem>
  </MizuAccordionRoot>
</template>
```

## Anatomy

A MizuAccordion consists of 5 parts:

| Part             | Required | Description                                |
| ---------------- | -------- | ------------------------------------------ |
| AccordionRoot    | Yes      | Container that manages expanded state      |
| AccordionItem    | Yes      | Wrapper for each collapsed panel           |
| AccordionHeader  | Yes      | Heading wrapper around the trigger         |
| AccordionTrigger | Yes      | Button that toggles the content visibility |
| AccordionContent | Yes      | The expandable content panel               |

## Composition

```
MizuAccordionRoot (type, collapsible)
  MizuAccordionItem (value)
    MizuAccordionHeader
      MizuAccordionTrigger
    MizuAccordionContent
  MizuAccordionItem (value, disabled)
    MizuAccordionHeader
      MizuAccordionTrigger
    MizuAccordionContent
```

## Accordion vs Collapsible

|                     | Accordion                                                              | Collapsible                                                        |
| ------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Structure**       | Multiple sections stacked                                              | Single expandable section                                          |
| **Sub-components**  | Root, Item, Header, Trigger, Content                                   | Root, Trigger, Content                                             |
| **Multiple open?**  | By default only one item open (`type="single"`)                        | Yes — each is independent                                          |
| **Item management** | Built-in item tracking (Root manages open items by `value`)            | Manual (controlled via `open` prop)                                |
| **Wrapping**        | Designed for multi-section UI out of the box                           | You would manually wrap multiple collapsibles for multi-section UI |
| **Use case**        | Group of related sections (e.g., settings page, product details, FAQs) | Single expand/collapse region (e.g., a filter panel, FAQ item)     |

Use **Accordion** when you have multiple related expandable sections that should coordinate with each other. Use **Collapsible** when you need a single toggle region.

## Implementation Notes

1. Each `MizuAccordion*` component is a thin wrapper around the corresponding Reka UI `Accordion*` primitive.
2. CSS follows the Mizu convention of `mizu-accordion__*` BEM classes applied via computed property.
3. The chevron icon rotates 180 degrees when the trigger is in the open state via `[data-state="open"]` selector.
4. Content uses CSS animation for slide-down (`accordionSlideDown`) and slide-up (`accordionSlideUp`) using Reka UI's `--reka-accordion-content-height` runtime CSS variable.
5. Items are visually separated by a `border-bottom` using `--color-surface-muted` in vertical orientation.
6. Disabled items have reduced opacity, `pointer-events: none`, and `color: var(--color-foreground-tertiary)`.
7. The `collapsible` prop only has effect when `type="single"` — clicking the open item closes it.
8. When `type="multiple"`, items toggle independently and `collapsible` has no effect.
9. Each `MizuAccordionHeader` defaults to rendering an `<h3>` element. Override with the `as` prop (e.g. `as="h2"`).
10. Focus-visible outline uses a 2px solid `--color-brand-ycp` ring inside the trigger.
