A metric displays a key performance indicator with an optional label, trend indicator, and trend value. Use it in dashboards, analytics panels, and data overviews.

<MetricDemo client:only="vue" />

## API

### Props

| Prop         | Type                                                                      | Default     | Description                        |
| ------------ | ------------------------------------------------------------------------- | ----------- | ---------------------------------- |
| `label`      | `string`                                                                  | `undefined` | Metric label displayed above value |
| `value`      | `string \| number`                                                        | `undefined` | The metric value                   |
| `trend`      | `'up' \| 'down' \| 'neutral'`                                             | `undefined` | Trend direction                    |
| `trendValue` | `string`                                                                  | `undefined` | Trend percentage or delta text     |
| `size`       | `'sm' \| 'md' \| 'lg'`                                                    | `'md'`      | Controls typography scale          |
| `variant`    | `'default' \| 'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'default'` | Value color variant                |

### Example Usage

```vue
<template>
  <!-- Basic -->
  <MizuMetric label="Revenue" value="$128,500" />

  <!-- With trend -->
  <MizuMetric label="Active Users" value="24,521" trend="up" trend-value="+12.5%" />

  <!-- Variants -->
  <MizuMetric label="Sales" value="$84K" variant="primary" />
  <MizuMetric label="Errors" value="23" variant="error" trend="down" />

  <!-- Sizes -->
  <MizuMetric label="Metric" value="123" size="sm" />
  <MizuMetric label="Metric" value="123" size="md" />
  <MizuMetric label="Metric" value="123" size="lg" />
</template>
```

### Trend Indicators

| Trend   | Icon Direction | Color                   |
| ------- | -------------- | ----------------------- |
| up      | Upward arrow   | `feedback-success-base` |
| down    | Downward arrow | `feedback-error-base`   |
| neutral | No icon        | `foreground-tertiary`   |

### Accessibility

| Criterion          | Implementation                                    |
| ------------------ | ------------------------------------------------- |
| Semantic structure | Uses `<div>` elements with descriptive text       |
| Trend icons        | `aria-hidden="true"` on SVG icons                 |
| Color independence | Trend direction can be determined from icon shape |

```html
<div>
  <span>Revenue</span>
  <span>$48,250</span>
  <div>
    <svg aria-hidden="true"><!-- up arrow --></svg>
    <span>+12.5%</span>
  </div>
</div>
```

## Anatomy

A metric consists of up to three parts:

| Part  | Required | Description                               |
| ----- | -------- | ----------------------------------------- |
| Label | No       | Descriptive text above the value          |
| Value | No       | The numeric or text statistic             |
| Trend | No       | Directional indicator with optional value |

## Implementation Notes

1. **Display component** -- Purely presentational; no state or interactivity.
2. **Trend arrows** -- SVG arrow paths for up/down; no icon for neutral.
3. **Variant colors** -- The `variant` prop changes the value color only; label and trend use their own colors.
4. **Semantic tags** -- Uses `<div>` and `<span>` elements; considers numeric formatting to be the consumer`s responsibility.
5. **Class inheritance** -- Accepts `class` prop via `useAttrs()` for Tailwind overrides.
6. **Tree-shakeable** -- Exported as ESM + CJS via Vite library mode.
