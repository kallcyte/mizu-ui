A NumberField allows users to enter a numeric value and increment or decrement it using stepper buttons or keyboard shortcuts. It supports formatting for decimals, currencies, and percentages.

<NumberFieldDemo client:load />

## Anatomy

A NumberField consists of 4 parts:

| Part | Required | Description |
|------|----------|-------------|
| NumberFieldRoot | Yes | Manages value, min/max, step, and format options |
| NumberFieldInput | Yes | Displays the formatted numeric value |
| NumberFieldIncrement | Yes | Button to increase the value |
| NumberFieldDecrement | Yes | Button to decrease the value |

## Composition

```
MizuNumberFieldRoot
  MizuNumberFieldDecrement
  MizuNumberFieldInput
  MizuNumberFieldIncrement
```

## Color Specifications

### Group Container

| Token | Value | Usage |
|-------|-------|-------|
| `--color-surface-base` | #FFFFFF (light) / #0F1117 (dark) | Group background |
| `--color-surface-border` | #E1E2E6 (light) / #2D2F3A (dark) | Group border |

### Stepper Buttons

| State | Token | Value | Usage |
|-------|-------|-------|-------|
| Default | — | transparent | Button background |
| Hover | `--color-surface-hover` | #F4F5F7 (light) / #1D1F28 (dark) | Button hover bg |
| Disabled | `--color-foreground-disabled` | #8B8FA3 (light) / #5C5F6E (dark) | Button text color |

## Vue Component API

### NumberFieldRoot Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `number` | `undefined` | Controlled value |
| `defaultValue` | `number` | `undefined` | Default value |
| `min` | `number` | `undefined` | Minimum value |
| `max` | `number` | `undefined` | Maximum value |
| `step` | `number` | `1` | Increment/decrement step |
| `largeStep` | `number` | `10` | Page Up/Down step |
| `disabled` | `boolean` | `false` | Disable the input |
| `formatOptions` | `Intl.NumberFormatOptions` | `undefined` | Formatting options (style, currency, etc.) |
| `locale` | `string` | `undefined` | Locale for formatting |

### NumberFieldRoot Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `number` | Emitted on value change |

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import {
  MizuNumberFieldRoot,
  MizuNumberFieldInput,
  MizuNumberFieldIncrement,
  MizuNumberFieldDecrement,
} from "@mizu/vue";

const value = ref(25);
</script>

<template>
  <MizuNumberFieldRoot v-model="value" :min="0" :max="100">
    <div class="number-field-group">
      <MizuNumberFieldDecrement>−</MizuNumberFieldDecrement>
      <MizuNumberFieldInput />
      <MizuNumberFieldIncrement>+</MizuNumberFieldIncrement>
    </div>
  </MizuNumberFieldRoot>
</template>

<style>
.number-field-group {
  display: inline-flex;
  align-items: center;
  border: 1px solid var(--color-surface-border);
  border-radius: 8px;
  overflow: hidden;
  background: var(--color-surface-base);
}
</style>
```

## Implementation Notes

1. Each `MizuNumberField*` component wraps the corresponding Reka UI `NumberField*` primitive.
2. The group container (Root > Decrement + Input + Increment) must be styled manually via CSS — the library provides the parts, not the layout.
3. `formatOptions` accepts any `Intl.NumberFormatOptions`, including `style: "currency"` and `style: "percent"`.
4. Keyboard shortcuts: Arrow Up/Down (step), Page Up/Down (largeStep × step), Home (min), End (max).
5. The input is read-only in the sense that users type through the formatted display; Reka UI parses keystrokes into number edits.
6. Use `@internationalized/number` for custom number parsing in advanced use cases.
