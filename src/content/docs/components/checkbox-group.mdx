The Checkbox Group component manages a collection of checkboxes with shared state, layout, and accessibility. It renders as a fieldset with a legend for proper form semantics.

<CheckboxGroupDemo client:load />

## Anatomy

A checkbox group consists of a fieldset containing multiple checkboxes:

| Part | Required | Description |
|------|----------|-------------|
| Fieldset | Yes | Container with optional legend |
| Checkboxes | Yes | Collection of MizuCheckbox components |

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string[]` (v-model) | `[]` | Selected values |
| `options` | `CheckboxGroupOption[]` | `[]` | Available options |
| `orientation` | `'horizontal' \| 'vertical'` | `'vertical'` | Layout direction |
| `legend` | `string` | — | Fieldset legend text |
| `disabled` | `boolean` | `false` | Disabled state for all checkboxes |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size for all checkboxes |

### CheckboxGroupOption

```typescript
interface CheckboxGroupOption {
  value: string;
  label: string;
  disabled?: boolean;
}
```

## Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string[]` | Emitted when selection changes |

## Examples

### Basic Usage

```vue
<script setup>
import { ref } from 'vue';

const selected = ref(['email']);
const options = [
  { value: 'email', label: 'Email notifications' },
  { value: 'sms', label: 'SMS notifications' },
  { value: 'push', label: 'Push notifications' },
];
</script>

<template>
  <MizuCheckboxGroup
    v-model="selected"
    :options="options"
    legend="Notification preferences"
  />
</template>
```

### Horizontal Layout

```vue
<MizuCheckboxGroup
  v-model="selected"
  :options="options"
  orientation="horizontal"
/>
```

### With Disabled Options

```vue
const options = [
  { value: 'email', label: 'Email' },
  { value: 'sms', label: 'SMS (coming soon)', disabled: true },
  { value: 'push', label: 'Push' },
];
```

## Implementation Notes

1. **Form semantics** — Uses `<fieldset>` and `<legend>` for proper form structure and accessibility.
2. **Shared state** — All checkboxes share the same `modelValue` array. Checking/unchecking updates the array.
3. **Layout** — Vertical layout stacks checkboxes with 8px gap. Horizontal layout uses flex-wrap with 16px gap.
4. **Disabled state** — When the group is disabled, all checkboxes are disabled. Individual options can also be disabled.
