A Toast is a non-modal notification that provides brief, time-sensitive feedback. It auto-dismisses after a duration and supports swipe-to-close gestures.

<ToastDemo client:load />

## Anatomy

A Toast consists of up to 7 parts:

| Part | Required | Description |
|------|----------|-------------|
| ToastProvider | Yes | Context provider — wrap at app root |
| ToastViewport | Yes | Fixed-position list container for all toasts |
| ToastRoot | Yes | Individual toast item with auto-dismiss timer |
| ToastTitle | No | Heading text for the toast |
| ToastDescription | No | Supporting detail text |
| ToastAction | No | Action button within the toast |
| ToastClose | No | Close button within the toast |

## Composition

### Provider API (recommended)

```
MizuToastProvider (app root, position)
  MizuToastViewport (rendered automatically)
    MizuToastRoot (per toast, managed internally)
      Icon (auto-selected by variant)
      MizuToastTitle (optional)
      MizuToastDescription (optional)
      MizuToastAction (optional)
  ... (app content)
```

### Component API (advanced)

```
MizuToastProvider (app root)
  MizuToastViewport
    MizuToastRoot (v-for or manual)
      MizuToastTitle
      MizuToastDescription (optional)
      MizuToastAction (optional)
      MizuToastClose (optional)
  MizuToastRoot (anywhere, teleported to viewport)
```

## Variants

All variants use a gradient background from the subtle variant color on the left to `--color-surface-base` on the right, plus a solid left border in the variant's base color.

| Variant | Gradient Start (left) | Left Border | Icon | Use Case |
|---------|----------------------|-------------|------|----------|
| `info` | `--color-feedback-info-subtle` (#EFF6FF) | `--color-feedback-info-base` | `Info` (blue) | General notifications |
| `success` | `--color-feedback-success-subtle` (#F0FDF4) | `--color-feedback-success-base` | `CheckCircle` (green) | Successful operations |
| `warning` | `--color-feedback-warning-subtle` (#FFFBEB) | `--color-feedback-warning-base` | `AlertTriangle` (yellow) | Warnings and cautions |
| `error` | `--color-feedback-error-subtle` (#FEF2F2) | `--color-feedback-error-base` | `XCircle` (red) | Errors and failures |

## Positions

Toasts can be placed in 6 positions via the `position` prop on `MizuToastProvider`:

| Position | Description |
|----------|-------------|
| `top-right` | Top-right corner (default) |
| `top-left` | Top-left corner |
| `top-center` | Top center, horizontally centered |
| `bottom-right` | Bottom-right corner |
| `bottom-left` | Bottom-left corner |
| `bottom-center` | Bottom center, horizontally centered |

| Property | Duration | Easing |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|---------------|
| Role | Each toast is rendered as `role="status"` with `aria-live="polite"` (`assertive` for foreground type) |
| Focus management | Tab cycles through toasts in reverse order (most recent first). Focus proxies handle entry/exit. |
| Keyboard shortcut | `F8` moves focus to the toast viewport |
| Swipe | Pointer swipe to dismiss. Can be disabled via `disableSwipe` prop. |
| Auto-dismiss | Timer pauses on hover, focus, and window blur. Resumes on leave, blur, and window focus. |

### ARIA Attributes

```html
<ol role="region" aria-label="Notifications (F8)" tabindex="-1">
  <li role="status" aria-live="polite" tabindex="0" data-state="open">
    Invoice saved
  </li>
</ol>
```

### `useToast` Composable

```ts
interface ToastContext {
  addToast(options: Omit<ToastItem, 'id' | 'open'>): string
  dismissToast(id: string): void
}
```

| Option | Type | Description |
|--------|------|-------------|
| `title` | `string` (optional) | Toast heading |
| `description` | `string` (optional) | Supporting text |
| `variant` | `'info' \| 'success' \| 'warning' \| 'error'` | Visual variant |
| `duration` | `number` (optional) | Override provider duration |
| `showTimer` | `boolean` (optional) | Show countdown timer on the toast |
| `action` | `{ label, altText, onClick }` (optional) | Action button config |

### Example Usage

```vue
<script setup lang="ts">
import { MizuToastProvider, useToast, MizuButton } from "@mizu/vue";

const { addToast } = useToast();

function showNotification() {
  addToast({
    title: "Invoice saved",
    description: "Invoice #INV-2026-0042 has been saved.",
    variant: "success",
  });
}
</script>

<template>
  <MizuToastProvider position="top-right">
    <MizuButton @click="showNotification">Show Toast</MizuButton>
  </MizuToastProvider>
</template>
```

## Implementation Notes

1. **Provider at app root** — `MizuToastProvider` must wrap your app (or the section that uses toasts). The viewport renders as a fixed-position `<ol>` at the configured position.
2. **Position** — Use the `position` prop on `MizuToastProvider` to place toasts in any corner or center of the screen. Default is `top-right`.
3. **Variant styling** — All variants use a gradient background from the subtle variant color (left) to `--color-surface-base` (right), plus a `3px` solid left border in the variant's base color. Each variant also includes a colored Lucide icon.
4. **Icons** — Toasts automatically include a variant-specific Lucide icon. No manual icon configuration needed.
5. **Dual API** — Use `useToast()` composable for simple programmatic toasts, or use the component API (`MizuToastRoot`, `MizuToastTitle`, etc.) directly for custom toast content.
6. **Optional title** — `title` is optional in `addToast()`. You can show title-only, description-only, or both.
7. **Auto-dismiss behavior** — The timer pauses on hover, focus, and window blur. It resumes on pointer leave, blur, and window focus.
8. **Swipe to dismiss** — Enabled by default with a right-swipe gesture. Threshold is 50px.
9. **Focus management** — The viewport manages tab order so that Tab cycles from most recent to oldest toast. F8 hotkey moves focus to the viewport.
