A textarea is a multi-line text input for collecting longer-form content. Use it for messages, descriptions, biographies, and other free-text input.

## Demo

## Anatomy

A textarea consists of up to four parts:

| Part | Required | Description |
|------|----------|-------------|
| Label | No | Descriptive text above the textarea |
| Textarea | Yes | The native `<textarea>` element |
| Helper text | No | Contextual help or error message below the textarea |
| Required indicator | No | Asterisk `*` on the label when required |

## Variants

| Variant | Border | Background | Use Case |
|---------|--------|------------|----------|
| default | `surface-muted` | `surface-base` | Standard input |
| error | `feedback-error-base` | `surface-base` | Validation failure |
| disabled | `surface-muted` | `surface-muted` | Non-interactive |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Role | Native `<textarea>` element |
| Label | `<label>` with `for`/`id` association |
| Required | `aria-required` + visible `*` indicator |
| Error | `aria-invalid` + `aria-describedby` linking to helper text |
| Disabled | `aria-disabled` attribute |

### ARIA Attributes

```html
<div>
  <label for="bio">Biography</label>
  <textarea id="bio" name="bio" aria-required="true" aria-invalid="false"></textarea>
</div>
```

## Vue Component API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string` | `''` | v-model value |
| `placeholder` | `string` | `''` | Placeholder hint text |
| `disabled` | `boolean` | `false` | Disables the textarea |
| `error` | `boolean` | `false` | Shows error state |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls typography and spacing |
| `name` | `string` | `undefined` | Form field name |
| `required` | `boolean` | `false` | Required form validation |
| `label` | `string` | `undefined` | Visible label text |
| `helperText` | `string` | `undefined` | Helper or error message text |
| `rows` | `number` | `3` | Number of visible text rows |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string` | Emitted on input with current value |
| `focus` | `FocusEvent` | Emitted on focus |
| `blur` | `FocusEvent` | Emitted on blur |

### Example Usage

```vue
<template>
  <!-- Basic -->
  <MizuTextarea v-model="message" />

  <!-- With label and placeholder -->
  <MizuTextarea
    v-model="description"
    label="Description"
    placeholder="Enter a description..."
  />

  <!-- Sizes -->
  <MizuTextarea v-model="text" size="sm" />
  <MizuTextarea v-model="text" size="md" />
  <MizuTextarea v-model="text" size="lg" />

  <!-- Error state -->
  <MizuTextarea
    v-model="feedback"
    label="Feedback"
    error
    helper-text="This field is required"
  />

  <!-- Custom rows -->
  <MizuTextarea v-model="bio" :rows="5" label="Biography" />
</template>
```

## Implementation Notes

1. **Native element** -- Uses the native `<textarea>` HTML element; no Reka UI primitive needed.
2. **Resizable** -- `resize-y` is enabled for vertical resizing.
3. **Size matching** -- Sizes match MizuInput for consistent forms.
4. **Class inheritance** -- Accepts `class` prop via `useAttrs()` for Tailwind overrides.
5. **Tree-shakeable** -- Exported as ESM + CJS via Vite library mode.
