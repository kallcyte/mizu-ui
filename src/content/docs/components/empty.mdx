The Empty component provides a consistent placeholder UI for empty states in lists, tables, and other data displays. It supports an icon, title, description, and action button.

<EmptyDemo client:load />

## Anatomy

An empty state consists of up to 4 parts:

| Part | Required | Description |
|------|----------|-------------|
| Icon | No | Visual indicator (slot) |
| Title | Yes | Heading text |
| Description | No | Supporting text |
| Action | No | CTA button (slot) |

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | Heading text |
| `description` | `string` | — | Body text |

## Slots

| Slot | Description |
|------|-------------|
| `icon` | Icon or illustration above the title |
| `action` | Action button below the description |

## Examples

### Basic Empty State

```vue
<MizuEmpty
  title="No results found"
  description="Try adjusting your search or filters to find what you're looking for."
/>
```

### With Icon

```vue
<MizuEmpty title="No messages">
  <template #icon>
    <InboxIcon />
  </template>
</MizuEmpty>
```

### With Action

```vue
<MizuEmpty
  title="No projects yet"
  description="Get started by creating your first project."
>
  <template #action>
    <MizuButton variant="primary">Create Project</MizuButton>
  </template>
</MizuEmpty>
```

## Implementation Notes

1. **Centered layout** — The component uses flexbox to center all content vertically and horizontally.
2. **Responsive** — The description text has a max-width to maintain readability on wide screens.
3. **Flexible** — Use slots for custom icons and actions, or props for simple text-only states.
