A breadcrumb displays the current page's position in a site's hierarchy. It helps users understand where they are and navigate back to parent pages.

## Demo

<BreadcrumbDemo client:load />

## Anatomy

A breadcrumb consists of three parts:

| Part | Required | Description |
|------|----------|-------------|
| Nav | Yes | `<nav>` wrapper with `aria-label="Breadcrumb"` |
| List | Yes | `<ol>` containing the breadcrumb items |
| Item | Yes | `<li>` wrapping a link or current-page text |

## Variants

| Variant | Separator | Use Case |
|---------|-----------|----------|
| Slash | `/` | Default, general-purpose navigation |
| Chevron | `>` | Deep hierarchies, file explorers |
| Dot | `·` | Minimal, compact layouts |

## Size Specifications

| Size | Font Size | Icon Size | Separator Margin |
|------|-----------|-----------|------------------|
| `sm` | `text-xs` (12px) | 12px | 4px |
| `md` | `text-sm` (14px) | 16px | 6px |
| `lg` | `text-base` (16px) | 20px | 8px |

## Typography

| Size | Font Size | Font Weight | Line Height |
|------|-----------|-------------|-------------|
| `sm` | 12px | 400 (regular) | 1.5 |
| `md` | 14px | 400 (regular) | 1.5 |
| `lg` | 16px | 400 (regular) | 1.5 |

The current page item uses font weight 500 (medium) to distinguish it from ancestor links.

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Landmark | `<nav>` with `aria-label="Breadcrumb"` identifies the navigation region |
| Current page | `aria-current="page"` on the last item's link |
| List semantics | `<ol>` provides ordered list semantics, conveying page hierarchy |
| Link targets | All ancestor items render as `<a>` elements; current page renders as `<span>` (not focusable) |

### ARIA Attributes

```html
<nav aria-label="Breadcrumb">
  <ol>
    <li>
      <a href="/">Home</a>
      <span aria-hidden="true">/</span>
    </li>
    <li>
      <a href="/products">Products</a>
      <span aria-hidden="true">/</span>
    </li>
    <li>
      <span aria-current="page">Laptop Stand</span>
    </li>
  </ol>
</nav>
```

## Vue Component API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `BreadcrumbItem[]` | required | Array of breadcrumb items |
| `separator` | `'/' \| '>' \| '·' \| Component` | `'/'` | Visual separator between items |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size variant |

### BreadcrumbItem

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `label` | `string` | Yes | Display text for the item |
| `href` | `string` | No | URL for the item; omit for current page |
| `icon` | `Component` | No | Optional icon component |

### Slots

None. Use the `items` prop to define content.

### Events

None.

### Example Usage

```vue
<script setup>
import { MizuBreadcrumb } from "@mizu/vue";
import { Home } from "@lucide/vue";

const items = [
  { label: "Home", href: "/", icon: Home },
  { label: "Products", href: "/products" },
  { label: "Laptop Stand" },
];
</script>

<template>
  <!-- Basic -->
  <MizuBreadcrumb :items="items" />

  <!-- Chevron separator, small size -->
  <MizuBreadcrumb :items="items" separator=">" size="sm" />

  <!-- With icons -->
  <MizuBreadcrumb :items="[
    { label: 'Home', href: '/', icon: Home },
    { label: 'Settings' },
  ]" />
</template>
```

## Implementation Notes

1. **Native HTML** -- uses `<nav>`, `<ol>`, `<li>`, `<a>`, and `<span>` elements; no Reka UI primitive needed.
2. **Current page detection** -- the last item in the `items` array is treated as the current page (rendered as `<span>` with `aria-current="page"` instead of an `<a>` link).
3. **Separator rendering** -- string separators (`/`, `>`, `·`) are rendered as text; component separators are rendered via `<component :is="separator">`.
4. **Class inheritance** -- accepts `class` prop via `useAttrs()` for Tailwind overrides.
5. **Token-based colors** -- link, hover, current, and separator colors use CSS custom properties for automatic light/dark theme support.
6. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode.
