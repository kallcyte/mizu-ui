A quote is a styled `<blockquote>` element for displaying cited passages, testimonials, or highlighted text. Use it to visually distinguish quoted content from the surrounding body copy.

## Demo

<QuoteDemo client:load />

## Anatomy

A quote consists of two parts:

| Part | Required | Description |
|------|----------|-------------|
| Content | Yes | The quoted text (default slot) |
| Citation | No | The source attribution footer |

## Variants

| Variant | Left Border | Background | Use Case |
|---------|-------------|------------|----------|
| Default | `surface-muted` | transparent | Neutral block quotes, editorial content |
| Accent | `brand-accent` | `brand-accent-subtle` | Highlighted testimonials, callouts |

### Default

A subtle left border with no background. Fits naturally into body copy without drawing attention.

### Accent

A brand-accent left border with a light accent-tinted background. Used for highlighted quotes, testimonials, or content that needs emphasis.

## Typography

| Element | Font Size | Weight | Line Height | Style |
|---------|-----------|--------|-------------|-------|
| Content | 14px (body) | normal | 1.5 | normal |
| Citation | 12px (caption) | normal | 1.4 | italic |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Semantic element | Native `<blockquote>` element |
| Citation | `<cite>` element inside `<footer>` for machine-readable source attribution |

### ARIA Attributes

```html
<blockquote class="mizu-quote">
  <div class="mizu-quote__content">
    Quoted text goes here.
  </div>
  <footer class="mizu-quote__cite">
    <cite>Source Name</cite>
  </footer>
</blockquote>
```

## Vue Component API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `cite` | `string` | `undefined` | Source attribution text shown in the footer |
| `accent` | `boolean` | `false` | Enables the accent variant (colored left border + tinted background) |

### Slots

| Slot | Description |
|------|-------------|
| default | The quoted content |

### Example Usage

```vue
<template>
  <!-- Basic -->
  <MizuQuote>
    Design is not just what it looks like and feels like.
  </MizuQuote>

  <!-- With citation -->
  <MizuQuote cite="Steve Jobs">
    Innovation distinguishes between a leader and a follower.
  </MizuQuote>

  <!-- Accent variant -->
  <MizuQuote accent cite="Albert Einstein">
    Imagination is more important than knowledge.
  </MizuQuote>

  <!-- Multi-paragraph -->
  <MizuQuote accent cite="APA Style">
    <p>First paragraph of the block quote.</p>
    <p>Second paragraph continues here.</p>
  </MizuQuote>
</template>
```

## Implementation Notes

1. **Native element** -- uses `<blockquote>` for semantic correctness; no Reka UI primitive needed.
2. **Citation** -- uses `<footer>` and `<cite>` elements for proper semantic markup and machine-readable source attribution.
3. **Accent variant** -- toggled via `accent` boolean prop; applies a `brand-accent` left border and `brand-accent-subtle` background.
4. **Class inheritance** -- accepts `class` prop via `useAttrs()` for Tailwind overrides.
5. **Token-based colors** -- uses Mizu color tokens for automatic light/dark theme support.
6. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode.
