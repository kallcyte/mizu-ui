A date picker input that opens a calendar for date selection. Mizu uses Nuxt UI's `UInputDate` with consistent form sizing and the Mizu color palette. Values use `@internationalized/date` objects.

|------|-------|-------------|
| `leading` | — | Content before the date input |

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CalendarDate, type DateValue } from "@internationalized/date";

interface DateRange {
  start: DateValue;
  end: DateValue;
}

const single = ref(new CalendarDate(2026, 7, 9));
const range = ref<DateRange>({
  start: new CalendarDate(2026, 7, 1),
  end: new CalendarDate(2026, 7, 15),
});
</script>

<template>
  <!-- Single date -->
  <UInputDate v-model="single" placeholder="Select a date" />

  <!-- Date range -->
  <UInputDate v-model="range" range placeholder="Select a date range" />
</template>
```

## Anatomy

An input date consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | Wrapper element |
| Input | Yes | Clickable text input that displays the selected date |
| Trigger Icon | Yes | Calendar icon (trailing) that opens the popover |
| Popover | Yes | Floating calendar panel |
| Calendar | Yes | Month grid with day cells |
| Prev/Next Buttons | Yes | Navigate between months |
| Day Cell | Yes | Individual date button, with states for selected, range, today, unavailable |
| Time Inputs | No | Hour/minute/second fields (when granularity below `'day'`) |
| Separator | No | Dash between start and end inputs (range mode) |
| Leading | No | Content before the date input |
| Trailing | No | Content after the date input |

## Implementation Notes

1. **Use `<UInputDate>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Date values use `@internationalized/date`** — Model values must be `CalendarDate`, `CalendarDateTime`, `ZonedDateTime`, or `DateRange` from `@internationalized/date`. This is Nuxt UI's standard date handling.
3. **Range selection** — Set `range` to `true`. The model value becomes a `DateRange` object with `start` and `end` properties.
4. **Time selection** — Set `granularity` to `'hour'`, `'minute'`, or `'second'` to enable time fields. Use `hourCycle` to choose between 12-hour and 24-hour display.
5. **Date constraints** — Use `minValue` and `maxValue` to set the selectable range. Use `isDateUnavailable` for custom per-date logic (e.g. blocking weekends or holidays).
6. **Locale** — Set `locale` to format dates in the user's region (e.g. `'en-US'` for MM/DD/YYYY, `'en-GB'` for DD/MM/YYYY).
7. **Custom time steps** — Use `step` to control time increment behavior. For example, `{ minute: 15 }` restricts minute selection to 0, 15, 30, 45.
8. **Form integration** — Wrap with `UFormField` for labels, helper text, and error messages. The component integrates with native form validation via the `required` and `name` props.
