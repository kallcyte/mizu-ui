A rating input lets users provide feedback by selecting from a configurable number of icons — typically stars. Mizu uses Nuxt UI's `UInputRating` with support for fractional steps, hover preview, and clearing.

## API

Reference: [Nuxt UI InputRating](https://ui.nuxt.com/docs/components/input-rating)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `number` | — | v-model binding for the rating value |
| `defaultValue` | `number` | `0` | Initial value (uncontrolled) |
| `length` | `number` | `5` | Number of rating items to render |
| `step` | `1 \| 0.5 \| 0.25 \| 0.1` | `1` | Granularity of each rating item |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Icon size scale |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'primary'` | Semantic color for filled icons |
| `icon` | `string` (Iconify) | `'i-ph-star'` | Icon used for filled rating items |
| `emptyIcon` | `string` (Iconify) | — | Icon used for empty rating items (defaults to `icon`) |
| `readonly` | `boolean` | `false` | Display-only mode, no interaction |
| `disabled` | `boolean` | `false` | Disables interaction |
| `clearable` | `boolean` | `false` | Allow clearing the rating by clicking the current value again |
| `hoverable` | `boolean` | `false` | Preview the rating value under the pointer on hover |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction of the rating items |
| `required` | `boolean` | `false` | Marks the field as required |
| `name` | `string` | — | Field name for form submission |
| `id` | `string` | — | HTML `id` attribute |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `item` | `{ index, filled }` | Rendered for each rating item. `filled` is `false` for the empty background and `true` for the filled overlay |

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";

const rating = ref(3);
const halfRating = ref(2.5);
const hoverRating = ref(0);
const clearableRating = ref(3);
const lengthRating = ref(7);
const iconRating = ref(4);
const emptyIconRating = ref(3);
const colorRating = ref(4);
const sizeRating = ref(4);
const verticalRating = ref(4);
</script>

<template>
  <!-- Basic 5-star rating -->
  <UInputRating v-model="rating" />

  <!-- Half-step rating -->
  <UInputRating v-model="halfRating" :step="0.5" />

  <!-- 10-star rating -->
  <UInputRating v-model="lengthRating" :length="10" />

  <!-- Hoverable -->
  <UInputRating v-model="hoverRating" hoverable />

  <!-- Clearable -->
  <UInputRating v-model="clearableRating" clearable />

  <!-- Custom icon -->
  <UInputRating v-model="iconRating" icon="i-lucide-heart" />

  <!-- Empty icon -->
  <UInputRating v-model="emptyIconRating" icon="i-ph-star-fill" empty-icon="i-ph-star" />

  <!-- Colors -->
  <UInputRating v-model="colorRating" color="primary" />
  <UInputRating v-model="colorRating" color="secondary" />
  <UInputRating v-model="colorRating" color="success" />
  <UInputRating v-model="colorRating" color="info" />
  <UInputRating v-model="colorRating" color="warning" />
  <UInputRating v-model="colorRating" color="error" />
  <UInputRating v-model="colorRating" color="neutral" />

  <!-- Sizes -->
  <UInputRating v-model="sizeRating" size="sm" />
  <UInputRating v-model="sizeRating" size="md" />
  <UInputRating v-model="sizeRating" size="lg" />

  <!-- Vertical -->
  <UInputRating v-model="verticalRating" orientation="vertical" />

  <!-- Readonly -->
  <UInputRating :default-value="4.5" readonly />

  <!-- Disabled -->
  <UInputRating disabled :default-value="3" />
</template>
```

## Anatomy

An input rating consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | Wrapper element containing all rating items |
| Item | Yes | Individual rating slot rendered `length` times |
| Indicator | Yes | Overlay element within each item, sized proportionally to the filled amount |
| Filled Icon | Yes | The `icon` displayed for the filled portion |
| Empty Icon | Yes | The `emptyIcon` (or `icon`) displayed as the background |

## Implementation Notes

1. **Use `<UInputRating>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Fractional steps** — Set `step` to `0.5`, `0.25`, or `0.1` to allow partial ratings. The indicator width is clipped proportionally to show partial fill.
3. **Hover preview** — Set `hoverable` to preview the candidate value as the pointer moves over the items. The value only commits on click.
4. **Clearable** — Set `clearable` to let users reset the rating to `0` by clicking the currently selected item again.
5. **Custom icons** — Use `icon` and `emptyIcon` with any Iconify icon. Perfect for non-star ratings like hearts, thumbs-up, or custom shapes.
6. **Orientation** — Set `orientation="vertical"` for a vertical stacking layout. Arrow key navigation respects the orientation.
7. **Form integration** — Wrap with `UFormField` for labels and error messages. The component participates in native form submission via `name` and `required`.
