A select displays a dropdown list of options and allows users to choose one. Use it when there are many options or space is limited.

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string` | `''` | v-model selected value |
| `placeholder` | `string` | `''` | Placeholder option text |
| `options` | `SelectOption[]` | `[]` | Array of `{ value, label, disabled? }` |
| `disabled` | `boolean` | `false` | Disables the select |
| `error` | `boolean` | `false` | Shows error state |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls height and padding |
| `name` | `string` | `undefined` | Form field name |
| `required` | `boolean` | `false` | Required form validation |
| `label` | `string` | `undefined` | Visible label text |
| `helperText` | `string` | `undefined` | Helper or error message text |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string` | Emitted on change with selected value |
| `focus` | `FocusEvent` | Emitted on focus |
| `blur` | `FocusEvent` | Emitted on blur |

## Anatomy

A select consists of up to five parts:

| Part | Required | Description |
|------|----------|-------------|
| Label | No | Descriptive text above the select |
| Container | Yes | The visible trigger element |
| Chevron | Yes | Dropdown indicator icon |
| Options | Yes | The `<option>` elements in the native dropdown |
| Helper text | No | Contextual help or error message below |

## Implementation Notes

1. **Native element** -- Uses the native `<select>` HTML element for reliable form behavior.
2. **Custom chevron** -- SVG chevron icon overlaid via absolute positioning on the container.
3. **Placeholder** -- Uses `<option value="" disabled hidden>` for placeholder text.
4. **Appearance reset** -- `appearance: none` removes the native arrow, replaced by the custom chevron.
5. **Size matching** -- Heights (28/36/40px) match MizuInput for consistent form layouts.
6. **Class inheritance** -- Accepts `class` prop via `useAttrs()` for Tailwind overrides.
7. **Tree-shakeable** -- Exported as ESM + CJS via Vite library mode.
