A textarea allows users to enter and edit multi-line text. Mizu uses Nuxt UI's `UTextarea` with the same height scale as inputs and buttons (28/36/40px) for visual alignment in forms.

## API

Reference: [Nuxt UI Textarea](https://ui.nuxt.com/docs/components/textarea)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Textarea size. Mizu overrides sm/md/lg to 28/36/40px |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'primary'` | Semantic color for focus ring |
| `variant` | `'outline' \| 'soft' \| 'subtle' \| 'ghost' \| 'none'` | `'outline'` | Visual style |
| `placeholder` | `string` | — | Placeholder text |
| `rows` | `number \| string` | — | Initial number of visible text lines |
| `autoresize` | `boolean` | `false` | Auto-resize height to fit content |
| `maxrows` | `number \| string` | — | Maximum rows when autoresize is enabled |
| `disabled` | `boolean` | `false` | Disables interaction |
| `readonly` | `boolean` | `false` | Read-only mode |
| `required` | `boolean` | `false` | Marks the field as required |
| `modelValue` | `string \| number` | — | v-model binding |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Default slot (not typically used) |
| `leading` | `{ ui }` | Custom leading content |
| `trailing` | `{ ui }` | Custom trailing content |

### Form Integration

Use `UFormField` to add labels, helper text, and error messages:

```vue
<UFormField label="Description" help="Describe your project in detail">
  <UTextarea class="w-full" placeholder="Write something..." />
</UFormField>
```

### Example Usage

```vue
<template>
  <!-- Basic v-model -->
  <UTextarea v-model="value" placeholder="Write something..." />

  <!-- Rows -->
  <UTextarea :rows="12" />

  <!-- Autoresize -->
  <UTextarea v-model="value" autoresize />

  <!-- Max rows -->
  <UTextarea v-model="value" :maxrows="4" autoresize />

  <!-- Color -->
  <UTextarea color="primary" placeholder="Primary" highlight />
  <UTextarea color="success" placeholder="Success" highlight />
  <UTextarea color="error" placeholder="Error" highlight />

  <!-- Variant -->
  <UTextarea variant="outline" placeholder="Outline" />
  <UTextarea variant="soft" placeholder="Soft" />
  <UTextarea variant="subtle" placeholder="Subtle" />
  <UTextarea variant="ghost" placeholder="Ghost" />
  <UTextarea variant="none" placeholder="None" />

  <!-- Size -->
  <UTextarea size="sm" placeholder="SM" />
  <UTextarea size="md" placeholder="MD" />
  <UTextarea size="lg" placeholder="LG" />

  <!-- Icon -->
  <UTextarea icon="i-ph-magnifying-glass" placeholder="Search..." />
  <UTextarea icon="i-ph-envelope" placeholder="Email" trailing />
  <UTextarea leading-icon="i-ph-pencil" trailing-icon="i-ph-check" placeholder="Notes" />

  <!-- Avatar -->
  <UTextarea :avatar="{ src: 'https://github.com/nuxt.png', size: '2xs' }" placeholder="Username" />

  <!-- Loading -->
  <UTextarea loading placeholder="Loading..." />
  <UTextarea loading loading-icon="i-ph-circle-notch" placeholder="Custom spinner..." />

  <!-- Disabled -->
  <UTextarea disabled placeholder="Disabled textarea" />

  <!-- With UFormField -->
  <UFormField label="Bio" help="Tell us about yourself">
    <UTextarea placeholder="Write a short bio..." rows="3" />
  </UFormField>
</template>
```

## Theme

Mizu overrides Nuxt UI's textarea sizing to match the same height scale as inputs and buttons.

```ts
// app.config.ts
import { mizuTheme } from "@mizu-ui/vue/theme";
export default defineAppConfig({ ui: mizuTheme });
```

### Design Specs

| Size | Height | H-Padding | V-Padding | Radius | Gap |
|------|--------|-----------|-----------|--------|-----|
| **SM** | 28px | 8px (`px-2`) | 4px (`py-1`) | 4px (`rounded`) | 4px |
| **MD** | 36px | 10px (`px-2.5`) | 6px (`py-1.5`) | 6px | 6px |
| **LG** | 40px | 10px (`px-2.5`) | 8px (`py-2`) | 6px | 8px |

### Typography

| Property | Value |
|----------|-------|
| Font Family | DM Sans (`--font-family-sans`) |
| Font Size (SM) | 14px (`text-sm/4`) |
| Font Size (MD/LG) | 16px (`text-base/5`) |

### Color Map

| Mizu Token | Nuxt UI Color |
|------------|---------------|
| `--color-hub-primary` | `primary` (focus ring) |
| `--color-hub-ycp` | `secondary` |
| `--color-feedback-error-base` | `error` (validation) |

### Focus Ring

Nuxt UI provides a built-in focus ring. Mizu uses the `primary` color for the focus state, resolving to the Mizu hub blue token.

## Anatomy

A textarea consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<div>` wrapper |
| Base | Yes | `<textarea>` element |
| Leading | No | Icon or content before the textarea |
| Trailing | No | Icon or content after the textarea |

## Implementation Notes

1. **Use `<UTextarea>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Same height as inputs and buttons** — SM (28px), MD (36px), LG (40px) aligns with `UInput` and `UButton` for form row consistency.
3. **Autoresize** — Set `autoresize` to `true` for the textarea to grow with content. Use `maxrows` to cap the maximum height.
4. **Label and validation** — Use `UFormField` for labels, helper text, and error messages.
5. **Default rows** — Set the `rows` prop for the initial visible line count. Does not constrain total input length.
