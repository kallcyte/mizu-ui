### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Time, type TimeValue } from "@internationalized/date";

interface TimeRange {
  start: TimeValue;
  end: TimeValue;
}

const time = ref(new Time(14, 30));
const range = ref<TimeRange>({
  start: new Time(9, 0),
  end: new Time(17, 0),
});
</script>

<template>
  <!-- Single time -->
  <UInputTime v-model="time" placeholder="Select a time" />

  <!-- Time range -->
  <UInputTime v-model="range" range placeholder="Select a time range" />

  <!-- 12-hour format with 15-minute steps -->
  <UInputTime v-model="time" hour-cycle="12" :step="{ minute: 15 }" />

  <!-- With min/max constraints -->
  <UInputTime v-model="time" :min-value="new Time(9, 0)" :max-value="new Time(17, 0)" />
</template>
```

## Anatomy

An input time consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | Wrapper element containing the time field |
| Segment | Yes | Individual editable time segment (hour, minute, second) |
| Separator | No | Colon between time segments, or dash between start/end (range mode) |
| Leading | No | Icon or content before the time input |
| Trailing | No | Icon or content after the time input |
| Time Zone | No | Display of the current timezone (hidden by default) |

## Implementation Notes

1. **Use `<UInputTime>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Time values use `@internationalized/date`** — Model values must be `Time`, `CalendarDateTime`, or `ZonedDateTime` from `@internationalized/date`. This is Nuxt UI's standard time handling.
3. **Range selection** — Set `range` to `true`. The model value becomes a `TimeRange` object with `start` and `end` properties.
4. **Granularity** — Defaults to `'minute'`. Set to `'hour'` for hour-only selection or `'second'` to include seconds. Controls which editable segments appear.
5. **Hour cycle** — Use `hour-cycle="12"` for 12-hour display with AM/PM, or `hour-cycle="24"` for 24-hour format. Defaults to the locale preference.
6. **Custom time steps** — Use `step` to control increment behavior. For example, `{ minute: 15 }` restricts minute selection to 0, 15, 30, 45. Combine with `stepSnapping` to enforce the value snaps on blur.
7. **Time constraints** — Use `minValue` and `maxValue` to bound the selectable range. Use `isTimeUnavailable` for custom per-time logic (e.g. blocking business hours).
8. **Form integration** — Wrap with `UFormField` for labels, helper text, and error messages. The component integrates with native form validation via `required` and `name`.
