TagsInput is a text field that converts typed entries into a list of removable tag chips. It is used wherever users need to assign multiple discrete values to an entity — labels, skills, recipients, categories.

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string[]` | `undefined` | Controlled list of tag values |
| `defaultValue` | `string[]` | `undefined` | Initial uncontrolled tags |
| `placeholder` | `string` | `'Add a tag...'` | Input placeholder (only when empty) |
| `disabled` | `boolean` | `false` | Disable the control and hide remove buttons |
| `readOnly` | `boolean` | `false` | Render the control without removing or typing |
| `required` | `boolean` | `false` | Marks the field as required; renders a label asterisk |
| `error` | `boolean` | `false` | Applies the error border + `aria-invalid="true"` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control + chip dimensions |
| `tagVariant` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'primary'` | Chip color scheme (delegated to each `MizuTag`) |
| `separator` | `('Enter' \| ',' \| ';' \| 'Tab')[]` | `['Enter', ',']` | Keys / characters that commit a tag |
| `maxTags` | `number` | `undefined` | Maximum allowed tag count |
| `allowDuplicates` | `boolean` | `false` | Permit repeated values |
| `validate` | `(value: string) => boolean \| string` | `undefined` | Custom validator; `false` or empty-string result rejects the tag |
| `name` | `string` | `undefined` | Form field name |
| `label` | `string` | `undefined` | Optional label rendered above the control |
| `helperText` | `string` | `undefined` | Optional hint shown below the control |
| `id` | `string` | `undefined` | Optional explicit ID for the container |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string[]` | Emitted on every commit and remove (use with `v-model`) |
| `add` | `string` | Emitted when a tag is committed |
| `remove` | `string` | Emitted when a tag is removed (via button or Backspace) |
| `focus` | `FocusEvent` | Emitted when the trailing input receives focus |
| `blur` | `FocusEvent` | Emitted when the trailing input loses focus |
| `invalid-tag` | `[value: string, reason: 'duplicate' \| 'max' \| 'validation']` | Emitted when a tag is rejected |

| Token | Value | Usage |
|-------|-------|-------|
| `--color-surface-base` | #FFFFFF / #0F1117 | Container background |
| `--color-surface-muted` | #F4F4F6 / #1B1D26 | Container border + disabled background |
| `--color-foreground-primary` | #001C44 / #EDEDED | Input text color |
| `--color-foreground-tertiary` | #6E7079 / #9C9DA8 | Input placeholder |
| `--color-foreground-secondary` | #4F5159 / #B5B6BD | Helper text |
| `--color-brand-ycp` | #001C44 | Focus border on container |
| `--color-feedback-error-base` | #DC2626 | Error border + error helper text |

Chip colors are consumed from the same tokens as `MizuTag` (`--mizu-tag-bg`, `--mizu-tag-text`, `--mizu-tag-border`).

### Sizing

Three sizes control the container height and input font size. The chips themselves are always rendered by `MizuTag` at its fixed 24px height.

| Size | Container Min-Height | Horizontal Padding | Vertical Padding | Input Font Size | Input Height |
|------|---------------------|-------------------|------------------|-----------------|--------------|
| `sm` | 28px | 8px | 2px | 12px | 24px |
| `md` | 36px | 10px | 6px | 12px | 24px |
| `lg` | 40px | 10px | 8px | 14px | 24px |

### Transitions

| Property | Duration | Easing |
|----------|----------|--------|
| Container border / shadow (focus) | 200ms | ease-in-out |
| Chip add animation | 150ms | ease-out (`scale(0.85) → scale(1)` + fade) |
| Chip error flash (invalid) | 200ms | ease-in-out (`translateX` shake) |
| Remove button opacity | 150ms | linear |

### Focus Ring

| Element | Behavior |
|---------|----------|
| Container (focus) | Border becomes `brand-ycp`, `0 0 0 1px brand-ycp` shadow |
| Remove button (focus-visible) | 2px `brand-ycp` shadow ring at `border-radius: 2px` |
| Error + focused | Border becomes `feedback-error-base` with matching shadow |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Color Contrast | 4.5:1 for chip label text via `brand-primary` / `feedback-*-base` |
| Keyboard | `Enter`, `,`, `;`, `Tab` commit a tag; `Backspace` removes the last tag when input is empty |
| Screen Reader | Container announces as `role="group"`; helper text linked via `aria-describedby`; remove button uses `aria-label="Remove {tag}"` |
| Disabled | `aria-disabled="true"` on container; native `disabled` on input |
| Required | `aria-required="true"` on container; visual asterisk in label |
| Invalid | `aria-invalid="true"` on container when `error` is set |

## Anatomy

A TagsInput consists of up to 5 parts:

| Part | Required | Description |
|------|----------|-------------|
| Wrapper | Yes | Layout shell with vertical label → control → helper text stack (same as `MizuInput`) |
| Container | Yes | The chip-and-input "well" reusing `MizuInput`'s `.mizu-input` styling |
| `MizuTag` Chip | No | A closable `MizuTag` pill for each committed value |
| Native Input | Yes | The trailing transparent text field where new values are typed |
| Helper Text | No | Optional hint shown below the control (or an error message) |

## Implementation Notes

1. **Composition** — the container reuses `MizuInput`'s `.mizu-input` class, so focus, error, and disabled states are visually identical to the standalone input. Chips are rendered with the existing `MizuTag` component, so the color palette, close button, and accessibility are inherited rather than duplicated.
2. **Tag variant option** — the `tagVariant` prop maps directly to `MizuTag`'s `variant` prop, allowing consumers to choose the chip color scheme independently from the input size.
3. **Controlled / uncontrolled** — when `modelValue` is `undefined`, TagsInput holds its own internal `ref` and only emits on change; passing `v-model` makes it fully controlled.
4. **Multi-separator support** — the `separator` prop is a list of keys / characters; any of them commit a tag, and pasted strings are split on every configured separator at paste time.
5. **Whitespace trimming** — committed values are `.trim()`-ed before validation, so leading/trailing whitespace never produces blank or duplicate-looking tags.
6. **Duplicate rejection** — controlled by `allowDuplicates`; rejected duplicates fire `invalid-tag` with `reason: 'duplicate'` and flash the most recently added chip.
7. **Custom validation** — `validate(value)` returning `false` or `""` rejects the tag; returning `true` accepts it. No tag is silently dropped.
8. **Backspace deletion** — when the input is empty and focus is inside the container, `Backspace` removes the last tag and refocuses the input automatically.
9. **Blur commits** — leaving the field while text is still in the input commits the pending value (trimmed).
10. **Inline animations** — chips animate in via a 150ms `scale(0.85) → scale(1)` pop; rejected commits trigger a 200ms `translateX` shake on the most recent chip.
11. **Tailwind `@apply`** — uses `@apply` + `@reference "../index.css"` for Tailwind v4 compatibility; the `MizuTag` component already handles its own token binding.
12. **Class inheritance** — accepts `class` from `useAttrs()` to allow consumers to override container-level styling without losing the `mizu-input` hooks.
