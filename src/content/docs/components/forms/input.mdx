## API

### Props

| Prop           | Type                                                                        | Default     | Description                                               |
| -------------- | --------------------------------------------------------------------------- | ----------- | --------------------------------------------------------- |
| `modelValue`   | `string`                                                                    | `""`        | Controlled value, supports v-model                        |
| `placeholder`  | `string`                                                                    | `""`        | Placeholder text                                          |
| `disabled`     | `boolean`                                                                   | `false`     | Disabled state                                            |
| `error`        | `boolean`                                                                   | `false`     | Error state                                               |
| `type`         | `'text' \| 'password' \| 'email' \| 'number' \| 'tel' \| 'url' \| 'search'` | `'text'`    | Input type                                                |
| `size`         | `'sm' \| 'md' \| 'lg'`                                                      | `'md'`      | Input size                                                |
| `name`         | `string`                                                                    | `undefined` | Form field name                                           |
| `required`     | `boolean`                                                                   | `false`     | Required state                                            |
| `label`        | `string`                                                                    | `undefined` | Label text                                                |
| `helperText`   | `string`                                                                    | `undefined` | Helper text below input                                   |
| `showPassword` | `boolean`                                                                   | `false`     | Show password toggle button (only when type=`"password"`) |

### Slots

| Slot            | Description           |
| --------------- | --------------------- |
| `leading-icon`  | Leading icon content  |
| `trailing-icon` | Trailing icon content |

### Events

| Event               | Payload      | Description             |
| ------------------- | ------------ | ----------------------- |
| `update:modelValue` | `string`     | Emitted on value change |
| `focus`             | `FocusEvent` | Emitted on focus        |
| `blur`              | `FocusEvent` | Emitted on blur         |

### Sizing

Inputs share the same height scale as MizuButton so side-by-side fields and buttons align cleanly.

#### Height & Padding

| Size   | Height | Horizontal Padding | Border Radius |
| ------ | ------ | ------------------ | ------------- |
| **SM** | 28px   | 8px                | 4px           |
| **MD** | 36px   | 10px               | 6px           |
| **LG** | 40px   | 10px               | 6px           |

#### Icon Sizes

| Size   | Icon Container | Icon Size |
| ------ | -------------- | --------- |
| **SM** | 28px           | 12px      |
| **MD** | 34px           | 14px      |
| **LG** | 36px           | 14px      |

#### Touch Target

All input sizes maintain a minimum touch target of **44px x 44px** for accessibility (WCAG 2.5.8).

### Transitions

| Property     | Duration | Easing      |
| ------------ | -------- | ----------- |
| Border Color | 200ms    | ease-in-out |
| Box Shadow   | 200ms    | ease-in-out |

### Focus Ring

| Property      | Value                                                         |
| ------------- | ------------------------------------------------------------- |
| Style         | `border-color: brand-ycp` + `box-shadow: 0 0 0 1px brand-ycp` |
| Offset        | 0px (inset)                                                   |
| Border Radius | Inherit from input                                            |

### Accessibility

| Criterion           | Implementation                                            |
| ------------------- | --------------------------------------------------------- |
| Touch Target        | Minimum 44px x 44px                                       |
| Color Contrast      | 4.5:1 for text, 3:1 for borders                           |
| Keyboard Navigation | `tabindex="0"`, Tab to focus, Enter to submit             |
| Screen Reader       | `<label>` associated via `for`/`id`                       |
| Focus Indicator     | Visible focus ring on keyboard focus                      |
| Disabled State      | `aria-disabled="true"`, `disabled` attribute              |
| Required            | `aria-required="true"`, `required` attribute              |
| Error               | `aria-invalid="true"`, `aria-describedby` for helper text |

## Anatomy

An input consists of up to 5 parts:

| Part          | Required | Description                                   |
| ------------- | -------- | --------------------------------------------- |
| Container     | Yes      | The input's border and background area        |
| Label         | No       | Descriptive text above the input              |
| Leading Icon  | No       | Icon placed inside the input, before the text |
| Trailing Icon | No       | Icon placed inside the input, after the text  |
| Helper Text   | No       | Descriptive text below the input              |

## Show Password

When `showPassword` is set on a `type="password"` input, an eye toggle button appears at the trailing edge. Click it to switch between masked (`type="password"`) and visible (`type="text"`).

```vue
<MizuInput
  v-model="pwd"
  label="Password"
  type="password"
  show-password
  placeholder="Enter password"
/>
```

## Implementation Notes

1. **Native `<input>` element** — No Reka UI primitive needed; use native HTML input for maximum accessibility
2. **Tailwind `@apply`** — Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
3. **CSS Custom Properties** — Colors are resolved via CSS variables from `@mizu/tokens`
4. **Self-contained CSS** — Tailwind utilities are bundled into `dist/index.css` via `@tailwindcss/vite`; consumers do not need Tailwind installed
5. **Class inheritance** — Accept `class` prop for overrides via `useAttrs()`
6. **TypeScript** — Full type safety with `<script setup lang="ts">`
7. **Tree-shakeable** — Export as ESM + CJS via Vite library mode
8. **v-model support** — Uses `modelValue`/`update:modelValue` pattern for two-way binding
9. **Label association** — Label is linked to input via `for`/`id` for screen reader accessibility
10. **Helper text** — Connected via `aria-describedby` for screen reader announcements
11. **Password toggle** — Built-in eye icon toggle when `showPassword` is enabled on password inputs
