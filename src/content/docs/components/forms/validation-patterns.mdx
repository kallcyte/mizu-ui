Mizu provides a lightweight `useForm` composable that pairs with [Zod](https://zod.dev) schemas for form validation. It is designed to work with the existing `error` and `helperText` props on `UInput` and other form components, keeping validation at the application level rather than baked into the components themselves.

## Why Application-Level Validation?

`UInput` accepts an `error` (boolean) and `helperText` (string) prop. You can plug in any validation library without modifying the component. The `useForm` composable is one adapter for Zod schemas.

## Setup

Add `zod` to your project:

```bash
npm install zod
```

Then import the composable:

```ts
import { useForm } from "@mizu/vue";
import { z } from "zod";
```

## Basic Usage

Define a Zod schema and pass it to `useForm`:

```vue
<script setup lang="ts">
import { useForm, UInput, UButton } from "@mizu/vue";
import { z } from "zod";

const schema = z.object({
  email: z.email("Please enter a valid email address"),
  password: z.string().min(8, "Password must be at least 8 characters"),
});

type Form = z.infer<typeof schema>;

const form = useForm(schema);

async function handleSubmit(values: Form) {
  // Submit to API
  console.log(values);
}

const submitHandler = form.handleSubmit(handleSubmit);
</script>

<template>
  <form @submit="submitHandler" novalidate>
    <UInput
      v-model="form.fields.email.value"
      :error="!!form.fields.email.error.value"
      :helper-text="form.fields.email.error.value"
      label="Email"
      type="email"
      placeholder="you@example.com"
      @blur="form.fields.email.onBlur()"
    />
    <UInput
      v-model="form.fields.password.value"
      :error="!!form.fields.password.error.value"
      :helper-text="form.fields.password.error.value"
      label="Password"
      type="password"
      placeholder="Enter password"
      @blur="form.fields.password.onBlur()"
    />
    <UButton type="submit" :loading="form.isSubmitting.value">
      {{ form.isSubmitting.value ? "Submitting..." : "Submit" }}
    </UButton>
  </form>
</template>
```

## API

### `useForm(schema)`

| Return value                  | Type                                  | Description                                                                   |
| ----------------------------- | ------------------------------------- | ----------------------------------------------------------------------------- |
| `fields`                      | `Record<string, FieldState>`          | Reactive field objects with `value`, `error`, `touched`, `onChange`, `onBlur` |
| `values`                      | `ComputedRef<T>`                      | All form values as a single reactive object                                   |
| `errors`                      | `ComputedRef<Record<string, string>>` | All field errors as `{ fieldName: message }`                                  |
| `hasErrors`                   | `ComputedRef<boolean>`                | Whether any field has an error                                                |
| `isSubmitting`                | `Ref<boolean>`                        | Whether the form is currently submitting                                      |
| `submitCount`                 | `Ref<number>`                         | Number of times the form has been submitted                                   |
| `validate()`                  | `() => boolean`                       | Validate all fields, returns `true` if valid                                  |
| `handleSubmit(fn)`            | `(fn) => (event?) => Promise<void>`   | Wraps your submit handler with validation                                     |
| `reset()`                     | `() => void`                          | Reset values, errors, and touched state                                       |
| `setFieldValue(field, value)` | `(field, value) => void`              | Programmatically set a field value                                            |
| `setFieldError(field, error)` | `(field, error) => void`              | Programmatically set a field error (e.g. server validation)                   |

### `FieldState`

| Property          | Type                               | Description                                       |
| ----------------- | ---------------------------------- | ------------------------------------------------- |
| `value`           | `Ref<string \| boolean \| number>` | Two-way bindable field value (use with `v-model`) |
| `error`           | `Ref<string \| undefined>`         | Current validation error message                  |
| `touched`         | `Ref<boolean>`                     | Whether the field has been blurred                |
| `onChange(value)` | `(value) => void`                  | Call when the field value changes                 |
| `onBlur()`        | `() => void`                       | Call when the field loses focus                   |

## Validation Patterns

### Required Fields

```ts
const schema = z.object({
  name: z.string().min(1, "Name is required"),
});
```

### Email Format

```ts
const schema = z.object({
  email: z.email("Please enter a valid email address"),
});
```

### Minimum / Maximum Length

```ts
const schema = z.object({
  username: z.string().min(3, "At least 3 characters").max(20, "At most 20 characters"),
});
```

### Password Confirmation (Cross-Field)

```ts
const schema = z
  .object({
    password: z.string().min(8, "Password must be at least 8 characters"),
    confirmPassword: z.string(),
  })
  .refine((data) => data.password === data.confirmPassword, {
    message: "Passwords do not match",
    path: ["confirmPassword"],
  });
```

### Server-Side Errors

Use `setFieldError` after an API call to display server validation messages:

```ts
async function handleSubmit(values: Form) {
  const response = await fetch("/api/login", {
    method: "POST",
    body: JSON.stringify(values),
  });
  if (!response.ok) {
    const errors = await response.json();
    for (const [field, message] of Object.entries(errors)) {
      form.setFieldError(field, message as string);
    }
    throw new Error("Validation failed");
  }
}
```

## Summary

| Concern              | Handled by                               |
| -------------------- | ---------------------------------------- |
| Schema definition    | Zod                                      |
| Reactive state       | `useForm` composable                     |
| Visual feedback      | `UInput` `error` + `helperText` props |
| Submission lifecycle | `handleSubmit` wrapper                   |
| Server errors        | `setFieldError` after API call           |
