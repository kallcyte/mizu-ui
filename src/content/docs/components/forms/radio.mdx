A radio group allows users to select exactly one option from a predefined set. Use it when options are mutually exclusive and all options should be visible.

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string` | `''` | v-model selected value |
| `items` | `RadioItem[]` | `[]` | Array of `{ value, label, disabled? }` |
| `disabled` | `boolean` | `false` | Disables all items |
| `name` | `string` | `undefined` | Form field name |
| `required` | `boolean` | `false` | Required for form validation |
| `label` | `string` | `undefined` | Group label text |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls radio size |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | Layout direction |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string` | Emitted when selection changes |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Role | `radiogroup` on the group, `radio` on each item |
| Label | Group label + per-item labels via `id`/`for` |
| Keyboard | Arrow keys navigate between options |
| Focus | Visible focus ring via `focus-visible` |
| Disabled | Items removed from tab order |

## Anatomy

A radio group consists of up to three parts:

| Part | Required | Description |
|------|----------|-------------|
| Group label | No | Descriptive text above the radio group |
| Radio item | Yes | One radio button per option |
| Item label | Yes | Text label for each radio button |

## Implementation Notes

1. **Reka UI** -- Uses `RadioGroupRoot`, `RadioGroupItem`, and `RadioGroupIndicator` from Reka UI.
2. **CSS-only indicator** -- The checked indicator uses `::after` pseudo-element for the inner dot.
3. **Orientation** -- Supports `vertical` (default, column layout) and `horizontal` (inline row).
4. **Class inheritance** -- Accepts `class` prop via `useAttrs()` for Tailwind overrides.
5. **Tree-shakeable** -- Exported as ESM + CJS via Vite library mode.
