A checkbox allows users to toggle a state on or off, or select multiple items from a group. Mizu uses Nuxt UI's `UCheckbox` with the default size scale.

## API

Reference: [Nuxt UI Checkbox](https://ui.nuxt.com/docs/components/checkbox)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Checkbox size |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'primary'` | Semantic color |
| `variant` | `'outline' \| 'soft' \| 'subtle' \| 'ghost' \| 'none'` | `'outline'` | Visual style |
| `label` | `string` | — | Label text |
| `description` | `string` | — | Secondary description text below the label |
| `required` | `boolean` | `false` | Marks the field as required |
| `disabled` | `boolean` | `false` | Disables interaction |
| `indeterminate` | `boolean` | `false` | Partial selection state |
| `defaultValue` | `boolean \| 'indeterminate'` | — | Initial unchecked/checked/indeterminate state |
| `modelValue` | `boolean \| 'indeterminate'` | — | v-model binding |
| `checked` | `boolean \| 'indeterminate'` | — | Controlled checked state |
| `uncheckedValue` | `boolean \| 'indeterminate'` | `false` | Value when unchecked |
| `checkedValue` | `boolean \| 'indeterminate'` | `true` | Value when checked |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Default slot (not typically used) |
| `label` | `{ ui }` | Custom label content |
| `description` | `{ ui }` | Custom description content |

### Example Usage


## Theme

Nuxt UI v4 checkbox defaults already match the Mizu form scale, so no sizing overrides are applied. The default `md` size uses 16px indicators appropriate for inline checkboxes.

## Anatomy

A checkbox consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<label>` wrapping the input and indicator |
| Input | Yes | Hidden `<input type="checkbox">` |
| Indicator | Yes | Visual checkbox with checkmark/indeterminate icon |
| Label | Yes | Text label for the option |
| Description | No | Secondary text below the label |

## Implementation Notes

1. **Use `<UCheckbox>` directly** — No Mizu wrapper needed. Nuxt UI defaults match the Mizu design spec.
2. **Indeterminate state** — Use `v-model="value"` with `value` set to `'indeterminate'`, or pass `defaultValue="indeterminate"` for uncontrolled use. Useful for "select all" patterns where some children are selected.
3. **Card variant** — Set `variant="soft"` for a card-style checkbox with background fill.
4. **Description slot** — Use the `description` prop for inline help text under the label.
5. **Form integration** — Checkbox works inside `UFormField` for structured form layouts.
