A form component that validates form data using any validation library supporting [Standard Schema](https://github.com/standard-schema/standard-schema) — such as [Valibot](https://github.com/fabian-hiller/valibot), [Zod](https://github.com/colinhacks/zod), [Yup](https://github.com/jquense/yup), [Joi](https://github.com/hapijs/joi) or [Superstruct](https://github.com/ianstormtaylor/superstruct) — or your own custom validation logic. It works with the [FormField](/docs/components/forms/form-field) component to display error messages around form elements automatically.

## Usage

### Schema validation

Provide a `state` object and a `schema` to validate against. No validation library is included by default — install the one you need.

```vue
<script setup lang="ts">
import * as z from "zod";
import type { FormSubmitEvent } from "@nuxt/ui";

const schema = z.object({
  email: z.string().email("Invalid email"),
  password: z.string().min(8, "Must be at least 8 characters")
});

type Schema = z.output<typeof schema>;

const state = reactive<Partial<Schema>>({
  email: undefined,
  password: undefined
});

async function onSubmit(event: FormSubmitEvent<Schema>) {
  console.log(event.data);
}
</script>

<template>
  <UForm :schema="schema" :state="state" class="space-y-4" @submit="onSubmit">
    <UFormField label="Email" name="email">
      <UInput v-model="state.email" />
    </UFormField>

    <UFormField label="Password" name="password">
      <UInput v-model="state.password" type="password" />
    </UFormField>

    <UButton type="submit">Submit</UButton>
  </UForm>
</template>
```

### Custom validation

Use the `validate` prop for your own validation logic. The function must return an array of `FormError` objects with `name` (the `name` of the `UFormField`) and `message`.

```vue
<script setup lang="ts">
import type { FormError, FormSubmitEvent } from "@nuxt/ui";

const state = reactive({ email: undefined, password: undefined });
type Schema = typeof state;

function validate(state: Partial<Schema>): FormError[] {
  const errors: FormError[] = [];
  if (!state.email) errors.push({ name: "email", message: "Required" });
  if (!state.password) errors.push({ name: "password", message: "Required" });
  return errors;
}

async function onSubmit(event: FormSubmitEvent<Schema>) {
  console.log(event.data);
}
</script>

<template>
  <UForm :validate="validate" :state="state" class="space-y-4" @submit="onSubmit">
    <UFormField label="Email" name="email">
      <UInput v-model="state.email" />
    </UFormField>

    <UFormField label="Password" name="password">
      <UInput v-model="state.password" type="password" />
    </UFormField>

    <UButton type="submit">Submit</UButton>
  </UForm>
</template>
```

### Error reporting

Errors are matched to the corresponding `UFormField` using its `name` prop. Nested fields are matched using dot notation, e.g. `<UFormField name="user.email">`.

> Errors on array items include the index in their name (e.g. `tags.0`, `tags.1`) and won't match `<UFormField name="tags">` by name alone. Use the `error-pattern` prop with a regular expression like `/^tags\..+/` to capture them. This is especially useful for components like [InputTags](/docs/components/forms/input-tags).

```vue
<UForm :schema="schema" :state="state" class="space-y-4" @submit="onSubmit">
  <UFormField label="Tags" name="tags" :error-pattern="/^tags\..+/">
    <UInputTags v-model="state.tags" />
  </UFormField>
</UForm>
```

### Input events

The form automatically triggers validation when an input emits `input`, `change`, or `blur`:

- `input` — as you type
- `change` — when you commit to a value
- `blur` — when an input loses focus

Control this with the `validate-on` prop. The form always validates on submit.

```vue
<UForm :schema="schema" :state="state" :validate-on="['input','change','blur']" @submit="onSubmit">
  ...
</UForm>
```

### Error event

Listen to the `@error` event to react when validation fails. The payload is a `FormErrorEvent` containing an array of `FormError` objects with `id`, `name`, and `message`.

```vue
<script setup lang="ts">
import type { FormErrorEvent } from "@nuxt/ui";

async function onError(event: FormErrorEvent) {
  if (event?.errors?.[0]?.id) {
    const element = document.getElementById(event.errors[0].id);
    element?.focus();
    element?.scrollIntoView({ behavior: "smooth", block: "center" });
  }
}
</script>

<template>
  <UForm :validate="validate" :state="state" class="space-y-4" @submit="onSubmit" @error="onError">
    ...
  </UForm>
</template>
```

### HTML5 validation

When calling `form.submit()` programmatically, the Form component automatically triggers native HTML5 validation before submission. This is useful when the submit button is outside the form element, such as in a modal footer.

```vue
<script setup lang="ts">
import { useTemplateRef } from "vue";

const form = useTemplateRef("form");
</script>

<template>
  <div class="space-y-4">
    <UForm ref="form" :state="state" class="space-y-4" @submit="onSubmit">
      <UFormField label="Email" name="email">
        <UInput v-model="state.email" type="email" required />
      </UFormField>
    </UForm>
    <UButton @click="form?.submit()">Submit</UButton>
  </div>
</template>
```

### Nesting forms

Use the `nested` prop to nest multiple `UForm` components and link their validation. Nested forms inherit their parent's state; use the `name` prop to target a nested attribute within the parent's state.

```vue
<UForm :schema="schema" :state="state" class="space-y-4" @submit="onSubmit">
  <UFormField label="Name" name="name">
    <UInput v-model="state.name" />
  </UFormField>

  <UCheckbox v-model="state.news" name="news" label="Subscribe to newsletter" />

  <UForm v-if="state.news" :schema="emailSchema" nested>
    <UFormField label="Email" name="email">
      <UInput v-model="state.email" />
    </UFormField>
  </UForm>

  <UButton type="submit">Submit</UButton>
</UForm>
```

## API

Reference: [Nuxt UI Form](https://ui.nuxt.com/docs/components/form)

### Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `id` | `string \| number` | — | The `id` of the form element |
| `state` | `Record<string, unknown>` | — | Reactive object holding the form's state |
| `schema` | `StandardSchema \| Yup \| Joi \| Superstruct` | — | Schema to validate the form state |
| `validate` | `(state) => FormError[] \| Promise<FormError[]>` | — | Custom validation function |
| `validateOn` | `FormInputEvents[]` | `['input','change','blur']` | Input events that trigger validation |
| `validateOnInputDelay` | `number` | `300` | Debounce delay in ms for input validation |
| `disabled` | `boolean` | `false` | Disable all inputs inside the form |
| `name` | `string` | — | `name` attribute of the form element; for nested forms, the path within parent state |
| `transform` | `boolean` | `true` | Apply schema transformations on submit |
| `nested` | `boolean` | `false` | Attach this form to its parent form |
| `loadingAuto` | `boolean` | `true` | Disable all form elements on `@submit` |
| `ui` | `{ base?: any }` | — | Theme configuration |

`UForm` also supports all native `<form>` HTML attributes: `acceptcharset`, `action`, `autocomplete`, `enctype`, `method`, `novalidate`, `target`, etc.

### Slots

| Slot | Description |
| ---- | ----------- |
| `default` | Form content, typically `UFormField` components |

### Emits

| Event | Payload | Description |
| ----- | ------- | ----------- |
| `submit` | `FormSubmitEvent<FormData>` | Emitted after validation passes |
| `error` | `FormErrorEvent` | Emitted when validation fails on submit |

### Expose

Access the typed component instance using [`useTemplateRef`](https://vuejs.org/api/composition-api-helpers.html#usetemplateref).

| Name | Type | Description |
| ---- | ---- | ----------- |
| `submit` | `() => Promise<void>` | Trigger form submission with HTML5 validation |
| `validate` | `(opts?) => Promise<T>` | Trigger form validation; set `opts.silent` to `true` to suppress errors |
| `clear` | `(path?) => void` | Clear form errors for a path, or all errors if no path |
| `getErrors` | `(path?) => FormErrorWithId[]` | Get errors for a path, or all errors |
| `setErrors` | `(errors, name?) => void` | Set errors for a path, or override all errors |
| `errors` | `Ref<FormErrorWithId[]>` | Reactive reference to all validation errors |
| `disabled` | `Ref<boolean>` | Whether the form is disabled |
| `dirty` | `Ref<boolean>` | `true` if at least one field has been modified |
| `dirtyFields` | `ReadonlySet<keyof T>` | Fields modified by the user |
| `touchedFields` | `ReadonlySet<keyof T>` | Fields the user interacted with |
| `blurredFields` | `ReadonlySet<keyof T>` | Fields blurred by the user |

### FormError

```ts
interface FormError {
  name: string;
  message: string;
}
```

Use `name` (not `field`) to target the `UFormField` that should display the error.

## Anatomy

A complete form consists of:

| Part | Required | Description |
| ---- | -------- | ----------- |
| `UForm` | Yes | Wraps all fields, provides validation and submission lifecycle |
| `UFormField` | Yes (per input) | Renders label, description, error, and help text for a single field |

See [FormField](/docs/components/forms/form-field) for detailed field-level API.
