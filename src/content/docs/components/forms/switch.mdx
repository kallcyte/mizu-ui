A switch toggles a binary setting on or off. Unlike checkboxes (selection), switches are used for immediate-effect settings like enabling notifications. Mizu uses Nuxt UI's `USwitch` with the default size scale.

## API

| `label` | `string` | — | Label text |

| `loadingIcon` | `string` (Iconify) | `i-lucide-loader-circle` | Icon shown when loading |
| `highlight` | `boolean` | `false` | Highlight the ring like a focus state |
| `required` | `boolean` | `false` | Marks the field as required |
| `disabled` | `boolean` | `false` | Disables interaction |
| `defaultValue` | `boolean` | — | Initial state |
| `modelValue` | `boolean` | — | v-model binding |
| `trueValue` | `boolean` | `true` | Value when checked |
| `falseValue` | `boolean` | `false` | Value when unchecked |
| `id` | `string` | — | Element id |
| `name` | `string` | — | Field name submitted with form |

### Slots

| Slot | Props | Description |
|------|-------|-------------|

### Example Usage

```vue
<USwitch label="Enable notifications" v-model="notifications" />

<USwitch label="Dark mode" :default-value="true" :checked-icon="'i-ph-moon'" :unchecked-icon="'i-ph-sun'" />

<USwitch disabled label="Airplane mode" />
```

## Theme

Nuxt UI v4 switch defaults already match the Mizu form scale, so no sizing overrides are applied. The default track is 36px x 20px with a 16px thumb.

### Design Specs

| Property | Value |
|----------|-------|

| Track Height | 20px |
| Thumb Size | 16px |
| Track Radius | 9999px (full pill) |

## Anatomy

A switch consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<label>` wrapping the track and thumb |
| Track | Yes | Pill-shaped background that changes color on toggle |
| Thumb | Yes | Circular knob that slides left/right |
| Label | Yes | Text label describing the setting |
| Description | No | Secondary text below the label |

## Implementation Notes

1. **Use `<USwitch>` directly** "” No Mizu wrapper needed. Nuxt UI defaults match the Mizu design spec.
2. **Switch vs. Checkbox** "” Use a Switch for immediate-effect settings (notifications, dark mode). Use a Checkbox for selections that require a submit action (terms agreement, item selection).
3. **Custom icons** "” Use `checkedIcon` and `uncheckedIcon` to display contextual icons inside the thumb.
4. **Loading state** "” Set `loading` to `true` to show a spinner in the thumb while the setting change is being processed.
5. **Form integration** "” Switch works inside `UFormField` for structured form layouts, though switches are typically standalone settings controls.
