> **Nuxt UI Component:** This uses Nuxt UI's `USwitch` component. Nuxt UI v4 defaults already match the Mizu form scale, so no sizing overrides are applied. See the [Theme](#theme) section for details.

A switch toggles a binary setting on or off. Unlike checkboxes (selection), switches are used for immediate-effect settings like enabling notifications. Mizu uses Nuxt UI's `USwitch` with the default size scale.

## Anatomy

A switch consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<label>` wrapping the track and thumb |
| Track | Yes | Pill-shaped background that changes color on toggle |
| Thumb | Yes | Circular knob that slides left/right |
| Label | Yes | Text label describing the setting |
| Description | No | Secondary text below the label |

## Implementation Notes

1. **Use `<USwitch>` directly** â€” No Mizu wrapper needed. Nuxt UI defaults match the Mizu design spec.
2. **Switch vs. Checkbox** â€” Use a Switch for immediate-effect settings (notifications, dark mode). Use a Checkbox for selections that require a submit action (terms agreement, item selection).
3. **Custom icons** â€” Use `checkedIcon` and `uncheckedIcon` to display contextual icons inside the thumb.
4. **Loading state** â€” Set `loading` to `true` to show a spinner in the thumb while the setting change is being processed.
5. **Form integration** â€” Switch works inside `UFormField` for structured form layouts, though switches are typically standalone settings controls.
