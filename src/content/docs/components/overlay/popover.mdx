A popover displays floating content anchored to a trigger element. Use it for rich interactive content such as forms, color pickers, profile cards, or menus of actions that need more space than a tooltip provides.

## API

### MizuPopoverRoot Props

| Prop          | Type      | Default     | Description                                          |
| ------------- | --------- | ----------- | ---------------------------------------------------- |
| `open`        | `boolean` | `undefined` | Controlled open state (v-model:open)                 |
| `defaultOpen` | `boolean` | `false`     | Initial open state when uncontrolled                 |
| `modal`       | `boolean` | `false`     | Trap focus and disable outside interaction when true |

### MizuPopoverTrigger Props

| Prop      | Type      | Default    | Description                        |
| --------- | --------- | ---------- | ---------------------------------- |
| `asChild` | `boolean` | `true`     | Merge props onto the child element |
| `as`      | `string`  | `"button"` | Element or component to render as  |

### MizuPopoverPortal Props

| Prop         | Type                    | Default     | Description                                           |
| ------------ | ----------------------- | ----------- | ----------------------------------------------------- |
| `forceMount` | `boolean`               | `undefined` | Force render even when closed (useful for animations) |
| `to`         | `string \| HTMLElement` | `"body"`    | Where to portal the content                           |

### MizuPopoverContent Props

| Prop                | Type                                     | Default     | Description                                        |
| ------------------- | ---------------------------------------- | ----------- | -------------------------------------------------- |
| `side`              | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"`  | Preferred side relative to the trigger             |
| `sideOffset`        | `number`                                 | `8`         | Distance from the trigger in pixels                |
| `align`             | `"start" \| "center" \| "end"`           | `"center"`  | Alignment along the trigger axis                   |
| `alignOffset`       | `number`                                 | `0`         | Offset along the alignment axis                    |
| `avoidCollisions`   | `boolean`                                | `true`      | Flip to opposite side when colliding with viewport |
| `collisionBoundary` | `Element \| Element[] \| null`           | `undefined` | Custom boundary for collision detection            |
| `collisionPadding`  | `number`                                 | `8`         | Padding from collision boundary in pixels          |
| `sticky`            | `"partial" \| "always"`                  | `"partial"` | Keep content in view while trigger scrolls         |
| `hideWhenDetached`  | `boolean`                                | `false`     | Hide when trigger is occluded                      |
| `arrowPadding`      | `number`                                 | `0`         | Minimum distance between arrow and corner          |

### MizuPopoverArrow Props

| --------- | --------- | ----------- | ---------------------------------- |

| `asChild` | `boolean` | `undefined` | Merge props onto the child element |

### MizuPopoverClose Props

| Prop      | Type      | Default     | Description                        |

### MizuPopoverAnchor Props

| Prop        | Type          | Default     | Description                              |
| ----------- | ------------- | ----------- | ---------------------------------------- |
| `asChild`   | `boolean`     | `undefined` | Merge props onto the child element       |
| `as`        | `string`      | `undefined` | Element or component to render as        |
| `reference` | `HTMLElement` | `undefined` | Custom reference element for positioning |

### Events

| Event                | Payload         | Description                               |
| -------------------- | --------------- | ----------------------------------------- |
| `update:open`        | `boolean`       | Emitted from Root when open state changes |
| `openAutoFocus`      | `Event`         | Emitted before focus moves to content     |
| `closeAutoFocus`     | `Event`         | Emitted before focus returns to trigger   |
| `escapeKeyDown`      | `KeyboardEvent` | Emitted when Escape is pressed            |
| `pointerDownOutside` | `Event`         | Emitted when a pointerdown occurs outside |
| `focusOutside`       | `Event`         | Emitted when focus moves outside          |
| `interactOutside`    | `Event`         | Emitted on any outside interaction        |

### Example Usage

```vue
<script setup>
import {
  MizuPopoverRoot,
  MizuPopoverTrigger,
  MizuPopoverPortal,
  MizuPopoverContent,
  MizuPopoverArrow,
  MizuPopoverClose,
  MizuButton,
} from "@mizu/vue";

const open = ref(false);
</script>

<template>
  <MizuPopoverRoot v-model:open="open">
    <MizuPopoverTrigger>
      <MizuButton variant="secondary" size="sm">Open</MizuButton>
    </MizuPopoverTrigger>
    <MizuPopoverPortal>
      <MizuPopoverContent side="bottom" :side-offset="8">
        <div class="popover-title">Popover title</div>
        <div class="popover-body">Rich content goes here.</div>
        <MizuPopoverArrow />
        <MizuPopoverClose>
          <MizuButton variant="ghost" size="sm">Close</MizuButton>
        </MizuPopoverClose>
      </MizuPopoverContent>
    </MizuPopoverPortal>
  </MizuPopoverRoot>
</template>
```

### Transitions

| Property             | Duration | Easing                        |
| -------------------- | -------- | ----------------------------- |
| opacity              | 200ms    | cubic-bezier(0.16, 1, 0.3, 1) |
| transform            | 200ms    | cubic-bezier(0.16, 1, 0.3, 1) |
| translate (per side) | 8px      | cubic-bezier(0.16, 1, 0.3, 1) |

Animations are direction-aware: when `side="top"`, content slides down from above; when `side="right"`, content slides in from the right, and so on.

### Focus Ring

The popover content itself does not render a focus ring (it is programmatically focused only when `modal` is true). Focus management is handled by Reka UI's PopoverRoot.

### Accessibility

| Criterion      | Implementation                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------- |
| Keyboard       | `Tab` moves focus through interactive elements inside the popover; `Escape` closes it           |
| Screen readers | Content announced via `role="dialog"`; trigger is a `button` element                            |
| Focus trap     | When `modal` is true, focus is trapped inside the popover                                       |
| Click outside  | Clicking outside closes the popover (unless `modal` is true with `disableOutsidePointerEvents`) |
| Focus return   | On close, focus returns to the trigger element                                                  |

#### ARIA Attributes

```html
<button aria-haspopup="dialog" aria-expanded="false" aria-controls="popover-1">Open</button>
<div id="popover-1" role="dialog" aria-labelledby="popover-title">Content</div>
```

Reka UI handles all ARIA attributes automatically when using the compound components.

## Anatomy

A popover consists of up to seven parts:

| Part    | Required | Description                                                     |
| ------- | -------- | --------------------------------------------------------------- |
| Root    | Yes      | Controls open state and modal behavior of a single popover      |
| Trigger | Yes      | The element that opens the popover when clicked                 |
| Portal  | No       | Renders content into the body to escape stacking-context issues |
| Content | Yes      | The floating panel that holds the popover body                  |
| Arrow   | No       | Optional arrow pointing back to the trigger element             |
| Close   | No       | Any element that closes the popover when activated              |
| Anchor  | No       | Custom anchor element for advanced positioning                  |

## Composition

```
PopoverRoot
  ├── PopoverTrigger (activates the popover)
  └── PopoverPortal (portals content to body)
        └── PopoverContent (the floating panel)
              ├── PopoverArrow (optional)
              └── PopoverClose (any element that closes the popover)
```

## Implementation Notes

1. **Reka UI primitives** -- uses `PopoverRoot`, `PopoverTrigger`, `PopoverPortal`, `PopoverContent`, `PopoverArrow`, `PopoverClose`, and `PopoverAnchor` from `reka-ui`.
2. **Compound component** -- requires `MizuPopoverRoot` at the top with `MizuPopoverTrigger` and `MizuPopoverContent` as children.
3. **Portal by convention** -- the demo wraps content in `MizuPopoverPortal` to escape parent stacking contexts. While Reka UI does not strictly require a portal, it is recommended for popovers rendered inside transformed or overflow-hidden containers.
4. **Modal vs non-modal** -- the `modal` prop enables focus trapping and disables outside interaction. Use it for destructive confirmation flows inside the popover.
5. **Direction-aware animations** -- content slides in from the opposite side of where it appears (e.g., `side="top"` slides down from above), with a scale + fade animation.
6. **Arrow styling** -- the arrow fill matches the popover background, and its stroke matches the popover border, creating a seamless visual edge.
7. **Class inheritance** -- each sub-component accepts a `class` attribute via `useAttrs()` for Tailwind overrides.
8. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode. Each sub-component is independently importable.
