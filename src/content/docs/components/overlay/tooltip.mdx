> **Nuxt UI Component:** This uses Nuxt UI's `UTooltip` component. Nuxt UI v4 defaults already match the Mizu design scale, so no sizing overrides are applied.

A tooltip provides brief, contextual help text when hovering or focusing an element. Mizu uses Nuxt UI's `UTooltip` with compact dimensions (6px height, 12px font size).

### Example Usage

```vue
<UTooltip text="Save changes">
  <UButton icon="i-ph-floppy-disk" />
</UTooltip>

<UTooltip text="Delete" :popper="{ placement: 'top' }">
  <UButton color="error" icon="i-ph-trash" />
</UTooltip>
```

## Theme

Nuxt UI v4 tooltip defaults (compact h-6, px-2.5, text-xs, rounded-sm) are standard tooltip dimensions that don't require Mizu-specific adjustments. No overrides are needed.

## Anatomy

A tooltip consists of:

| Part | Required | Description |
|------|----------|-------------|
| Trigger | Yes | The element that reveals the tooltip on hover/focus |
| Content | Yes | The popup text label |

## Implementation Notes

1. **Use `<UTooltip>` directly** â€” No Mizu wrapper needed.
2. **Text vs. slot** â€” Use the `text` prop for simple strings. Use the `text` slot for rich content or custom formatting.
3. **Positioning** â€” Use the `content` prop (popper options) to control placement. Default is `top`.
4. **Keyboard accessibility** â€” Tooltips are shown on `:focus` as well as `:hover`, meeting WCAG keyboard requirements.
