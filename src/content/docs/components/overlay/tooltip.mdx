A tooltip displays contextual information when a user hovers over or focuses an element. Use it for labels, descriptions, or hints that supplement the UI without cluttering it.

## API

### MizuTooltipProvider Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `delayDuration` | `number` | `700` | Delay before tooltip opens (ms) |
| `skipDelayDuration` | `number` | `300` | Delay to skip when moving between tooltips (ms) |
| `disableHoverableContent` | `boolean` | `false` | Disable hover on content |
| `disabled` | `boolean` | `false` | Disable all tooltips |

### MizuTooltipRoot Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `undefined` | Controlled open state (v-model:open) |
| `defaultOpen` | `boolean` | `false` | Initial open state |
| `delayDuration` | `number` | `undefined` | Override provider delay |
| `disableHoverableContent` | `boolean` | `undefined` | Override provider setting |
| `disableClosingTrigger` | `boolean` | `undefined` | Disable closing on trigger click |
| `disabled` | `boolean` | `undefined` | Disable this tooltip |

### MizuTooltipTrigger Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Merge props onto child element |
| `as` | `string` | `"button"` | Element or component to render as |

### MizuTooltipContent Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | Preferred side |
| `sideOffset` | `number` | `8` | Distance from trigger |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment along trigger |
| `alignOffset` | `number` | `0` | Offset from alignment |
| `avoidCollisions` | `boolean` | `true` | Flip when colliding |
| `collisionPadding` | `number` | `0` | Padding from viewport edge |
| `showArrow` | `boolean` | `true` | Show arrow pointing to trigger |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:open` | `boolean` | Emitted when open state changes |

### Example Usage

```vue
<script setup>
import { MizuTooltipProvider, MizuTooltipRoot, MizuTooltipTrigger, MizuTooltipContent, MizuButton } from "@mizu/vue";
</script>

<template>
  <MizuTooltipProvider>
    <MizuTooltipRoot>
      <MizuTooltipTrigger>
        <MizuButton variant="secondary" size="sm">Hover me</MizuButton>
      </MizuTooltipTrigger>
      <MizuTooltipContent side="top">
        <span>Tooltip content</span>
      </MizuTooltipContent>
    </MizuTooltipRoot>
  </MizuTooltipProvider>
</template>
```

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Keyboard | Trigger receives focus; tooltip opens on focus |
| Screen readers | Content associated with trigger via aria-describedby |
| Hover | Tooltip appears on hover with configurable delay |
| Dismiss | Tooltip closes when trigger loses focus or mouse leaves |

#### ARIA Attributes

```html
<button aria-describedby="tooltip-1">Hover me</button>
<div id="tooltip-1" role="tooltip">Tooltip content</div>
```

## Anatomy

A tooltip consists of four parts:

| Part | Required | Description |
|------|----------|-------------|
| Provider | Yes | Wraps tooltips and manages shared delay/delay settings |
| Root | Yes | Controls open state and behavior of a single tooltip |
| Trigger | Yes | The element that activates the tooltip on hover/focus |
| Content | Yes | The popup that displays the tooltip text |

## Composition

```
TooltipProvider
  └── TooltipRoot
        ├── TooltipTrigger (activates the tooltip)
        └── TooltipContent (popup with text)
              └── TooltipArrow (optional arrow pointing to trigger)
```

## Implementation Notes

1. **Reka UI primitives** -- uses `TooltipProvider`, `TooltipRoot`, `TooltipTrigger`, `TooltipContent`, and `TooltipArrow` from reka-ui.
2. **Compound component** -- requires `MizuTooltipProvider` at the top level to manage shared settings.
3. **Arrow** -- optional arrow shown by default; disable with `:show-arrow="false"`.
4. **Animations** -- content slides and fades in from the trigger; direction-aware animations based on `side` prop.
5. **Class inheritance** -- each sub-component accepts `class` prop via `useAttrs()` for Tailwind overrides.
6. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode.
