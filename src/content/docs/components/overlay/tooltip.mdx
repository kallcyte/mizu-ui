A tooltip provides brief, contextual help text when hovering or focusing an element. Mizu uses Nuxt UI's `UTooltip` with compact dimensions (6px height, 12px font size).

## API

Reference: [Nuxt UI Tooltip](https://ui.nuxt.com/docs/components/tooltip)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | — | Tooltip text content |
| `content` | `{ align, side, alignOffset, sideOffset, collisionPadding }` | — | Popper positioning options |
| `delayDuration` | `number` | `700` | Delay before showing (ms) |
| `disabled` | `boolean` | `false` | Disable tooltip |
| `defaultOpen` | `boolean` | — | Initial open state |
| `open` | `boolean` | — | v-model:open binding for controlled state |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | The trigger element |
| `content` | `{ ui }` | Custom tooltip content (overrides `text` prop) |

### Example Usage

```vue
<UTooltip text="Save changes">
  <UButton icon="i-ph-floppy-disk" />
</UTooltip>

<UTooltip text="Delete" :content="{ placement: 'top' }">
  <UButton color="error" icon="i-ph-trash" />
</UTooltip>
```

## Theme

Nuxt UI v4 tooltip defaults (compact h-6, px-2.5, text-xs, rounded-sm) are standard tooltip dimensions that don't require Mizu-specific adjustments. No overrides are needed.

## Anatomy

A tooltip consists of:

| Part | Required | Description |
|------|----------|-------------|
| Trigger | Yes | The element that reveals the tooltip on hover/focus |
| Content | Yes | The popup text label |

## Implementation Notes

1. **Use `<UTooltip>` directly** "” No Mizu wrapper needed.
2. **Text vs. slot** — Use the `text` prop for simple strings. Use the `content` slot for rich content or custom formatting.
3. **Positioning** "” Use the `content` prop (popper options) to control placement. Default is `top`.
4. **Keyboard accessibility** "” Tooltips are shown on `:focus` as well as `:hover`, meeting WCAG keyboard requirements.
