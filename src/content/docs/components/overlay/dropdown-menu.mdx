A dropdown menu presents a list of actions or options when a trigger button is clicked. Mizu uses Nuxt UI's `UDropdownMenu` with rounded-md panels and compact item sizing.

## Theme

Nuxt UI v4 dropdown menu defaults already use rounded-md panels with well-sized items (xs-xl) and proper leading/trailing icon sizing. No overrides are needed.

## Anatomy

A dropdown menu consists of:

| Part | Required | Description |
|------|----------|-------------|
| Trigger | Yes | Button or element that opens the menu |
| Content | Yes | Floating menu panel with items |
| Item | Yes | Individual action or option |
| Separator | No | Horizontal divider between item groups |
| Submenu | No | Nested child menu triggered by hovering an item |

## Implementation Notes

1. **Use `<UDropdownMenu>` directly** â€” No Mizu wrapper needed.
2. **Items as array** â€” Use the `items` prop for declarative menus. Each item is an object with `label`, `icon`, `color`, etc.
3. **Destructive actions** â€” Set `color: 'error'` on delete/remove items for red styling.
4. **Separators** â€” Add `{ type: 'separator' }` between groups to visually separate item clusters.
5. **Controlled state** â€” Use `v-model:open` for programmatic open/close control.
