A modal is an overlay dialog that focuses the user on a single task or confirmation. Mizu uses Nuxt UI's `<UModal>` directly via theme preset — no Mizu wrapper component is needed.

## Anatomy

A modal consists of up to 7 parts:

| Part | Required | Description |
|------|----------|-------------|
| Overlay | Yes | Semi-transparent backdrop covering the viewport |
| Content | Yes | Centered panel with header, body, and footer |
| Header | Yes | Title, description, and close button area |
| Body | Yes | Scrollable content area |
| Footer | No | Action buttons (save, cancel, etc.) |
| Close Button | No | X button in the header (shown by default) |
| Trigger | No | Element that opens the modal |

## Variants

Modal has no visual variants — it is a single component with behavioral toggles via props:

| Prop | Effect |
|------|--------|
| `fullscreen` | Fills entire viewport, removes border radius |
| `scrollable` | Content scrolls within the overlay |
| `dismissible` | Controls close-on-outside-click / Escape behavior |
| `modal` | When `false`, outside content remains interactive |
| `transition` | Enables or disables enter/leave animations |
| `overlay` | Shows or hides the backdrop |

## Size Specifications

Modal dimensions are defined by Nuxt UI's default theme. The content panel uses `max-w-lg` (512px) in standard mode and `inset-0` in fullscreen mode. No Mizu-specific size tokens apply.

| Token | Usage |

## Spacing Details

The content panel uses Nuxt UI's default padding scale: `p-4` (16px) on mobile, `sm:p-6` (24px) on desktop for header, body, and footer. The header includes a `gap-1.5` (6px) flex layout for title + description.

## Accessibility

### ARIA Attributes

The Modal is built on Reka UI's Dialog primitive, which provides:

| Attribute | Value | Target |
|-----------|-------|--------|
| `role="dialog"` | — | Content panel |
| `aria-modal="true"` | — | Content panel |
| `aria-labelledby` | Auto-linked to title | Content panel |
| `aria-describedby` | Auto-linked to description | Content panel |

### Keyboard Navigation

| Key | Action |
|-----|--------|
| `Escape` | Closes the modal (unless `dismissible` is `false`) |
| `Tab` | Moves focus within the modal (focus trap) |
| `Shift+Tab` | Moves focus backward (focus trap) |
| `Enter` | Activates focused button |

### Focus Management

Focus is automatically trapped inside the modal when open. On close, focus returns to the trigger element. The close button is the first focusable element in the header.

## Vue Component API

Modal uses Nuxt UI's `<UModal>` component directly. The Mizu theme preset overrides the content slot for radius and background tokens.

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | Modal title text |
| `description` | `string` | — | Modal description text |
| `open` | `boolean` | — | Controlled open state (`v-model:open`) |
| `defaultOpen` | `boolean` | — | Initial open state (uncontrolled) |
| `fullscreen` | `boolean` | `false` | Fills entire viewport |
| `scrollable` | `boolean` | `false` | Content scrolls within the overlay |
| `dismissible` | `boolean` | `true` | Allow close on click-outside and Escape |
| `modal` | `boolean` | `true` | Block interaction with outside content |
| `overlay` | `boolean` | `true` | Show backdrop overlay |
| `transition` | `boolean` | `true` | Enable enter/leave animations |
| `close` | `boolean \| ButtonProps` | `true` | Close button configuration or `false` to hide |
| `closeIcon` | `string` | `i-lucide-x` | Close button icon |
| `portal` | `boolean \| string \| HTMLElement` | `true` | Render in a portal |
| `unmountOnHide` | `boolean` | `true` | Unmount content when closed |
| `content` | `DialogContentProps` | — | Reka UI content props passthrough |
| `ui` | `object` | — | Slot class overrides |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Trigger element |
| `content` | — | Full custom content (replaces header/body/footer) |
| `header` | `{ ui }` | Custom header |
| `title` | — | Custom title content |
| `description` | — | Custom description content |
| `body` | `{ ui }` | Scrollable body content |
| `footer` | `{ close }` | Footer for action buttons (exposes `close` callback) |
| `actions` | — | Custom actions area |
| `close` | `{ ui }` | Custom close button |

### Emits

| Event | Payload | Description |
|-------|---------|-------------|
| `update:open` | `boolean` | Emitted when open state changes |
| `close:prevent` | — | Emitted when close is prevented (`dismissible` is `false`) |
| `enter` | — | Enter animation started |
| `after:enter` | — | Enter animation completed |
| `leave` | — | Leave animation started |
| `after:leave` | — | Leave animation completed |

### Example Usage

```vue
<template>
  <UModal v-model:open="open" title="Edit Profile" description="Make changes to your profile.">
    <UButton label="Open" color="neutral" variant="subtle" />

    <template #body>
      <UInput placeholder="Your name" />
    </template>

    <template #footer="{ close }">
      <UButton label="Cancel" variant="outline" @click="close" />
      <UButton label="Save" color="primary" />
    </template>
  </UModal>
</template>

<script setup lang="ts">
const open = ref(false);
</script>
```

## Implementation Notes

1. **Use `<UModal>` directly** — No Mizu wrapper component exists. Import from `@mizu-ui/vue` (re-exports Nuxt UI's `UModal`).
2. **Theme preset** — Mizu overrides: `rounded-md` (6px) content radius, `--color-surface-base` background, `--color-surface-muted` dividers, `bg-black/25` overlay, `justify-end` footer alignment, `z-40`/`z-50` stacking context, and fullscreen content positioning.
3. **Controlled vs. uncontrolled** — Use `v-model:open` for controlled state. Use `defaultOpen` for uncontrolled initial state.
4. **Non-dismissible pattern** — Set `:dismissible="false"` for confirmation dialogs that require an explicit action. A `close:prevent` event fires on attempted close.
5. **Non-modal mode** — Set `:modal="false"` to allow outside interaction. The overlay is automatically disabled.
6. **Scrollable mode** — Requires `overlay` to be `true`. Content gets `overflow-y: auto` within the overlay.
7. **Fullscreen mode** — Uses `fixed inset-0 z-50 rounded-none`. Fills the viewport with no border radius. Suitable for mobile or immersive workflows.
8. **Portal rendering** — By default, the modal is rendered in a portal at the document root. Set `:portal="false"` to render in-place (useful for SSR or SEO).
