An AlertDialog is a modal dialog that interrupts the user to confirm a critical or potentially destructive action. Unlike Dialog, it does not close on outside click and auto-focuses the cancel button for safety.

## Anatomy

An AlertDialog consists of up to 9 parts:

| Part | Required | Description |
|------|----------|-------------|
| AlertDialogRoot | Yes | Controls open state |
| AlertDialogPortal | Yes | Teleports overlay and content to `body` |
| AlertDialogOverlay | Yes | Semi-transparent backdrop |
| AlertDialogContent | Yes | The alert dialog panel with `role="alertdialog"` |
| AlertDialogTitle | Yes | Accessible title linked via `aria-labelledby` |
| AlertDialogDescription | No | Optional description linked via `aria-describedby` |
| AlertDialogAction | Yes | Button that confirms the action and closes the dialog |
| AlertDialogCancel | No | Button that cancels and closes; auto-focused on open |
| AlertDialogTrigger | Yes | Button or element that opens the dialog |

Layout sub-components from Dialog (`MizuDialogHeader`, `MizuDialogBody`, `MizuDialogFooter`) may be reused for structure.

## Composition

```
MizuAlertDialogRoot
  MizuAlertDialogTrigger
  MizuAlertDialogPortal
    MizuAlertDialogOverlay
    MizuAlertDialogContent
      MizuDialogHeader
        MizuAlertDialogTitle
        MizuAlertDialogDescription (optional)
      MizuDialogBody (optional)
        ... (additional content)
      MizuDialogFooter
        MizuAlertDialogCancel
        MizuAlertDialogAction
```

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|---------------|
| Focus trap | Reka UI DialogContentModal traps focus within the dialog |
| Body scroll lock | Reka UI disables background scrolling when open |
| Escape key | Reka UI closes dialog on Escape key press |
| Outside click | Reka UI AlertDialog prevents closing on outside click (safety) |
| ARIA role | Content has `role="alertdialog"` and `aria-modal="true"` |
| ARIA labelling | `aria-labelledby` links to `AlertDialogTitle`; `aria-describedby` links to `AlertDialogDescription` |
| Focus return | Focus returns to the trigger element on close |
| Auto-focus cancel | Cancel button receives initial focus on open for safety |

### ARIA Attributes

```html
<div role="alertdialog" aria-modal="true" aria-labelledby="alert-title" aria-describedby="alert-desc">
  <h2 id="alert-title">Confirm Deletion</h2>
  <p id="alert-desc">This action cannot be undone.</p>
  <button>Cancel</button>
  <button>Delete</button>
</div>
```

### AlertDialogContent Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `forceMount` | `boolean` | `undefined` | Keep content mounted when closed |
| `disableOutsidePointerEvents` | `boolean` | `undefined` | Disable pointer events outside |
| `asChild` | `boolean` | `undefined` | Render as child element |
| `as` | `string` | `undefined` | Custom root element |
| `fullscreen` | `boolean` | `false` | Dialog fills entire viewport — no border, no shadow, inset 0 |
| `dismissible` | `boolean` | `true` | When `false`, prevents close on click-outside / Escape (overrides Reka UI default for safety) |
| `scrollable` | `boolean` | `false` | Content scrolls within the overlay (max-height: 90vh) |
| `transition` | `boolean` | `true` | Enable/disable enter/leave animations |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Dialog width (sm: 400px, md: 500px, lg: 700px, xl: 900px) |

### AlertDialogContent Events

| Event | Payload | Description |
|-------|---------|-------------|
| `escapeKeyDown` | `KeyboardEvent` | Escape key pressed |
| `pointerDownOutside` | `PointerEvent` | Click outside content — fires only when `dismissible` is `true` |
| `focusOutside` | `FocusEvent` | Focus leaves content |
| `interactOutside` | `Event` | Interaction outside content — fires only when `dismissible` is `true` |
| `openAutoFocus` | `Event` | Auto-focus on open |
| `closeAutoFocus` | `Event` | Auto-focus on close |

When `dismissible` is `false`, `pointerDownOutside` and `interactOutside` events are prevented (same as Reka UI AlertDialog default behavior). When `dismissible` is `true`, these events fire and the dialog will close on click-outside.

### Example Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import {
  MizuAlertDialogRoot,
  MizuAlertDialogPortal,
  MizuAlertDialogOverlay,
  MizuAlertDialogContent,
  MizuAlertDialogTitle,
  MizuAlertDialogDescription,
  MizuAlertDialogAction,
  MizuAlertDialogCancel,
  MizuAlertDialogTrigger,
  MizuDialogHeader,
  MizuDialogBody,
  MizuDialogFooter,
  MizuButton,
} from "@mizu/vue";

const open = ref(false);
</script>

<template>
  <MizuAlertDialogRoot v-model:open="open">
    <MizuAlertDialogTrigger as-child>
      <MizuButton variant="accent" size="md" class="w-max">Delete Invoice</MizuButton>
    </MizuAlertDialogTrigger>
    <MizuAlertDialogPortal>
      <MizuAlertDialogOverlay />
      <MizuAlertDialogContent>
        <MizuDialogHeader>
          <MizuAlertDialogTitle>Confirm Deletion</MizuAlertDialogTitle>
          <MizuAlertDialogDescription>
            Are you sure you want to delete this invoice? This action cannot be undone.
          </MizuAlertDialogDescription>
        </MizuDialogHeader>
        <MizuDialogBody>
          <p>Additional context or warning details.</p>
        </MizuDialogBody>
        <MizuDialogFooter>
          <MizuAlertDialogCancel as-child>
            <MizuButton variant="ghost" size="md" class="w-max">Cancel</MizuButton>
          </MizuAlertDialogCancel>
          <MizuAlertDialogAction as-child>
            <MizuButton variant="accent" size="md" class="w-max">Delete</MizuButton>
          </MizuAlertDialogAction>
        </MizuDialogFooter>
      </MizuAlertDialogContent>
    </MizuAlertDialogPortal>
  </MizuAlertDialogRoot>
</template>
```

## Implementation Notes

1. **`dismissible` control** — Defaults to `true` (consistent with MizuDialogContent). Set `dismissible` to `false` to prevent Escape/click-outside dismiss. When `false`, `pointerDownOutside` and `escapeKeyDown` events are prevented.
2. **Cancel receives initial focus** — Reka UI AlertDialogContent auto-focuses the cancel button on open as a safety measure, ensuring the user must actively move to the confirm action.
3. **Always modal** — Unlike `MizuDialogRoot`, `MizuAlertDialogRoot` has no `modal` prop and is always modal.
4. **Use `as-child` on Action and Cancel** — Both `MizuAlertDialogAction` and `MizuAlertDialogCancel` accept `as-child` for composition with `MizuButton`. Use `as-child` to apply MizuButton styling while keeping the Reka UI dialog-closing behavior.
5. **Reuse Dialog layout components** — `MizuDialogHeader`, `MizuDialogBody`, and `MizuDialogFooter` work identically as structural wrappers for AlertDialog content.
6. **`fullscreen` mode** — When `fullscreen` is `true`, the alert dialog fills the viewport with `inset: 0`, no border-radius, and no box-shadow.
7. **`scrollable` mode** — When `scrollable` is `true`, the content area gets `overflow-y: auto` and `max-height: 90vh`.
8. **`transition` toggle** — Set `transition` to `false` to disable enter/leave animations. Useful for reduced-motion preferences.
9. **`size` prop** — Control dialog width via `size` (`sm`: 400px, `md`: 500px, `lg`: 700px, `xl`: 900px). Default is `md`.
