A badge is a small, compact indicator used to display counts, statuses, or short labels. It can render as a dot for presence indicators, a number for notification counts, or inline text for status labels. Badges are typically positioned relative to another element (such as an avatar or button) using the `position` prop.

## Anatomy

A badge consists of up to 2 parts:

| Part | Required | Description |
|------|----------|-------------|
| Container | Yes | The badge's background and shape |
| Content | No | Count, text, or dot indicator |

## Variants

Mizu badges support 6 visual variants. All variants use a solid fill with inverse text for high contrast against their background.

| Variant | Background | Text Color | Use Case |
|---------|------------|------------|----------|
| **Primary** | `brand-primary` | `foreground-inverse` | Brand emphasis, primary notifications |
| **Accent** | `brand-accent` | `foreground-inverse` | Interactive highlights, new items |
| **Success** | `feedback-success-base` | `foreground-inverse` | Online status, completed items |
| **Warning** | `feedback-warning-base` | `foreground-inverse` | Pending items, warnings |
| **Error** | `feedback-error-base` | `foreground-inverse` | Error counts, critical alerts |
| **Info** | `feedback-info-base` | `foreground-inverse` | Informational counts, neutral status |

### Positioned Badge Layout

When using `position`, the badge is absolutely positioned relative to its parent container. The parent must have `position: relative`.

```
┌─────────────────────────┐
│                    ┌──┐ │
│                    │5 │ │  ← top-right
│                    └──┘ │
│                         │
└─────────────────────────┘
```

| Position | Top | Right | Bottom | Left | Transform |
|----------|-----|-------|--------|------|-----------|
| `top-right` | 0 | 0 | — | — | `translate(50%, -50%)` |
| `top-left` | 0 | — | — | 0 | `translate(-50%, -50%)` |
| `bottom-right` | — | 0 | 0 | — | `translate(50%, 50%)` |
| `bottom-left` | — | — | 0 | 0 | `translate(-50%, 50%)` |

## Count Overflow

When the `count` prop exceeds the `max` value (default: 99), the badge displays `{max}+`. When `count` is `0` and `showZero` is `false` (default), the badge is hidden.

| `count` | `max` | `showZero` | Display |
|---------|-------|------------|---------|
| 0 | 99 | false | Hidden |
| 0 | 99 | true | `0` |
| 5 | 99 | — | `5` |
| 99 | 99 | — | `99` |
| 100 | 99 | — | `99+` |
| 1500 | 999 | — | `999+` |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Color Contrast | 4.5:1 for count/text content against solid background |
| Screen Reader | `role="status"` on the badge element |
| Non-interactive | Badge is a `<span>`, not focusable; decorative when positioned |
| Semantic | Count content is announced by screen readers via `role="status"` |

### ARIA Attributes

```html
<span class="mizu-badge mizu-badge--error mizu-badge--md" role="status">5</span>

<!-- Dot mode -->
<span class="mizu-badge mizu-badge--success mizu-badge--sm mizu-badge--dot" role="status"></span>
```

## Vue Component API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'error'` | Visual variant |
| `size` | `'sm' \| 'md'` | `'md'` | Badge size |
| `dot` | `boolean` | `false` | Render as a dot indicator (ignores content) |
| `count` | `number` | `undefined` | Numeric count to display |
| `max` | `number` | `99` | Maximum count before overflow (`{max}+`) |
| `showZero` | `boolean` | `false` | Show badge when count is 0 |
| `position` | `'inline' \| 'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'inline'` | Absolute positioning relative to parent |

### Slots

| Slot | Description |
|------|-------------|
| `default` | Custom text content (ignored when `dot` or `count` is set) |

### Example Usage

```vue
<!-- Count badge -->
<MizuBadge :count="5" />

<!-- Dot indicator -->
<MizuBadge dot variant="success" />

<!-- Positioned on avatar -->
<div style="position: relative; display: inline-flex;">
  <MizuAvatar name="Jane Doe" size="lg" />
  <MizuBadge :count="3" variant="error" position="top-right" />
</div>

<!-- Text content -->
<MizuBadge variant="accent">New</MizuBadge>

<!-- Custom max overflow -->
<MizuBadge :count="1500" :max="999" />  <!-- 999+ -->

<!-- Show zero -->
<MizuBadge :count="0" show-zero />

<!-- Small dot for presence -->
<MizuBadge dot variant="success" size="sm" />
```

## Implementation Notes

1. **Native `<span>` element** — No Reka UI primitive needed; the badge is a lightweight inline indicator
2. **Solid fill** — Unlike Tag (which uses subtle backgrounds), Badge uses solid backgrounds with inverse text for maximum contrast at small sizes
3. **Positioning** — The `position` prop applies `position: absolute` with `transform` for centering; the parent container must have `position: relative`
4. **Count formatting** — When `count` exceeds `max`, displays `{max}+`; when `count` is 0 and `showZero` is false, the badge is hidden entirely
5. **Dot mode** — Renders as a small circle (8px sm, 10px md) with no content; useful for presence/status indicators
6. **Slot fallback** — When neither `dot` nor `count` is provided, the default slot is rendered for custom text content
7. **Tabular nums** — Uses `font-variant-numeric: tabular-nums` for consistent digit width in counts
8. **Tailwind `@apply`** — Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
9. **CSS Custom Properties** — Colors are resolved at runtime via CSS custom properties
10. **Self-contained CSS** — Tailwind utilities are bundled into `dist/index.css` via `@tailwindcss/vite`; consumers do not need Tailwind installed
11. **Class inheritance** — Accept `class` prop for overrides via `useAttrs()`
12. **TypeScript** — Full type safety with `<script setup lang="ts">`
13. **Tree-shakeable** — Export as ESM + CJS via Vite library mode
