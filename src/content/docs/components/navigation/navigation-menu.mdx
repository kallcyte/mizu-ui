> **Nuxt UI Component:** This uses Nuxt UI's `UNavigationMenu` component. Nuxt UI v4 defaults already match the Mizu design scale, so no sizing overrides are applied.

NavigationMenu renders a list of links with support for nested sub-items, tooltips, and popover expansion. Mizu uses Nuxt UI's `UNavigationMenu` with pill variant links and horizontal orientation for top-level navigation.

### Example Usage

```vue
<UNavigationMenu :items="[
  { label: 'Home', to: '/' },
  { label: 'Products', children: [
    { label: 'Software', to: '/products/software' },
    { label: 'Hardware', to: '/products/hardware' },
  ]},
  { label: 'About', to: '/about' },
]" />
```

## Anatomy

A NavigationMenu consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<nav>` wrapper containing the menu items |
| Item | Yes | Each top-level navigation item |
| Sub-item | No | Nested items within a parent, shown on expand |
| Label | Yes | Display text for each item |
| Icon | No | Optional leading or trailing icon per item |

## Implementation Notes

1. **Use `<UNavigationMenu>` directly** — No Mizu wrapper needed.
2. **Items structure** — Items accept `label`, `to`/`href`, `icon`, and `children` (nested sub-items). Use `children` for dropdowns.
3. **Orientation** — Use `orientation="vertical"` for sidebar navigation. Default `horizontal` is for top navigation bars.
4. **Selection** — Set `type="multiple"` to allow expanding multiple sub-menus simultaneously. Default `single` collapses others on open.
5. **Popovers** — Set `popover` on nested items to display children in a floating panel instead of inline expansion.
