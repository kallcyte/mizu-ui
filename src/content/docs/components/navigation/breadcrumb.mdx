Breadcrumbs show the user's location within a site hierarchy and provide navigation links back to ancestor pages. Mizu uses Nuxt UI's `UBreadcrumb` with text-sm links and size-5 separator icons.

## API

Reference: [Nuxt UI Breadcrumb](https://ui.nuxt.com/docs/components/breadcrumb)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `string` | `'nav'` | Element or component to render as |
| `items` | `BreadcrumbItem[]` | — | Breadcrumb trail items |
| `separatorIcon` | `string` (Iconify) | `i-lucide-chevron-right` | Separator icon between items |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'error' \| 'neutral'` | `'primary'` | Color for the current (last) item |
| `labelKey` | `string` | `'label'` | Key used to get the label from each item |
| `ui` | `object` | — | Slot-level class overrides (root, list, item, link, separator, etc.) |

### BreadcrumbItem

| Prop | Type | Description |
|------|------|-------------|
| `label` | `string` | Display text |
| `icon` | `string` (Iconify) | Leading icon |
| `avatar` | `AvatarProps` | Leading avatar |
| `slot` | `string` | Named slot key for custom content |
| `to` | `string` | Vue Router route |
| `href` | `string` | External link |
| `target` | `string` | Link target (e.g. `_blank`) |
| `class` | `string` | Additional CSS classes on the item |
| `ui` | `object` | Per-item slot class overrides |

Items without `to` or `href` are rendered as a `<span>` and treated as the current page (active).

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `{{ item.slot }}` | `{ item, index, active, ui }` | Custom content for a specific item (via its `slot` key) |
| `{{ item.slot }}-leading` | `{ item, index, active, ui }` | Custom leading content for a specific item |
| `{{ item.slot }}-label` | `{ item, index, active }` | Custom label for a specific item |
| `{{ item.slot }}-trailing` | `{ item, index, active }` | Custom trailing content for a specific item |
| `item` | `{ item, index, active, ui }` | Custom content for all items |
| `item-leading` | `{ item, index, active, ui }` | Custom leading content for all items |
| `item-label` | `{ item, index, active }` | Custom label for all items |
| `item-trailing` | `{ item, index, active }` | Custom trailing content for all items |
| `separator` | `{ ui }` | Custom separator between all items |

### Example Usage

```vue
<UBreadcrumb :items="[
  { label: 'Home', icon: 'i-lucide-book-open', to: '/' },
  { label: 'Docs', icon: 'i-lucide-box', to: '/docs' },
  { label: 'Components' }
]" />
```

## Theme

Nuxt UI v4 breadcrumb defaults (text-sm links, size-5 separator icons) are already consistent with Mizu. No overrides are needed.

Default: `color="primary"`.

## Anatomy

A breadcrumb consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<nav>` wrapper with role="navigation" |
| Item | Yes | Link or span for each breadcrumb step |
| Separator | Yes | Chevron or slash between items |
| Current | Yes | Last item (non-clickable, shows current page) |

## Implementation Notes

1. **Use `<UBreadcrumb>` directly** "” No Mizu wrapper needed.
2. **Links vs. current** "” The last item in the items array is automatically rendered as a non-clickable current page indicator. All preceding items are links.
3. **Accessibility** "” Nuxt UI renders the breadcrumb inside a `<nav>` with `aria-label="Breadcrumb"`. The last item gets `aria-current="page"`.
4. **Custom separators** — Use the `separatorIcon` prop to change the icon (e.g. `'i-ph-arrow-right'` for arrow separators) or the `#separator` slot for completely custom separators.
