> **Nuxt UI Component:** This uses Nuxt UI's `UBreadcrumb` component. Nuxt UI v4 defaults already match the Mizu design scale, so no sizing overrides are applied.

Breadcrumbs show the user's location within a site hierarchy and provide navigation links back to ancestor pages. Mizu uses Nuxt UI's `UBreadcrumb` with text-sm links and size-5 separator icons.

| Prop | Type | Default | Description |

### Example Usage

```vue

```

## Theme

Nuxt UI v4 breadcrumb defaults (text-sm links, size-5 separator icons) are already consistent with Mizu. No overrides are needed.

Default: `color="primary"`.

## Anatomy

A breadcrumb consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<nav>` wrapper with role="navigation" |
| Item | Yes | Link or span for each breadcrumb step |
| Separator | Yes | Chevron or slash between items |
| Current | Yes | Last item (non-clickable, shows current page) |

## Implementation Notes

1. **Use `<UBreadcrumb>` directly** â€” No Mizu wrapper needed.
2. **Links vs. current** â€” The last item in the items array is automatically rendered as a non-clickable current page indicator. All preceding items are links.
3. **Accessibility** â€” Nuxt UI renders the breadcrumb inside a `<nav>` with `aria-label="Breadcrumb"`. The last item gets `aria-current="page"`.
4. **Custom separators** â€” Use the `separator` prop to change the icon (e.g. `'i-ph-slash'` for `/` separators).
