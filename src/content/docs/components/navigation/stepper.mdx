Stepper provides a visual indicator of progress through a sequence of steps, commonly used in multi-step forms, onboarding flows, or checkout processes. Mizu uses Nuxt UI's `UStepper` with linear progression enabled by default.

## API

Reference: [Nuxt UI Stepper](https://ui.nuxt.com/docs/components/stepper)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `StepperItem[]` | — | Step items array |
| `modelValue` (`v-model`) | `string \| number` | — | Active step value (controlled); falls back to the index |
| `defaultValue` | `string \| number` | — | Active step value when uncontrolled |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'error' \| 'neutral'` | `'primary'` | Color of active/completed indicators and separator |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Step indicator and label size |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction |
| `linear` | `boolean` | `true` | Require steps to be completed in order |
| `disabled` | `boolean` | `false` | Disable the stepper |
| `valueKey` | `string` | `'value'` | Key used to match items when `v-model` / `defaultValue` is provided |
| `as` | `any` | `'div'` | Element or component to render as |
| `ui` | `object` | — | Slot class overrides (root, header, item, container, trigger, indicator, icon, separator, wrapper, title, description, content) |

### StepperItem

| Field | Type | Description |
|-------|------|-------------|
| `title` | `string` | Step title text |
| `description` | `string` | Step description text |
| `icon` | `string` | Icon class (e.g. `i-lucide-house`) |
| `content` | `string` | Inline content rendered for the active step |
| `value` | `string \| number` | Unique value used to identify the step |
| `disabled` | `boolean` | Disable this individual step |
| `slot` | `string` | Render a named slot instead of default content |
| `class` | `any` | Extra class on the step item |
| `ui` | `object` | Per-item slot class overrides |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `indicator` | `{ item, ui }` | Replace the step indicator (number/icon) |
| `wrapper` | `{ item }` | Wrapper around each step's label area |
| `title` | `{ item }` | Custom step title content |
| `description` | `{ item }` | Custom step description content |
| `content` | `{ item }` | Active step content panel (use `item.content` for the inline value, or provide a full custom layout) |
| `#{{ item.slot }}` | — | Rendered when an item has a matching `slot` name |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `[value: string \| number \| undefined]` | Emitted when the active step changes |
| `next` | `[value: T]` | Emitted when `next()` is called |
| `prev` | `[value: T]` | Emitted when `prev()` is called |

### Expose

Access via `useTemplateRef` (or `ref`).

| Name | Type | Description |
|------|------|-------------|
| `next` | `() => void` | Advance to the next step (no-op at end) |
| `prev` | `() => void` | Go to the previous step (no-op at start) |
| `hasNext` | `Ref<boolean>` | `true` when there is a next step |
| `hasPrev` | `Ref<boolean>` | `true` when there is a previous step |

### Example Usage

```vue
<script setup lang="ts">
import { useTemplateRef, ref } from "vue";
import type { StepperItem } from "@nuxt/ui";

const items: StepperItem[] = [
  { title: "Address", description: "Add your address here", icon: "i-lucide-house" },
  { title: "Shipping", description: "Set your preferred shipping method", icon: "i-lucide-truck" },
  { title: "Checkout", description: "Confirm your order", icon: "i-lucide-credit-card" },
];

const stepper = useTemplateRef("stepper");
const active = ref(0);
</script>

<template>
  <UStepper ref="stepper" v-model="active" :items="items" class="w-full">
    <template #content="{ item }">
      <div class="aspect-video flex items-center justify-center border border-dashed border-surface-muted rounded-md">
        This is the {{ item?.title }} step.
      </div>
    </template>
  </UStepper>

  <div class="flex gap-2 justify-between mt-4">
    <UButton
      leading-icon="i-lucide-arrow-left"
      :disabled="!stepper?.hasPrev"
      @click="stepper?.prev()"
    >Prev</UButton>
    <UButton
      trailing-icon="i-lucide-arrow-right"
      :disabled="!stepper?.hasNext"
      @click="stepper?.next()"
    >Next</UButton>
  </div>
</template>
```

## Anatomy

A Stepper consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<div>` wrapper containing header + content |
| Header | Yes | List of step indicators + connectors |
| Step | Yes | Individual step with indicator + label |
| Indicator | Yes | Number or icon inside the step circle |
| Separator | Yes | Line connecting consecutive steps |
| Title | No | Heading text for the step |
| Description | No | Supporting text below the title |
| Content | No | Panel for the active step (`item.content` or `#content` slot) |

## Theme

Nuxt UI v4 stepper defaults are already consistent with Mizu: rounded-full triggers, xs–xl sizing that matches Button/Input, color tokens aligned with the rest of the system. No overrides are needed for the default Mizu palette.

Default: `color="primary"`, `size="md"`, `orientation="horizontal"`, `linear="true"`.

## Implementation Notes

1. **Use `<UStepper>` directly** — No Mizu wrapper needed.
2. **`v-model` not `v-model:step`** — Nuxt UI v4 binds the active value to `modelValue`; use `v-model="active"` (or `v-model:modelValue`).
3. **Linear mode** — Default `linear` ensures users complete steps in order. Set `:linear="false"` for non-sequential navigation.
4. **Item fields** — Prefer the canonical `value` field on each item and match it via `v-model` / `defaultValue`. The component falls back to the index when no `value` is set.
5. **Content rendering** — Three options, in order of preference: (a) inline `content` on the item, (b) the `#content="{ item }"` slot for shared layouts, (c) the `slot: '…'` item field + matching named slot for fully per-step content.
6. **Programmatic navigation** — Use `useTemplateRef` (or `ref`) to access `next()`, `prev()`, `hasNext`, `hasPrev` for custom controls.
7. **Vertical orientation** — Set `orientation="vertical"` for sidebar-style progress. The connector becomes a vertical line between steps.
8. **Disabled steps** — Per-item `disabled: true` blocks that step; the root `disabled` prop disables the entire stepper (useful for read-only states).
