Pagination provides controls for navigating between pages of content. Mizu uses Nuxt UI's `UPagination` with the default button scale (32px height pages).

## API

Reference: [Nuxt UI Pagination](https://ui.nuxt.com/docs/components/pagination)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `total` | `number` | — | Total number of items |
| `pageSize` | `number` | `10` | Items per page |
| `max` | `number` | `7` | Maximum number of visible page buttons |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Button size |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'primary'` | Active page color |
| `variant` | `'outline' \| 'soft' \| 'subtle' \| 'ghost' \| 'none'` | `'outline'` | Visual style |
| `disabled` | `boolean` | `false` | Disable pagination |
| `defaultPage` | `number` | `1` | Initial page (uncontrolled) |
| `modelValue` | `number` | — | v-model binding for current page |
| `showControls` | `boolean` | `true` | Show prev/next buttons |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Entire pagination (overrides default rendering) |

### Example Usage

```vue
<UPagination v-model:page="page" :total="100" :page-size="10" />

<UPagination v-model:page="page" :total="500" :page-size="20" :max="5" />
```

## Theme

Nuxt UI v4 pagination defaults (slot-based composition with button primitives) are already consistent with Mizu. No sizing variants needed — pagination inherits from the button/input scale.

Default: `color="primary"`, `size="md"`.

## Anatomy

Pagination consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<nav>` wrapper with page buttons |
| Prev | Yes | Previous page navigation button |
| Page Button | Yes | Individual numbered page button |
| Ellipsis | No | "..." indicator for collapsed page range |
| Next | Yes | Next page navigation button |
| Active Page | Yes | Currently selected page (different visual state) |

## Implementation Notes

1. **Use `<UPagination>` directly** — No Mizu wrapper needed.
2. **Total and pageSize** — Pass `total` (item count) and `pageSize` (items per page). Nuxt UI calculates total pages automatically.
3. **Max visible pages** — Use `max` to control how many page buttons are shown before collapsing with ellipsis.
4. **Controlled state** — Use `v-model:page` for controlled pagination. Use `defaultPage` for uncontrolled.
5. **Hiding controls** — Set `showControls` to `false` to hide prev/next arrows, showing only page number buttons.
