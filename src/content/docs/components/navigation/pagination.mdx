A pagination component displays data in paged format and provides navigation between pages. Use it for tables, lists, or any content that spans multiple pages.

## Examples

<PaginationDemo client:only="vue" />

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `page` | `number` | required | Current page (v-model:page) |
| `total` | `number` | required | Total number of pages |
| `siblingCount` | `number` | `1` | Number of sibling pages to show |
| `showEdges` | `boolean` | `false` | Show first/last page buttons |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size variant |

### Slots

None. Pagination renders page buttons from the `page` and `total` props.

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:page` | `number` | Emitted when page changes |

### Example Usage

```vue
<script setup>
import { ref } from "vue";
import { MizuPagination } from "@mizu/vue";

const page = ref(1);
</script>

<template>
  <!-- Basic -->
  <MizuPagination v-model:page="page" :total="10" />

  <!-- With edges and more siblings -->
  <MizuPagination
    v-model:page="page"
    :total="100"
    :sibling-count="2"
    :show-edges="true"
    size="lg"
  />
</template>
```

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Navigation landmark | `<nav>` wrapper with `aria-label="Pagination"` |
| Current page | Page buttons use `data-selected="true"` attribute |
| Keyboard | Tab to navigate between buttons, Enter/Space to activate |
| Disabled state | Previous/Next buttons disabled at boundaries |

```html
<nav aria-label="Pagination">
  <ul>
    <li><button type="button" aria-label="Previous page">...</button></li>
    <li><button type="button" data-selected="true">1</button></li>
    <li><button type="button">2</button></li>
    <li><button type="button">3</button></li>
    <li><button type="button" aria-label="Next page">...</button></li>
  </ul>
</nav>
```

## Anatomy

A pagination consists of five parts:

| Part | Required | Description |
|------|----------|-------------|
| Previous | Yes | Button to navigate to the previous page |
| Page List | Yes | Numbered page buttons |
| Next | Yes | Button to navigate to the next page |
| First | No | Button to navigate to the first page |
| Last | No | Button to navigate to the last page |

## Implementation Notes

1. **Reka UI primitive** -- wraps `PaginationRoot`, `PaginationList`, `PaginationListItem`, `PaginationEllipsis`, `PaginationFirst`, `PaginationPrev`, `PaginationNext`, `PaginationLast` for full accessibility.
2. **Controlled component** -- uses `v-model:page` for two-way binding; emits `update:page` on navigation.
3. **Class inheritance** -- accepts `class` prop via `useAttrs()` for Tailwind overrides.
4. **Token-based colors** -- button backgrounds, text, and borders use CSS custom properties for automatic light/dark theme support.
5. **Tree-shakeable** -- exported as ESM + CJS via Vite library mode.
