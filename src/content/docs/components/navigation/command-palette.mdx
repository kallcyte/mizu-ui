> **Nuxt UI Component:** This uses Nuxt UI's `UCommandPalette` component. Nuxt UI v4 defaults already match the Mizu design scale, so no sizing overrides are applied.

CommandPalette provides an accessible, keyboard-driven search interface with fuzzy matching via Fuse.js. Mizu uses Nuxt UI's `UCommandPalette` for quick actions, page navigation, and command menus.

### Example Usage

```vue
<UCommandPalette
  :groups="[
    {
      key: 'actions',
      label: 'Actions',
      items: [
        { id: 'new', label: 'New File' },
        { id: 'search', label: 'Search' },
      ],
    },
    {
      key: 'files',
      label: 'Recent Files',
      items: [
        { id: 'readme', label: 'README.md' },
        { id: 'config', label: 'config.ts' },
      ],
    },
  ]"
  @update:model-value="handleSelect"
/>
```

## Anatomy

A CommandPalette consists of:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | Container wrapping search input + results |
| Input | Yes | Search field for fuzzy filtering |
| Group | No | Logical grouping of items with a heading |
| Item | Yes | Each searchable/selectable result |
| Icon | No | Optional icon for each item |
| Description | No | Secondary text (e.g. path, shortcut) |

## Implementation Notes

1. **Use `<UCommandPalette>` directly** — No Mizu wrapper needed.
2. **Fuse.js** — Search is powered by Fuse.js for fuzzy matching. Pass options via the `fuse` prop to tune search behavior (threshold, distance, keys, etc.).
3. **Selection** — Listen to `@update:model-value` to handle selection events. With `multiple` enabled, the value is an array.
4. **Loading** — Use the `loading` prop to show a loading spinner while fetching items asynchronously.
5. **Virtualization** — Enable `virtualize` for large datasets to improve scroll performance.
