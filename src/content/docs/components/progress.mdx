A progress bar visualizes completion of a task or process. Use it for file uploads, loading sequences, multi-step forms, and skill or quota meters.

## Demo

<ProgressDemo client:load />

## Anatomy

A progress bar consists of 2 parts:

| Part | Required | Description |
|------|----------|-------------|
| Track | Yes | The full-width background rail (`surface-muted`) |
| Indicator | Yes | The filled portion whose width represents progress |
| Label | No | Optional percentage or descriptive text (rendered inline beside the track) |

## Variants

Mizu progress supports 6 color variants aligned with the brand and feedback palette:

| Variant | Use Case |
|---------|----------|
| **Primary** (default) | General progress, neutral tasks, file uploads |
| **Accent** | Highlighted progress, primary metric tracking |
| **Success** | Positive progress, completed milestones |
| **Warning** | Approaching limits, quota nearing capacity |
| **Error** | Critical failures, blocked progress |
| **Info** | Informational progress, downloads, syncs |

### Primary Progress
```
Track:      bg-surface-muted
Indicator:  bg-brand-primary
```

### Accent Progress
```
Track:      bg-surface-muted
Indicator:  bg-brand-accent
```

### Success / Warning / Error / Info Progress
```
Track:      bg-surface-muted
Indicator:  bg-feedback-{type}-base
```

## Size Specifications

| Size | Track Height | Use Case |
|------|--------------|----------|
| `sm` | 4px | Inline meters, compact lists, subtle indicators |
| `md` (default) | 8px | Standard forms, upload dialogs, general use |
| `lg` | 12px | Featured progress, dashboard hero metrics |

## Shape

| Property | Value | Notes |
|----------|-------|-------|
| Border radius | `--radius-full` (9999px) | Pill-shaped track and indicator |
| Track width | `100%` of parent | Fluid by default; `inline-flex` allows intrinsic width |

### State Map

| State | Trigger | Visual |
|-------|---------|--------|
| **Loading** | `0 <= value < max` | Indicator width = `(value / max) * 100%` |
| **Complete** | `value === max` | Indicator fills track; auto-colored to `feedback-success-base` |
| **Indeterminate** | `value === null` | Indicator pulses across track on a 1.4s loop |

## Spacing Details

### Inline Layout

```
[Track fills parent width]   [Label]
[←——— 100% ———→]               [32px]
       ↑                          ↑
   track padding: 0          label gap: 8px
```

| Element | Value |
|---------|-------|
| Wrapper gap (track → label) | 8px |
| Label min-width | 32px (md), 28px (sm), 36px (lg) |
| Wrapper default width | 100% of parent |

### Vertical Stacking

```
[Section header]
       ↓ 12px
[Progress bar(s)]
       ↓ 12px
[Next section]
```

When stacking multiple progress bars in a list, use 8px vertical gap between bars.

## Transitions

| Property | Duration | Easing | Trigger |
|----------|----------|--------|---------|
| Indicator transform | `duration-normal` (300ms) | ease-in-out | `value` prop change |
| Indeterminate animation | 1.4s | ease-in-out (loop) | `value === null` |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Screen Reader | `role="progressbar"` on the root (via Reka UI); `aria-valuenow`, `aria-valuemin` (0), `aria-valuemax` (max prop) |
| Value Label | `aria-valuetext` available via `getValueText` prop; default reads as a percentage (e.g. "67%") |
| Indeterminate | `aria-valuenow` omitted when `value` is `null` |
| Color Contrast | All indicator colors meet WCAG AA on the `surface-muted` track |
| Decorative Label | The visible label is `aria-hidden`; the accessible name comes from the role+value attrs |

### ARIA Attributes

```html
<!-- Determinate -->
<div role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-valuenow="67" aria-label="67%">
  <div style="transform: translateX(-33%)"></div>
</div>

<!-- Indeterminate -->
<div role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-label="Loading">
  <div data-state="indeterminate"></div>
</div>

<!-- Complete -->
<div role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-valuenow="100" aria-label="100%">
  <div data-state="complete" style="transform: translateX(0)"></div>
</div>
```

## Vue Component API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `number \| null` | `0` | Progress value; `null` triggers indeterminate state |
| `max` | `number` | `100` | Maximum progress value |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Track height |
| `variant` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'primary'` | Indicator color |
| `showLabel` | `boolean` | `false` | Show percentage or `label` text inline |
| `label` | `string` | `undefined` | Custom label text; overrides the percentage when provided |
| `getValueText` | `(value, max) => string` | `undefined` | Custom accessible value text formatter (passed to Reka UI) |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `number \| null` | Emitted when the model value changes (for v-model support) |

### Example Usage

```vue
<template>
  <!-- Determinate progress -->
  <MizuProgress :model-value="50" />

  <!-- With percentage label -->
  <MizuProgress :model-value="67" show-label />

  <!-- Custom label text -->
  <MizuProgress
    :model-value="42"
    :max="100"
    :label="`${42} GB of 100 GB used`"
    show-label
    variant="warning"
    size="lg"
  />

  <!-- Indeterminate (loading) -->
  <MizuProgress :model-value="null" variant="accent" />

  <!-- Custom max -->
  <MizuProgress :model-value="7" :max="10" variant="success" show-label />

  <!-- Variants -->
  <MizuProgress :model-value="60" variant="primary" />
  <MizuProgress :model-value="60" variant="accent" />
  <MizuProgress :model-value="60" variant="success" />
  <MizuProgress :model-value="60" variant="warning" />
  <MizuProgress :model-value="60" variant="error" />
  <MizuProgress :model-value="60" variant="info" />
</template>
```

## Implementation Notes

1. **Reka UI primitive** - Built on `ProgressRoot` + `ProgressIndicator`; provides `role="progressbar"`, `aria-valuenow`/`min`/`max`, and `data-state` for styling
2. **Transform-based fill** - Indicator uses `translateX(-{100 - percent}%)` instead of `width: %` to keep the indicator at 100% width and animate without layout shifts
3. **Indeterminate animation** - Indicator switches to `position: absolute; left: 0; width: 30%` and animates `left` from `-30%` to `100%` on a 1.4s infinite loop
4. **Complete state override** - When `value === max`, the indicator's color is overridden to `feedback-success-base` regardless of `variant`, signaling completion
5. **Tailwind `@apply`** - Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
6. **Class inheritance** - Accept `class` prop for overrides via `useAttrs()`; merged into the `ProgressRoot` class list
7. **v-model support** - `defineEmits<{ "update:modelValue": [...] }>()` enables `v-model:modelValue` two-way binding
8. **Tree-shakeable** - Export as ESM + CJS via Vite library mode; consumers import only the components they use
9. **TypeScript** - Full type safety with `<script setup lang="ts">`; `ProgressProps` interface exported for consumers
10. **Duration token** - Indicator transition uses `var(--duration-normal, 300ms)` with a fallback in case the token is missing in a consumer's stylesheet
