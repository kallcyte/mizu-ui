A banner displays a prominent announcement at the top of the page, ideal for important messages, alerts, or calls to action. Mizu uses Nuxt UI's `UBanner` with dismiss persistence and action support.

## Anatomy

A banner consists of a single horizontal bar:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<div>` container spanning full width |
| Left | No | Leading slot + icon |
| Center | Yes | Title text or slot |
| Right | No | Actions + close button |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Color is not the only signal | Always pair a colored banner with a leading `icon` or descriptive `title`. Users with color blindness need a non-color cue |
| Dismissal persistence | When `close` is set, also provide an `id` prop so the dismiss state persists across page reloads via `localStorage` |
| Keyboard dismissal | The close button is rendered through `<UButton>` and inherits its keyboard activation (`Enter` / `Space`) |
| Touch target | The close button meets the 44×44 minimum touch target via `<UButton>` defaults |
| Link semantics | When `to` is set, the banner is wrapped in `<ULink>` with `aria-label` set to `title`, exposing a single accessible name for the whole bar |

<div role="region" aria-label="Announcement">

## Vue Component API

Reference: [Nuxt UI Banner](https://ui.nuxt.com/docs/components/banner)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `any` (HTMLElement or component) | `'div'` | Element or component the banner root should render as |
| `id` | `string` | — | Unique ID for `localStorage` dismiss persistence |
| `icon` | `string` (Iconify) | — | Icon displayed next to the title |
| `title` | `string` | — | Banner message text |
| `actions` | `ButtonProps[]` | — | Array of action button configs (default `color="neutral"`, `size="xs"`) |
| `to` | `string` | — | Makes the banner a clickable link (`<ULink>`) |
| `target` | `'_blank' \| '_parent' \| '_self' \| '_top'` | — | Link target when `to` is set |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'error' \| 'neutral'` | `'primary'` | Semantic color |
| `close` | `boolean \| ButtonProps` | — | Show a dismiss close button |
| `closeIcon` | `string` (Iconify) | `'i-lucide-x'` | Custom icon for the close button |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `leading` | `{ ui }` | Custom leading content (overrides `icon`) |
| `title` | — | Custom title content (overrides `title` prop) |
| `actions` | — | Custom actions content (overrides `actions` prop) |
| `close` | — | Custom close button content (overrides `close` button) |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `close` | — | Emitted when the user dismisses the banner via the close button. If `id` is set, the dismiss state is also written to `localStorage` |

### Example Usage

```vue
<!-- Simple banner -->
<UBanner title="This is an important announcement." />

<!-- With icon and color -->
<UBanner
  icon="i-lucide-info"
  color="primary"
  title="New features are available!"
/>

<!-- Closable with persistence -->
<UBanner
  id="welcome-banner"
  title="Welcome to Mizu!"
  close
/>

<!-- With actions -->
<UBanner
  icon="i-lucide-info"
  title="We've updated our terms."
  :actions="[
    { label: 'Review', variant: 'outline' },
    { label: 'Accept' }
  ]"
/>

<!-- Link banner -->
<UBanner
  to="https://example.com"
  target="_blank"
  title="Learn more about the new release"
  color="primary"
/>
```

## Implementation Notes

1. **Use `<UBanner>` directly** — No Mizu wrapper needed. Apply the `mizuTheme` preset in `app.config.ts` and Nuxt UI handles the rest.
2. **Dismiss persistence** — Always provide an `id` prop when using `close`. The dismiss state is saved to `localStorage` under `banner-{id}`. Without an `id`, the banner reappears on page reload.
3. **`useHead` requires app context** — `<UBanner>` calls `useHead()` internally to inject a pre-hydrate script that hides the banner before paint if it was previously dismissed. In Astro/Starlight demos mounted with `client:only="vue"`, this throws unless a `createHead()` instance is provided on the demo's `appContext.provides['usehead']`. `BannerDemo.vue` ships this wiring inline.
4. **Action buttons** — Actions default to `color="neutral"` and `size="xs"`. Pass custom `ButtonProps` to override.
5. **Link behavior** — When `to` is set, the entire banner becomes clickable and navigates to the given URL. Use with `target="_blank"` for external links.
6. **Placement** — The banner renders inline where placed. For a full-width top banner, place it at the top of your layout, outside the main content container.
