Cards are containers for grouping related content and actions. They provide a clean, organized way to present information with optional visual emphasis.

## Examples

<CardDemo client:only="vue" />

```vue
<MizuCard>
  <MizuCardImage src="https://placecats.com/800/400" alt="Kitten" />
  <MizuCardHeader>
    <MizuCardTitle>Card Title</MizuCardTitle>
    <MizuCardDescription>Card description text.</MizuCardDescription>
    <MizuCardAction>
      <MizuButton variant="ghost" size="sm">Action</MizuButton>
    </MizuCardAction>
  </MizuCardHeader>
  <MizuCardContent>
```

### CSS Custom Properties

| Token | Default | Description |
|-------|---------|-------------|
| `--color-surface-base` | #FFFFFF | Card + content background |
| `--color-surface-subtle` | #F9FAFB | Header + footer background |
| `--color-foreground-tertiary` | #9CA3AF | Card border, separator, description text |
| `--color-foreground-primary` | #1B1B1D | Title + content text |
| `--font-size-h3` | 16px | Title font size |
| `--font-size-caption` | 12px | Description font size |
| `--font-size-body` | 14px | Content font size |
| `--line-height-h3` | 1.3 | Title line height |
| `--line-height-caption` | 1.45 | Description line height |
| `--line-height-body` | 1.6 | Content line height |
| `--letter-spacing-tight` | -0.03em | Title letter spacing |

### Sizing

Spacing is propagated via CSS custom properties (`--mizu-card-px`, `--mizu-card-py`, `--mizu-card-gap`) set on the card root — child sections inherit automatically.

#### Spacing Variants

| Variant | Section Padding | Header Gap | Use Case |
|---------|----------------|------------|----------|
| **compact** | 12px | 4px | Tight layouts, dense UIs |
| **default** | 16px | 6px | Standard cards |
| **comfortable** | 24px | 8px | Generous whitespace |

#### Visual Sections

| Section | Background | Separator |
|---------|-----------|-----------|
| CardHeader | `surface-subtle` (#F9FAFB) | Bottom border at 25% opacity |
| CardContent | `surface-base` (#FFFFFF) | — |
| CardFooter | `surface-subtle` (#F9FAFB) | Top border at 25% opacity |

Separators use `color-mix(in srgb, var(--mizu-color-foreground-tertiary) 25%, transparent)`.

#### CardImage

The image section renders a full-width image at the top of the card, clipped by the card's rounded corners.

| Property | Default | Description |
|----------|---------|-------------|
| `src` | — | Image URL (required) |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Semantic HTML | Use `<article>` or `<section>` for card containers when interactive |
| Heading Hierarchy | Cards should contain headings for screen reader navigation |
| Keyboard Navigation | If card is interactive, ensure focusable elements inside are reachable |
| Color Contrast | Border and background meet 3:1 contrast ratio |

## Anatomy

A card consists of up to 8 parts:

| Part | Required | Description |
|------|----------|-------------|
| Card | Yes | Root container with border and rounded corners |
| CardImage | No | Full-width image at the top, flushed to card edges |
| CardHeader | No | Container for title, description, and action |
| CardTitle | No | The card's heading |
| CardDescription | No | Helper text under the title |
| CardAction | No | Action area in the top-right of the header |
| CardContent | No | Main body content |
| CardFooter | No | Actions or secondary content at the bottom |

#### Composition

```
Card
├── CardImage (optional, placed before header)
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

## Implementation Notes

1. **Composition pattern** — Follows shadcn/ui's card structure for consistency
2. **Native `<div>` elements** — No Reka UI primitives needed; all components are lightweight containers
3. **Spacing via CSS vars** — `--mizu-card-px`, `--mizu-card-py`, `--mizu-card-gap` are set on the card root and inherited by children
4. **Section backgrounds** — Header and footer use `surface-subtle`; content uses `surface-base`
5. **Separators** — Header gets `border-bottom` and footer gets `border-top` at 25% foreground-tertiary opacity
6. **Image** — Full-width with `aspect-ratio: 2/1` and `object-fit: cover`; clipped by card's `overflow-hidden`
7. **Typography** — Uses `!important` to override host framework (Starlight) global heading/paragraph styles
8. **Tailwind `@apply`** — Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
9. **Class inheritance** — All components accept `class` prop for overrides via `useAttrs()`
10. **TypeScript** — Full type safety with `<script setup lang="ts">`
11. **Tree-shakeable** — Export as ESM + CJS via Vite library mode
