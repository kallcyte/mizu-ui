A card is a container for grouping related content. Mizu uses Nuxt UI's `UCard` with a subtle outline border and rounded corners.

## API

Reference: [Nuxt UI Card](https://ui.nuxt.com/docs/components/card)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'solid' \| 'outline' \| 'soft' \| 'subtle'` | `'outline'` (Mizu default) | Visual style |
| `title` | `string` | — | Card title (shorthand) |
| `description` | `string` | — | Card description (shorthand) |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `header` | — | Top section, typically title + description |
| `title` | — | Title content (alternative to `title` prop) |
| `description` | — | Description content (alternative to `description` prop) |
| `default` | — | Main body content |
| `footer` | — | Bottom section, typically actions |

## Theme

Mizu overrides Nuxt UI's card defaults:

```ts
// app.config.ts
import { mizuTheme } from "@mizu/vue/theme";
export default defineAppConfig({ ui: mizuTheme });
```

### Design Specs

| Property | Value |
|----------|-------|
| Default Variant | `outline` |
| Border Radius | 6px (`rounded-md`) |
| Overflow | `hidden` (clips content to border radius) |
| Padding | Nuxt UI default (inherited) |

### Typography

| Property | Value |
|----------|-------|
| Font Family | DM Sans (`--font-family-sans`) |
| Title Weight | 600 (semibold) |

## Anatomy

A card consists of three optional sections:

| Part | Required | Description |
|------|----------|-------------|
| Header | No | Top section with title and description |
| Body | No | Main content area |
| Footer | No | Bottom section, typically with actions |

## Implementation Notes

1. **Use `<UCard>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Default variant** — Mizu theme sets the default to `outline` for a subtle border. Override with `variant="solid"` for a filled background.
3. **Header/Footer slots** — Use named slots for structured card layouts. The `title` and `description` props are shorthands.
4. **Rounded corners** — Mizu applies `rounded-md` (6px) and `overflow-hidden` to clip child content to the border radius.
