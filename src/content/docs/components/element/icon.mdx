An icon renders any icon from the Iconify ecosystem using a simple name-based API. Mizu uses Nuxt UI's `UIcon` to display icons from Lucide, Phosphor, Simple Icons, and thousands of other collections.

## Anatomy

An icon is a single inline element:

| Part | Required | Description |
|------|----------|-------------|
| Inline SVG | Yes | An `<svg>` element (or CSS pseudo-element in `css` mode) displaying the icon |

## Size Specifications

Icon size is controlled by Tailwind utility classes on the component (e.g. `size-5`, `w-6 h-6`) or via the `size` prop (pixel value). The Nuxt UI recommendation is `size-N` Tailwind classes for consistency with other Mizu components.

| Tailwind class | Pixel size | Common use case |
|----------------|-----------|-----------------|
| `size-3` | 12px | Inline with small text, dense tables |
| `size-4` | 16px | Inline with body text, default icon button |
| `size-5` | 20px | **Default** — most surfaces |
| `size-6` | 24px | Larger buttons, section headers |
| `size-7` | 28px | Toolbars, navigation |
| `size-8` | 32px | Hero areas, feature callouts |
| `size-10` | 40px | Large feature icons |
| `size-12` | 48px | Empty states, hero illustrations |

## Color Specifications

Icons inherit `currentColor` by default, which means they take the text color of their parent. To override, use any Tailwind text color class:

| Technique | Example | Notes |
|-----------|---------|-------|
| Tailwind text color | `<UIcon class="size-5 text-primary" />` | Inherits via `currentColor` in SVG fill |
| CSS color property | `<UIcon style="color: var(--color-hub-ycp)" />` | Works with any CSS color source |
| `customize` callback | `<UIcon :customize="(content) => content.replace(/currentColor/g, '#0070F2')" />` | Replaces `currentColor` SVG attribute at render time — useful for animations or per-segment coloring |

The `customize` prop runs against the inlined SVG content before mount. It's most useful when you need different colors for different paths within the same icon (e.g. a status dot inside a circle).

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Decorative icons | When the icon is purely decorative (adjacent text already conveys meaning), add `aria-hidden="true"` so screen readers skip it |
| Semantic icons | When the icon conveys meaning without adjacent text (e.g. a standalone status indicator), wrap with `<span role="img" aria-label="...">` |
| `currentColor` | Icon's stroke/fill uses `currentColor`, so setting `aria-hidden` does not affect the visible rendering |
| `title` element | For assistive tooltips on SVG, use the inner `<title>` element inside the SVG (rendered as a tooltip on hover and announced by screen readers) |
| Decorative in nav | Icon-only buttons should pair with `aria-label` on the `<UButton>` wrapper; the `<UIcon>` itself stays `aria-hidden` |

### ARIA Attributes

```html
<!-- Decorative (most common) -->
<UButton icon="i-lucide-mail" aria-label="Open mail" />

<!-- Semantic standalone -->
<span role="img" aria-label="Online status">
  <UIcon name="i-lucide-circle-dot" class="size-4 text-success" />
</span>

<!-- With SVG title for tooltip -->
<UIcon name="i-lucide-info" class="size-5">
  <title>More information</title>
</UIcon>
```

## Token Mapping

`<UIcon>` does not consume Mizu design tokens directly — its `currentColor` fills inherit from the surrounding text color. Token usage depends on how you style the parent:

| Token | Value | Usage |
|-------|-------|-------|
| `--color-foreground-primary` | `#0F172A` | Default icon color via parent `text-foreground-primary` |
| `--color-foreground-secondary` | `#475569` | Muted icons via parent `text-foreground-secondary` |
| `--color-foreground-tertiary` | `#94A3B8` | Disabled-state icons |
| `--color-hub-primary` | `#001C44` | Hub-themed icons via `text-hub-primary` |
| `--color-feedback-{success,info,warning,error}-base` | varies | Status indicators via `text-success` etc. |

The `customize` callback can substitute Mizu token values into the SVG content for per-segment coloring.

## Vue Component API

### UIcon Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string \| VueComponent` | — | Iconify name (`'i-{collection}-{name}'`) or a Vue component to render. **Required.** |
| `mode` | `'svg' \| 'css'` | `'svg'` | Render mode. `'svg'` inlines the SVG; `'css'` uses background-image with a mask |
| `size` | `string \| number` | — | Icon size in pixels (e.g. `20`). Equivalent to applying a `size-N` Tailwind class |
| `customize` | `boolean \| IconifyIconCustomizeCallback` | — | Customize SVG content. Pass `true` to receive the raw icon object, or a callback `(content, props) => string` to transform the rendered SVG |

### Slots

| Slot | Description |
|------|-------------|
| `default` | Inner SVG content — typically a `<title>` element for assistive tooltips |

### Example Usage

```vue
<!-- Basic usage -->
<UIcon name="i-lucide-lightbulb" class="size-5" />

<!-- Different collections -->
<UIcon name="i-lucide-heart" class="size-5" />
<UIcon name="i-ph-smiley" class="size-5" />
<UIcon name="i-simple-icons-nuxtdotjs" class="size-5" />

<!-- Sized via class -->
<UIcon name="i-lucide-star" class="size-4" />
<UIcon name="i-lucide-star" class="size-8" />

<!-- Sized via prop -->
<UIcon name="i-lucide-star" :size="32" />

<!-- Color via text class (currentColor) -->
<UIcon name="i-lucide-check-circle" class="size-5 text-success" />
<UIcon name="i-lucide-alert-triangle" class="size-5 text-warning" />

<!-- CSS mode for background-image rendering -->
<UIcon name="i-lucide-zap" mode="css" class="size-5" />

<!-- Per-segment color via customize -->
<UIcon
  name="i-lucide-circle-dot"
  :customize="(content) => content.replace(/currentColor/g, 'var(--color-feedback-success-base)')"
  class="size-4"
/>

<!-- Decorative inside a button (aria-hidden via UButton) -->
<UButton icon="i-lucide-mail" aria-label="Open mail" />

<!-- Standalone semantic icon -->
<span role="img" aria-label="Online">
  <UIcon name="i-lucide-circle-dot" class="size-4 text-success" />
</span>
```

## Implementation Notes

1. **Use `<UIcon>` directly** — No Mizu wrapper needed. Apply the `mizuTheme` preset in `app.config.ts`.
2. **Iconify format** — Names follow the `i-{collection}-{name}` convention. Browse collections at [icones.js.org](https://icones.js.org) or use the `search_icons` MCP tool. Over 200,000 icons across 150+ collections.
3. **SVG mode by default** — `mode="svg"` (default) inlines the SVG element, allowing color inheritance via `currentColor` and dynamic styling with Tailwind classes. The SVG is fetched once per icon per session and cached.
4. **CSS mode** — `mode="css"` renders via `background-image` + mask. Useful when SVG DOM manipulation is undesirable (e.g. sending the rendered HTML through a sanitizer). Slightly faster on cold renders since no SVG parsing is needed.
5. **Size via Tailwind** — Use `size-N` or `w-N h-N` classes to control icon dimensions. The `size` prop provides a shorthand for pixel-based sizes and accepts both string and number values.
6. **`customize` callback** — Use to dynamically recolor parts of the SVG (e.g. replacing `currentColor` with specific hex values per path) or to transform the rendered markup. Runs once per render, not on every state change.
7. **Performance** — Icons are loaded on demand and cached after first use. Avoid using the same icon across many components without a shared import — though Nuxt UI handles this automatically via the Iconify runtime.
8. **Decorative vs semantic** — Default to `aria-hidden="true"` (handled by parent `<UButton>` when used as an icon prop). For standalone icons that carry meaning, wrap with `<span role="img" aria-label="...">`.
