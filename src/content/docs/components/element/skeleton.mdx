A skeleton is a lightweight, non-interactive placeholder used to indicate that content is loading. It mirrors the shape of the eventual content (text, avatars, cards, list items) so the layout stays stable while data fetches.

## Demo

<SkeletonDemo client:only="vue" />

## API

MizuSkeleton renders a styled `<div>` element with Mizu tokens. Sizing and shape are controlled via the standard `class` attribute, while animation is selected via the `animation` prop.

### Props

| Prop        | Type                                      | Default     | Description                                    |
| ----------- | ----------------------------------------- | ----------- | ---------------------------------------------- |
| `animation` | `"shimmer"` \| `"pulse"` \| `"none"`     | `"shimmer"` | Animation style for the placeholder            |

### Layout

Sizing is handled entirely through Tailwind utility classes passed via the `class` attribute:

| Aspect         | Class Pattern                     | Example                                    |
| -------------- | --------------------------------- | ------------------------------------------ |
| Height         | `h-*` or `h-[*]`                  | `h-3.5`, `h-4`, `h-30`               |
| Width          | `w-*` or `w-[*]`                  | `w-full`, `w-48`, `w-50`                  |
| Shape          | `rounded-*`                       | `rounded-md`, `rounded-full`               |
| Background     | `bg-surface-muted` (applied by default) | —                                     |

### Multi-line Text

For multi-line text, compose multiple instances inside a flex column:

```vue
<div class="flex flex-col gap-2">
  <MizuSkeleton class="h-3.5 w-full rounded-md" />
  <MizuSkeleton class="h-3.5 w-full rounded-md" />
  <MizuSkeleton class="h-3.5 w-3/5 rounded-md" />
</div>
```

### Content Loading Pattern

Use `v-if`/`v-else` to toggle between skeleton and real content:

```vue
<template>
  <MizuSkeleton v-if="loading" class="size-12 rounded-full" />
  <img v-else src="..." alt="Avatar" />
</template>
```

## Theme

### Placeholder Color

| Token                | Light      | Dark       |
| -------------------- | ---------- | ---------- |
| `--color-surface-muted` | `#F3F4F6` | `#1E2030` |

The skeleton background uses the Mizu `--color-surface-muted` token via the `bg-surface-muted` utility class. This token automatically switches between light and dark themes.

Skeletons are intentionally neutral. They do not carry semantic color variants since they do not represent a brand or status — only the absence of content.

#### Variant Color Map

| Element           | Token / Implementation           | Light                     | Dark                      |
| ----------------- | -------------------------------- | ------------------------- | ------------------------- |
| Placeholder fill  | `bg-surface-muted`               | `#F3F4F6`                | `#1E2030`                 |
| Shimmer highlight | inline gradient via `::after`    | `rgba(255,255,255,0.45)` | `rgba(255,255,255,0.08)` |

The placeholder fill uses the Mizu muted surface token, which adapts to both themes automatically. The shimmer highlight is a semi-transparent white overlay that sweeps across the placeholder.

### Sizing

#### Variant Shapes

| Variant    | Aspect   | Default Size              | Use Case                           |
| ---------- | -------- | ------------------------- | ---------------------------------- |
| **Text**   | Variable | 100% width, 14px height   | Paragraph text, headings, labels   |
| **Circle** | 1:1      | equal width & height      | Avatars, icons, status dots        |
| **Rect**   | Any      | explicit w & h via class  | Thumbnails, cards, buttons, images |

#### Dimensions

| Property                   | Text                         | Circle                | Rect                   |
| -------------------------- | ---------------------------- | --------------------- | ---------------------- |
| Height                     | 14px (fixed line height)     | = width               | explicit height class  |
| Width                      | 100% (or explicit class)     | explicit width class  | explicit width class   |
| Multi-line Stack Gap       | 0.5em between lines          | —                     | —                      |
| Last-line Width (in stack) | 60% (mimics natural prose)   | —                     | —                      |

#### Shape

| Mode           | Border Radius               |
| -------------- | --------------------------- |
| Default        | `radius-default` (6px) via `mizu-skel-base` |
| `rounded-md`   | `radius-default` (6px)      |
| `rounded-full` | 9999px                      |
| Custom         | any value via `rounded-*` class |

The component applies a default `border-radius: 0.375rem` via the `mizu-skel-base` class in `@layer components`. User-supplied `rounded-*` utility classes (in `@layer utilities`) always override this default.

#### Multi-line Text Layout

```
┌──────────────────────────────────────┐
│                                      │  ← line 1 (100%)
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│                                      │  ← line 2 (100%)
└──────────────────────────────────────┘

┌───────────────────────┐
│                       │  ← line 3 (60%)
└───────────────────────┘
```

| Property        | Value |
| --------------- | ----- |
| Stack Gap       | 0.5em |
| Last-line Width | 60%   |

### Transitions

Skeleton provides two animation modes via the `animation` prop.

| Mode    | Prop Value | Default? | CSS Mechanism                                                                 |
| ------- | ---------- | -------- | ----------------------------------------------------------------------------- |
| Shimmer | `shimmer`  | Yes      | `::after` pseudo-element with linear-gradient overlay, animated via `transform: translateX()` sweep |
| Pulse   | `pulse`    | No       | Tailwind's `animate-pulse` (opacity keyframes 1 → 0.5 → 1)                   |
| None    | `none`     | No       | No animation — renders as static placeholder at reduced opacity               |

#### Shimmer Animation

The shimmer renders a semi-transparent white gradient band that sweeps horizontally across the placeholder via a `::after` pseudo-element with `transform: translateX()`. This approach avoids browser quirks with `background-position` animation and works reliably across all rendering engines.

| Property                        | Value                                                         |
| ------------------------------- | ------------------------------------------------------------- |
| Implementation                  | `::after` pseudo-element, `linear-gradient`, `transform: translateX()` |
| Overlay color (light)           | `rgba(255, 255, 255, 0.45)` white shine                      |
| Overlay color (dark)            | `rgba(255, 255, 255, 0.08)` subtle white sheen               |
| Sweep                           | `translateX(-100%)` to `translateX(100%)`                    |
| Cycle duration                  | **1500ms**                                                    |
| Easing                          | `ease-in-out`                                                 |
| Iteration                       | infinite                                                      |
| Honors `prefers-reduced-motion` | Yes — animation disabled                                     |

#### Pulse Animation

The pulse animation fades the skeleton's opacity between 1 and 0.5, matching the standard `animate-pulse` pattern. This provides a simpler, more subdued loading indicator that works well in dense layouts.

| Property                        | Value                                           |
| ------------------------------- | ----------------------------------------------- |
| Implementation                  | Tailwind `animate-pulse` class                  |
| Cycle duration                  | **2000ms**                                      |
| Easing                          | `cubic-bezier(0.4, 0, 0.6, 1)`                  |
| Iteration                       | infinite                                        |
| Honors `prefers-reduced-motion` | Yes — animation disabled                        |

When `prefers-reduced-motion: reduce` is set, all animations stop and the skeleton renders with a flat background.

## Accessibility

### Requirements

| Criterion       | Implementation                                                                           |
| --------------- | ---------------------------------------------------------------------------------------- |
| Screen Reader   | Placeholder is hidden via `aria-hidden="true"` since it carries no semantic information  |
| Non-interactive | Skeleton is not focusable, not keyboard-accessible, and emits no events                  |
| Reduced Motion  | Shimmer and pulse animations are suppressed when `prefers-reduced-motion: reduce` is set |
| Color Contrast  | Placeholder color is decorative, not informational; no contrast requirement              |

### ARIA Attributes

```html
<!-- Single skeleton -->
<MizuSkeleton class="h-4 w-48 rounded-md" aria-hidden="true" />

<!-- Circle avatar -->
<MizuSkeleton class="size-12 rounded-full" aria-hidden="true" />

<!-- Multi-line stack -->
<div class="flex flex-col gap-2">
  <MizuSkeleton class="h-3.5 w-full rounded-md" />
  <MizuSkeleton class="h-3.5 w-full rounded-md" />
  <MizuSkeleton class="h-3.5 w-3/5 rounded-md" />
</div>
```

The component renders with `aria-hidden="true"` to hide the placeholder from assistive technology. Since skeletons carry no semantic information, they should be invisible to screen readers.

## Anatomy

A skeleton consists of a single styled placeholder element:

| Part        | Required | Description                                                                    |
| ----------- | -------- | ------------------------------------------------------------------------------ |
| Placeholder | Yes      | A `div` element with Mizu background token and optional animation              |

For multi-line text, a stack wrapper groups multiple MizuSkeleton instances and shrinks the final line to 60% width to mimic natural prose.

## Vue Component API

### MizuSkeleton Props

| Prop        | Type                                  | Default     | Description                            |
| ----------- | ------------------------------------- | ----------- | -------------------------------------- |
| `animation` | `"shimmer"` \| `"pulse"` \| `"none"` | `"shimmer"` | Animation style for the placeholder    |

### Slots

None. The component renders a single `<div>` element.

### Events

None.

### Example Usage

```vue
<script setup lang="ts">
import { MizuSkeleton } from "@mizu/vue";
</script>

<template>
  <!-- Text line with shimmer (default) -->
  <MizuSkeleton class="h-3.5 w-full rounded-md" />

  <!-- Circle avatar -->
  <MizuSkeleton class="size-12 rounded-full" />

  <!-- Rectangle card -->
  <MizuSkeleton class="h-30 w-50 rounded-md" />

  <!-- Pulse animation -->
  <MizuSkeleton animation="pulse" class="h-4 w-48 rounded-md" />

  <!-- No animation -->
  <MizuSkeleton animation="none" class="h-4 w-48 rounded-md" />

  <!-- Multi-line text -->
  <div class="flex flex-col gap-2">
    <MizuSkeleton class="h-3.5 w-full rounded-md" />
    <MizuSkeleton class="h-3.5 w-full rounded-md" />
    <MizuSkeleton class="h-3.5 w-3/5 rounded-md" />
  </div>

  <!-- Content loading pattern -->
  <MizuSkeleton v-if="loading" class="size-12 rounded-full" />
  <img v-else src="..." alt="Avatar" />
</template>
```

## Implementation Notes

1. **Component wrapper** — MizuSkeleton is a thin Vue component that renders a `<div>` with Mizu's `bg-surface-muted` token. It does not use Nuxt UI's `USkeleton`.
2. **Sizing via `class` attribute** — Dimensions are controlled entirely through standard Tailwind utility classes passed via `class` (e.g., `class="h-3.5 w-full rounded-md"`).
3. **Fixed text height** — Use `h-3.5` (14px) as a reliable default text-line height that renders consistently across contexts.
4. **Multi-line text** — Compose multiple MizuSkeleton instances inside a flex column with `gap-2`. Set the last child's width to `w-3/5` (60%) to mimic natural prose endings.
5. **Color via Mizu token** — The `bg-surface-muted` class maps to Mizu's `--color-surface-muted` token (light `#F3F4F6`, dark `#1E2030`), adapting automatically to the active theme.
6. **Shimmer animation** — Uses a `::after` pseudo-element with a linear-gradient overlay animated via `transform: translateX()` from `-100%` to `100%`. Avoids browser quirks with `background-position` animation.
7. **Pulse animation** — Tailwind's built-in `animate-pulse` class (opacity keyframes 1 → 0.5 → 1).
8. **Shimmer is default** — The `animation` prop defaults to `"shimmer"`. Use `animation="pulse"` or `animation="none"` to change.
9. **`prefers-reduced-motion`** — All animations are disabled when the user prefers reduced motion.
10. **Default border-radius** — The `mizu-skel-base` class (in `@layer components`) provides a default `border-radius: 0.375rem`. User-supplied `rounded-*` utility classes (in `@layer utilities`) always override it.
11. **ARIA** — The component renders with `aria-hidden="true"`. Skeletons carry no semantic information and should be hidden from assistive technology.
12. **Shimmer is purely CSS** — No JavaScript runtime cost. The animation is driven entirely by CSS keyframes on the `::after` pseudo-element.
13. **Tailwind v4 compatible** — All sizing utilities (`h-*`, `w-*`, `size-*`, `rounded-*`) are standard Tailwind v4 classes.
14. **Tree-shakeable** — Import `MizuSkeleton` from `@mizu/vue`; unused components are tree-shaken by your bundler.
