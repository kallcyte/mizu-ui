> **Nuxt UI Component:** This uses Nuxt UI's `UKbd` component. Nuxt UI v4 defaults already match the Mizu compact scale, so no sizing overrides are applied.

A Kbd (keyboard) component displays keyboard keys and shortcuts in documentation and UI hints. Mizu uses Nuxt UI's `UKbd` with compact sizes (18/22/26px heights).

## API

Reference: [Nuxt UI Kbd](https://ui.nuxt.com/docs/components/kbd)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Kbd size. Mizu matches: sm(18px), md(22px), lg(26px) |
| `variant` | `'outline' \| 'soft' \| 'subtle' \| 'ghost' \| 'none'` | `'outline'` | Visual style |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'neutral'` | Semantic color |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Key label text |

### Example Usage

```vue
Press <UKbd>Ctrl</UKbd> + <UKbd>K</UKbd> to open search.

<UKbd size="sm">Esc</UKbd> to close.
```

## Theme

Nuxt UI v4 Kbd defaults (sm: 18px, md: 22px, lg: 26px) match the compact Mizu scale. No overrides are needed.

Default: `variant="outline"`, `color="neutral"`, `size="md"`.

### Typography

| Property | Value |
|----------|-------|
| Font Family | JetBrains Mono (`--font-family-mono`) |
| Font Weight | 500 |

## Anatomy

A Kbd is a single inline element:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<kbd>` element with border, padding, and mono font |

## Implementation Notes

1. **Use `<UKbd>` directly** — No Mizu wrapper needed.
2. **Keyboard shortcuts** — Combine multiple `<UKbd>` elements with `+` separators for shortcut documentation.
3. **Semantic HTML** — Nuxt UI renders a native `<kbd>` element, which carries built-in semantic meaning for keyboard input.
4. **Compact scale** — Mizu Kbd sizes are intentionally smaller than buttons to fit inline with body text.
