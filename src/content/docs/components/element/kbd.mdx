The Kbd component displays keyboard keys and shortcuts in a visually distinct style. It renders as a `<kbd>` element for semantic correctness.

## Examples

<KbdDemo client:only="vue" />

### Single Key

```vue
<MizuKbd keys="Enter" />
<MizuKbd keys="Esc" />
```

### Key Combination

```vue
<MizuKbd :keys="['⌘', 'K']" />
<MizuKbd :keys="['Ctrl', 'S']" />
<MizuKbd :keys="['Shift', 'Alt', 'F']" />
```

## API

### Props

| Prop   | Type                 | Default | Description            |
| ------ | -------------------- | ------- | ---------------------- |
| `keys` | `string \| string[]` | —       | Key or keys to display |
| `size` | `'sm' \| 'md'`       | `'md'`  | Size                   |

## Theme

### CSS Custom Properties

| Token                        | Default | Description  |
| ---------------------------- | ------- | ------------ |
| `--color-surface-muted`      | #F3F4F6 | Background   |
| `--color-foreground-primary` | #1B1B1D | Text color   |
| `--color-surface-base`       | #FFFFFF | Border color |

### Sizing

| Size   | Height | Padding | Font Size | Border Radius |
| ------ | ------ | ------- | --------- | ------------- |
| **SM** | 20px   | 0 4px   | 11px      | 4px           |
| **MD** | 24px   | 0 6px   | 12px      | 4px           |

## Anatomy

A kbd consists of one or more key elements:

| Part      | Required | Description                     |
| --------- | -------- | ------------------------------- |
| Key       | Yes      | Individual keyboard key         |
| Separator | No       | Plus sign between multiple keys |

## Implementation Notes

1. **Semantic HTML** — Renders as a `<kbd>` element for proper accessibility and screen reader support.
2. **Multiple keys** — Pass an array to display key combinations with automatic `+` separators.
3. **Inline display** — The component is inline-flex, so it flows naturally within text.
