> **Nuxt UI Component:** This uses Nuxt UI's `UBadge` component. Mizu provides a theme preset (`@mizu/vue/theme`) that overrides sizing, radius, and spacing to match Mizu's design language. See the [Theme](#theme) section for Mizu-specific defaults.

A badge displays a short label for status, categories, or metadata. Mizu uses Nuxt UI's `UBadge` with compact sizing (16/20px).

## Theme

Mizu overrides Nuxt UI's badge sizing to match the Mizu design spec. Consumers apply the theme via `@mizu/vue/theme`:

```ts
// app.config.ts
import { mizuTheme } from "@mizu/vue/theme";
export default defineAppConfig({ ui: mizuTheme });
```

## Anatomy

A badge is a single inline element:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<span>` element with padding, radius, and color |

With optional leading icon and trailing icon inline.
