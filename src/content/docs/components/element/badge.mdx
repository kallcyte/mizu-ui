A badge is a compact inline label for status, categories, or counters. Mizu uses Nuxt UI's `UBadge` with a compressed size scale (Mizu `sm`=16px, `md`=20px) and full support for color, variant, icons, and counters.

## API

Reference: [Nuxt UI Badge](https://ui.nuxt.com/docs/components/badge)

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `any` (HTMLElement or component) | `'span'` | Element or component the badge root should render as |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Badge size. Mizu overrides `sm`=16px and `md`=20px for a compact scale |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'error' \| 'neutral'` | `'primary'` | Semantic color |
| `variant` | `'solid' \| 'outline' \| 'soft' \| 'subtle'` | `'solid'` | Visual style |
| `icon` | `string` (Iconify) | — | Leading icon (e.g. `'i-lucide-check'`) |
| `trailing` | `boolean` | `false` | When `true`, the icon renders on the right side |
| `trailingIcon` | `string` (Iconify) | — | Separate icon for the trailing slot when `icon` is empty |
| `label` | `string \| number` | — | Shorthand for text content. Use instead of the default slot for simple text-only badges |
| `square` | `boolean` | `false` | Equal padding on all sides. Useful for icon-only or numeric counters |

### Slots

| Slot | Props | Description |
|------|-------|-------------|
| `default` | — | Badge label/content (alternative to the `label` prop) |
| `leading` | `{ ui }` | Custom leading content (overrides the `icon` prop) |
| `trailing` | `{ ui }` | Custom trailing content (overrides the `trailingIcon` prop) |

## Anatomy

A badge is a single inline element:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<span>` element with padding, radius, and color |

With optional leading icon, trailing icon, and default text content rendered inline.

## Size Specifications

| Size | Min Width | Height | H-Padding | Font Size | Radius | Icon Size |
|------|-----------|--------|-----------|-----------|--------|-----------|
| `xs` | — | 14px | 4px | 10px (`text-[10px]`) | `rounded-full` | 12px (`size-3`) |
| `sm` | 16px | 16px | 4px | 10px (`text-[10px]`) | `rounded-full` | 12px (`size-3`) |
| `md` | 20px | 20px | 6px | 11px (`text-[11px]`) | `rounded-full` | 16px (`size-4`) |
| `lg` | — | 24px | 8px | 12px (`text-xs`) | `rounded-full` | 16px (`size-4`) |
| `xl` | — | 28px | 8px | 14px (`text-sm`) | `rounded-full` | 20px (`size-5`) |

**Mizu override** — `sm` and `md` are sized more compactly than Nuxt UI defaults to match the Mizu design scale. The overrides are applied via the `mizuTheme` preset in `app.config.ts`.

## Color Specifications

| Color | Mizu Token | Nuxt UI Mapping |
|-------|------------|-----------------|
| `primary` | `--color-hub-primary` | `#001C44` |
| `secondary` | `--color-hub-ycp` | secondary token |
| `success` | `--color-feedback-success-base` | success token |
| `info` | `--color-feedback-info-base` | info token |
| `warning` | `--color-feedback-warning-base` | warning token |
| `error` | `--color-feedback-error-base` | error token |
| `neutral` | `--color-surface-muted` | elevated token |

Each variant (`solid`, `outline`, `soft`, `subtle`) renders the color at a different opacity. `solid` uses the full color (background + inverted text), `soft` uses the color at low opacity for background and the full color for text, `outline` uses the full color for the border and text, `subtle` uses the lowest opacity for background and the full color for text.

### Variant Reference

| Variant | Background | Border | Text |
|---------|------------|--------|------|
| `solid` | full color | — | inverted (`text-inverted`) |
| `outline` | transparent | color | color |
| `soft` | color/10 | — | color |
| `subtle` | color/5 | — | color |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|----------------|
| Color is not the only signal | Always pair a color-coded badge with a text label or leading icon. Users with color blindness need a non-color cue |
| Status indicators | For "Online / Away / Offline" patterns, use `variant="soft"` with a leading `i-lucide-circle-dot` icon plus a text label |
| Sufficient contrast | `solid` variant on default surface passes WCAG AA for text. `outline`, `soft`, and `subtle` rely on color; check contrast on tinted backgrounds |
| Counter semantics | Notification counts (`label="99+"`) are decorative. The surrounding context should announce the count to screen readers |

## Example Usage

```vue
<!-- Text-only badge -->
<UBadge>Default</UBadge>

<!-- Using label shorthand -->
<UBadge label="New" color="primary" variant="subtle" />

<!-- With leading icon -->
<UBadge icon="i-lucide-check" color="success">Verified</UBadge>

<!-- With trailing icon -->
<UBadge icon="i-lucide-arrow-right" trailing color="primary">Continue</UBadge>

<!-- Status indicator -->
<UBadge variant="soft" color="success" icon="i-lucide-circle-dot">Online</UBadge>

<!-- Notification counter -->
<UBadge label="99+" color="error" size="md" />

<!-- Single-digit counter — force circular aspect with min-w matching height -->
<UBadge label="3" color="error" size="md" :ui="{ base: 'min-w-[26px] gap-0 justify-center' }" />

<!-- Square icon-only badge -->
<UBadge square color="error" icon="i-lucide-bell" />

<!-- Outline variant -->
<UBadge variant="outline" color="primary">Draft</UBadge>
```

## Implementation Notes

1. **Use `<UBadge>` directly** — No Mizu wrapper needed. Apply the theme preset and Nuxt UI handles the rest.
2. **Compact scale** — Mizu badges are smaller than Nuxt UI defaults. The theme preset overrides `sm` to 16px and `md` to 20px to match the Mizu design spec.
3. **Fully rounded** — The theme preset forces all badge sizes to `rounded-full` so they read as pills regardless of width (longer labels like "In meeting" or "Online" stay pill-shaped instead of turning into rounded rectangles).
4. **Status indicators** — Use `variant="soft"` with a semantic `color` and a leading icon (e.g. `i-lucide-circle-dot`) for "Online / Away / Offline" labels.
5. **`label` shorthand** — Prefer `<UBadge label="New" />` over the default slot for simple text-only badges. Keeps the template line tidy.
6. **Square for counters** — Set `square` when the badge contains only an icon or a short number so all sides have equal padding. For single-character labels like `label="3"`, pass `:ui="{ base: 'min-w-[26px] gap-0 justify-center' }"` (matching the badge height for `size="md"`, zeroing the flex gap, and centering the label) so the badge renders as a perfectly centered circle instead of an oval.
7. **Color contrast** — `solid` provides the highest contrast; `outline`, `soft`, and `subtle` are designed for use on tinted backgrounds where you want a softer visual weight.
