Alerts communicate status messages, feedback, and important information to the user. They appear inline within a page to provide context about a result, error, or system state.

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'success' \| 'error' \| 'warning' \| 'info'` | `'info'` | Visual variant |
| `title` | `string` | `undefined` | Bold title text |
| `closable` | `boolean` | `false` | Show close button |
| `defaultIcon` | `boolean` | `true` | Show built-in variant icon |

### Slots

| Slot | Description |
|------|-------------|
| `default` | Alert body text (required) |
| `icon` | Custom icon (overrides default icon) |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `close` | `void` | Emitted when close button is clicked |

#### Variant Use Cases

| Variant | Use Case |
|---------|----------|
| **Success** | Confirmation of completed actions, positive status |
| **Error** | Critical issues, validation errors, failed operations |
| **Warning** | Caution states, pending actions, attention required |
| **Info** | Neutral information, tips, system messages |

#### Default Icons

Each variant ships with a built-in default icon (16x16, 1.5px stroke):

| Variant | Icon |
|---------|------|
| **Success** | Circle with checkmark |
| **Error** | Circle with dot and line |
| **Warning** | Triangle with exclamation |
| **Info** | Circle with letter "i" |

Set `default-icon="false"` to hide, or use the `icon` slot to provide a custom one.

### Transitions

| Property | Duration | Easing |
|----------|----------|--------|
| Opacity (close hover) | 150ms | ease-in-out |
| Opacity (close animation) | 200ms | ease-out |
| Transform (close animation) | 200ms | ease-out |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Screen Reader | `role="alert"` for errors, `role="status"` for others |
| Live Region | `aria-live="assertive"` for errors, `aria-live="polite"` for others |
| Focus Indicator | Visible focus ring on close button |
| Color Contrast | 4.5:1 for text (variants meet WCAG AA on their subtle backgrounds) |
| Close Button | Descriptive `aria-label="Close alert"`, disabled during exit animation |
| Icon | Decorative only, not announced separately |

```html
<!-- Error alert (assertive) -->
<div
  role="alert"
  aria-live="assertive"
>
  <span aria-hidden="true">icon</span>
  <div>
    <div>Title</div>
    <div>Body content</div>
  </div>
  <button aria-label="Close alert">×</button>
</div>

<!-- Success / Warning / Info (polite) -->
<div
  role="status"
  aria-live="polite"
>
  ...
</div>
```

## Anatomy

An alert consists of up to 4 parts:

| Part | Required | Description |
|------|----------|-------------|
| Container | Yes | The alert's background and border |
| Icon | No | A leading icon that reinforces the variant meaning |
| Title | No | Bold heading text above the body |
| Body | Yes | Main message content (default slot) |
| Close Button | No | Dismissible trigger (shown when `closable` is true) |

## Implementation Notes

1. **Native `<div>` element** - No Reka UI primitive needed; uses native HTML with proper ARIA roles
2. **Tailwind `@apply`** - Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
3. **CSS Custom Properties** - Colors are resolved via CSS variables from `@mizu/tokens`, with border using `color-mix` for 25% opacity
4. **Self-contained CSS** - Tailwind utilities are bundled into `dist/index.css` via `@tailwindcss/vite`; consumers do not need Tailwind installed
5. **Class inheritance** - Accept `class` prop for overrides via `useAttrs()`
6. **TypeScript** - Full type safety with `<script setup lang="ts">`
7. **Tree-shakeable** - Export as ESM + CJS via Vite library mode
8. **Accessibility roles** - `role="alert"` + `aria-live="assertive"` for errors (interrupts screen reader), `role="status"` + `aria-live="polite"` for others (waits for pause)
9. **Decorative icons** - Default icons are visual only; screen readers announce the title and body text
10. **Body slot reset** - `mizu-alert__body > *` rule resets child margins so inline content sits cleanly
11. **Close animation** - On close, the alert fades out and slides up over 200ms via a `--closing` CSS class. The `close` event is emitted after the animation completes so parent `v-if` removal doesn't interrupt the animation.
