The Avatar Group component displays a collection of avatars in a compact, overlapping layout. When there are more avatars than the `max` limit, it shows an overflow indicator with the count of hidden avatars.

## Examples

<AvatarGroupDemo client:only="vue" />

### Basic Usage

```vue
<script setup>
const users = [
  { src: '/avatars/alice.jpg', alt: 'Alice', fallback: 'A' },
  { src: '/avatars/bob.jpg', alt: 'Bob', fallback: 'B' },
  { src: '/avatars/carol.jpg', alt: 'Carol', fallback: 'C' },
];
</script>

<template>
  <MizuAvatarGroup :items="users" :max="3" />
</template>
```

### With Overflow

```vue
<MizuAvatarGroup :items="manyUsers" :max="3" size="lg" />
```

## API

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `AvatarGroupItem[]` | `[]` | Array of avatar items |
| `max` | `number` | `5` | Max visible before +N overflow |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Avatar size |

### AvatarGroupItem

```typescript
interface AvatarGroupItem {
  src?: string;
  alt?: string;
  fallback?: string;
}
```

## Theme

### Sizing

#### Overlap

| Size | Overlap Margin |
|------|----------------|
| **SM** | -6px |
| **MD** | -8px |
| **LG** | -10px |
| **XL** | -12px |

### Accessibility

| Criterion | Implementation |
|-----------|----------------|
| Semantic Group | `role="group"` for screen reader support |
| Visual Separation | Each avatar has a 2px border matching the surface color |

## Anatomy

An avatar group consists of multiple avatars and an optional overflow indicator:

| Part | Required | Description |
|------|----------|-------------|
| Avatars | Yes | Collection of MizuAvatar components |
| Overflow | No | "+N" indicator when exceeding max |

## Implementation Notes

1. **Overlap effect** — Each avatar (except the first) has a negative left margin to create the stacking effect.
2. **Border** — Each avatar has a 2px border matching the surface color to create visual separation.
3. **Overflow indicator** — When the number of items exceeds `max`, a circular badge shows "+N" with the count of hidden avatars.
4. **Accessibility** — The group has `role="group"` for screen reader support.
