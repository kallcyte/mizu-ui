Avatars identify users with an image, initials, or icon in a compact circular or square container. They appear in headers, comment threads, dashboards, and team lists.

## Examples

<AvatarDemo client:only="vue" />

```vue
<template>
  <!-- Initials only -->
  <MizuAvatar name="Mariko Tanaka" />

  <!-- With image -->
  <MizuAvatar name="Aria Patel" src="https://i.pravatar.cc/96?img=32" />

  <!-- Sizes -->
  <MizuAvatar name="Small" size="sm" />
  <MizuAvatar name="Medium" size="md" />
  <MizuAvatar name="Large" size="lg" />
  <MizuAvatar name="Extra Large" size="xl" />

  <!-- Color variants -->
  <MizuAvatar name="Muted" color="muted" />
  <MizuAvatar name="Primary" color="primary" />
  <MizuAvatar name="Accent" color="accent" />
  <MizuAvatar name="Neutral" color="neutral" />

  <!-- Square shape -->
  <MizuAvatar name="Workspace" shape="square" color="accent" />

  <!-- Anonymous (default icon) -->
  <MizuAvatar size="md" />

  <!-- Custom icon slot -->
  <MizuAvatar size="lg" color="primary">
    <template #icon>
      <svg viewBox="0 0 24 24">
        <path d="M9 12L11 14L15 10" stroke="currentColor" stroke-width="2" />
      </svg>
    </template>
  </MizuAvatar>
</template>
```

## API

### Props

| Prop    | Type                                            | Default     | Description                                     |
| ------- | ----------------------------------------------- | ----------- | ----------------------------------------------- |
| `src`   | `string`                                        | `undefined` | Image URL; falls back to initials on error      |
| `alt`   | `string`                                        | `undefined` | Image alt text; defaults to `"<name>'s avatar"` |
| `name`  | `string`                                        | `undefined` | Person name; used to compute initials           |
| `size`  | `'sm' \| 'md' \| 'lg' \| 'xl'`                  | `'md'`      | Avatar size                                     |
| `shape` | `'circle' \| 'square'`                          | `'circle'`  | Shape (round or squared corners)                |
| `color` | `'muted' \| 'primary' \| 'accent' \| 'neutral'` | `'muted'`   | Background and text color variant               |

### Slots

| Slot   | Description                                                             |
| ------ | ----------------------------------------------------------------------- |
| `icon` | Custom fallback icon (overrides default person silhouette and initials) |

#### Touch Target

Avatars are presentational; when wrapped in a link or button, ensure the interactive element meets the WCAG 2.5.8 minimum of 44px x 44px.

#### Source Priority

The avatar renders the first available source in this order:

1. **`src` + successfully loaded** — full image with `object-fit: cover`
2. **`name` provided** — initials (computed from first + last words)
3. **Custom `icon` slot** — user-provided icon
4. **Default person icon** — built-in silhouette SVG (always present)

If the image URL fails to load (`@error` event), the avatar automatically falls back to initials or the default icon.

#### Initials Algorithm

Initials are derived from `name` by splitting on whitespace and taking the first letter of the first and last words (up to 2 characters, uppercase):

| Name              | Initials             |
| ----------------- | -------------------- |
| `"Mariko Tanaka"` | `MT`                 |
| `"Daichi"`        | `D`                  |
| `"John Q. Doe"`   | `JD`                 |
| `""`              | (falls back to icon) |

#### Inline Layout

```
[md 32px]
   ↓
[Avatar] [gap 8-12px] [Text content]
   ↑
   container sizes match Button/Input heights where aligned
```

| Use Case                   | Recommended Size | Inline Gap |
| -------------------------- | ---------------- | ---------- |
| List rows (team, settings) | `sm` or `md`     | 8px        |
| Comment threads            | `md`             | 12px       |
| Card headers (dashboard)   | `lg`             | 12px       |
| Profile pages              | `xl`             | 16px       |

### Transitions

None — the avatar is presentational and does not animate.

### Accessibility

| Criterion       | Implementation                                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Screen Reader   | `role="img"` on the container; `aria-label` set from `alt` or `name` ("X's avatar")                                                      |
| Image Alt       | Falls back to `name + "'s avatar"` when `alt` not provided                                                                               |
| Decorative Text | Initials and icons are `aria-hidden="true"` (the `aria-label` carries meaning)                                                           |
| Image Error     | Falls back to initials or default icon; never shows a broken-image glyph                                                                 |
| Color Contrast  | All 4 color variants meet WCAG AA on text/icon (primary and neutral use white-on-dark; muted and accent use 4.5:1+ on their backgrounds) |

```html
<!-- With image -->
<div role="img" aria-label="Mariko Tanaka's avatar">
  <img src="..." alt="Mariko Tanaka's avatar" />
</div>

<!-- With initials -->
<div role="img" aria-label="Mariko Tanaka's avatar">
  <span aria-hidden="true">MT</span>
</div>

<!-- With default icon (no name) -->
<div role="img" aria-label="Avatar">
  <svg aria-hidden="true">...</svg>
</div>
```

## Anatomy

An avatar consists of up to 3 rendering parts selected in priority order:

| Part      | Required | Description                                                           |
| --------- | -------- | --------------------------------------------------------------------- |
| Image     | No       | `<img>` rendered when `src` is provided and loads successfully        |
| Initials  | No       | Up to 2 uppercase letters derived from the `name` prop                |
| Icon      | No       | Custom icon via `icon` slot, or a built-in person silhouette fallback |
| Container | Yes      | The shape (circle or square) and color background                     |

## Implementation Notes

1. **Native `<div>` element** - No Reka UI primitive needed; uses native HTML with `role="img"` for accessibility
2. **Source priority** - Image > Initials > Custom icon > Default icon, evaluated by computed properties; `@error` on the `<img>` triggers fallback to initials
3. **Initials algorithm** - Splits `name` on whitespace, takes first letter of first + last word (up to 2 characters, uppercase)
4. **Tailwind `@apply`** - Component styles use `@apply` with `@reference` for Tailwind v4 compatibility
5. **CSS Custom Properties** - Backgrounds, text, radii, and letter-spacing are resolved via tokens from `@mizu/tokens`
6. **Self-contained CSS** - Tailwind utilities are bundled into `dist/index.css` via `@tailwindcss/vite`; consumers do not need Tailwind installed
7. **Class inheritance** - Accept `class` prop for overrides via `useAttrs()`
8. **Unique ID** - Uses `useId()` (Vue 3.5+) for stable identity when wrapped in labeled contexts
9. **TypeScript** - Full type safety with `<script setup lang="ts">`; `AvatarProps` interface exported for consumers
10. **Tree-shakeable** - Export as ESM + CJS via Vite library mode
11. **Decorative children** - Initials and icons are `aria-hidden="true"`; the container's `aria-label` is the single source of meaning
12. **Square radius scaling** - Smaller avatars use tighter corner radii (4-6px) for visual balance; larger ones scale up to 10px
