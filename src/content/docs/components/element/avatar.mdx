> **Nuxt UI Component:** This uses Nuxt UI's `UAvatar` component. Nuxt UI v4 defaults already match the Mizu design scale, so no sizing overrides are applied.

An avatar displays a user's photo, initials, or a placeholder. Mizu uses Nuxt UI's `UAvatar` with the default size scale (3xs-3xl).

## Theme

Nuxt UI v4 avatar defaults are already consistent with the Mizu design scale. The granular sizes (3xs-3xl, from 4px to 12px radius) match Mizu's icon and component sizing. No overrides are needed.

Default: `size="md"` (32px), `color="neutral"`.

## Anatomy

An avatar is a single element:

| Part | Required | Description |
|------|----------|-------------|
| Root | Yes | `<span>` with border-radius, overflow hidden, and background color |

When an image is provided, it renders an `<img>` inside. Otherwise, it shows fallback text or an icon.
