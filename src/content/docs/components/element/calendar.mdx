A calendar component for selecting dates. Supports single dates, multiple dates, and date ranges with month and year views. Mizu uses Nuxt UI's `UCalendar` with the `@internationalized/date` package for locale-aware formatting.

### Example Usage

```vue
<script setup lang="ts">
import { ref, shallowRef } from "vue";
import { CalendarDate } from "@internationalized/date";

const value = shallowRef(new CalendarDate(2025, 4, 15));
const rangeValue = shallowRef({
  start: new CalendarDate(2025, 4, 1),
  end: new CalendarDate(2025, 4, 7),
});
</script>

<template>
  <!-- Single date -->
  <UCalendar v-model="value" />

  <!-- Range -->
  <UCalendar range v-model="rangeValue" />

  <!-- Date picker in a popover -->
  <UPopover>
    <UButton color="neutral" variant="subtle" icon="i-lucide-calendar" :label="format(value)" />
    <template #content>
      <UCalendar v-model="value" class="p-2" />
    </template>
  </UPopover>
</template>
```

## Anatomy

A calendar is composed of a header and a body. The body changes based on the active view:

| Part | Required | Description |
|------|----------|-------------|
| Header | Yes | Navigation buttons + heading |
| Body — Day view | Yes (date type) | Weekday row + day grid |
| Body — Month view | Yes (month type) | 3×4 month grid |
| Body — Year view | Yes (year type) | 3×4 year grid |
| Grid Cell Trigger | Yes | Clickable button per day/month/year cell |
| Week Number Cell | No | ISO week number column (when `weekNumbers` is true) |

## Implementation Notes

1. **Use `<UCalendar>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Date library** — Uses `@internationalized/date`. Import `CalendarDate`, `CalendarDateTime`, `HebrewCalendar`, `getLocalTimeZone`, `today`, `DateFormatter` for typed models and locale helpers.
3. **`shallowRef` vs `ref`** — Use `shallowRef` for `CalendarDate` instances (immutable) and reactive arrays/objects (`{start, end}` or `DateValue[]`) since the values are class instances and reassigning them is the typical update path.
4. **Type switching** — With `type="date"` (default), clicking the heading switches to month then year views for quick navigation. Use `viewControl` to configure or disable this behavior (also accepts a `ButtonProps` override for styling).
5. **Range constraints** — Combine `minValue`, `maxValue`, `isDateDisabled`, and `isDateUnavailable` for fine-grained date restrictions. The matchers receive a `DateValue` and return a boolean.
6. **External controls** — Mutate the `v-model` `CalendarDate` with `.add({ months: 1 })` / `.subtract({ months: 1 })` to drive the calendar from external Prev/Next buttons. Cast to `DateValue` since `.add` returns `Mutable<DateValue>`.
7. **Calendar systems** — Pass any `@internationalized/date` calendar (e.g. `HebrewCalendar`) as the first constructor arg of `CalendarDate` to render alternative systems. The `locale` prop still controls label formatting.
8. **Popover composition** — Wrap the calendar in `<UPopover>` with `<template #content>` containing the calendar. Pair with a `UButton` (e.g. `color="neutral"` `variant="subtle"` `icon="i-lucide-calendar"`) to build compact date pickers.
