A calendar component for selecting dates. Supports single dates, multiple dates, and date ranges with month and year views. Mizu uses Nuxt UI's `UCalendar` with the `@internationalized/date` package for locale-aware formatting.

### Example Usage

```vue
<script setup lang="ts">
import { CalendarDate } from "@internationalized/date";

const value = shallowRef(new CalendarDate(2022, 2, 3));
</script>

<template>
  <UCalendar v-model="value" />

  <UCalendar type="month" v-model="value" />

  <UCalendar type="year" v-model="value" />

  <UCalendar range v-model="rangeValue" />

  <UCalendar multiple v-model="multipleValue" />
</template>
```

## Anatomy

A calendar consists of several sections:

| Part | Required | Description |
|------|----------|-------------|
| Header | Yes | Navigation with previous/next buttons and heading |
| Grid | Yes | Day/month/year grid with selectable cells |
| Weekday Row | Yes (date) | "Sun Mon Tue ..." labels |
| Cell Trigger | Yes | Clickable button per day/month/year cell |

## Implementation Notes

1. **Use `<UCalendar>` directly** — No Mizu wrapper needed. Apply the theme preset.
2. **Date library** — Uses `@internationalized/date`. Import `CalendarDate`, `CalendarDateTime`, or `ZonedDateTime` for typed models.
3. **v-model binding** — Use `shallowRef` for single dates, `ref` for reactive objects when using `range` or `multiple`.
4. **Type switching** — With `type="date"` (default), clicking the heading switches to month then year views for quick navigation. Use `viewControl` to configure or disable this behavior.
5. **Range constraints** — Combine `minValue`, `maxValue`, `isDateDisabled`, and `isDateUnavailable` for fine-grained date restrictions.
