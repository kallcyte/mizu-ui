Tabs organize content into separate panels, with one panel visible at a time. They support horizontal and vertical orientation, underline and button-group variants, three sizes, notification badges, and disabled tabs.

<TabsDemo client:load />

## Anatomy

A Tabs component consists of up to 5 parts:

| Part | Required | Description |
|------|----------|-------------|
| TabsRoot | Yes | Container that manages the active tab state |
| TabsList | Yes | Groups the tab triggers |
| TabsTrigger | Yes | Button that activates its associated content |
| TabsIndicator | No | Animated indicator highlighting the active tab |
| TabsContent | Yes | The panel associated with a trigger |

## Composition

```
MizuTabsRoot
  MizuTabsList (variant, size)
    MizuTabsTrigger
    MizuTabsTrigger
  MizuTabsContent
  MizuTabsContent
```

## Color Specifications

### Underline Variant

| State | Token | Value | Usage |
|-------|-------|-------|-------|
| Inactive | `--color-foreground-muted` | #696D7D (light) / #9DA0AD (dark) | Trigger text |
| Active | `--color-foreground-primary` | #001C44 (light) / #EDEDED (dark) | Active trigger text |
| Disabled | `--color-foreground-tertiary` + `opacity: 0.5` | #696D7D (light) / #9DA0AD (dark) at 50% | Disabled trigger text |
| Hover | `--color-foreground-primary` | #001C44 (light) / #EDEDED (dark) | Hover text color |
| Active Indicator | `--mizu-tabs-color` (default: `--color-brand-primary`) | #001C44 (light) / #001C44 (dark) | Underline bar |
| List Border | `--color-surface-muted` | #F3F4F6 (light) / #1E2030 (dark) | Bottom/right border |

### Button Variant

| State | Token | Value | Usage |
|-------|-------|-------|-------|
| Container | `--color-surface-muted` | #F3F4F6 (light) / #1E2030 (dark) | Button group background |
| Inactive | `--color-foreground-muted` | #696D7D (light) / #9DA0AD (dark) | Button text |
| Hover | `--color-foreground-primary` + `--color-surface-base` | #001C44 + #FFFFFF | Hover text and background |

## Accessibility

### Requirements

| Criterion | Implementation |
|-----------|---------------|
| [Tabs WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabpanel) | Reka UI manages `role="tab"`, `role="tabpanel"`, `aria-selected`, `aria-controls`, `aria-labelledby`, and keyboard navigation |
| Keyboard navigation | Arrow keys, Home/End, Tab to move between list and content |

### Keyboard Interactions

| Key | Description |
|-----|-------------|
| Tab | Focuses active trigger, then moves to active content |
| ArrowLeft / ArrowUp | Moves focus to previous trigger |
| ArrowRight / ArrowDown | Moves focus to next trigger |
| Home | Moves focus to first trigger |
| End | Moves focus to last trigger |

## Vue Component API

### TabsRoot Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string` | `undefined` | Controlled active tab value |
| `defaultValue` | `string` | `undefined` | Default active tab value |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Tabs orientation |
| `activationMode` | `"automatic" \| "manual"` | `"automatic"` | Focus vs click activation |

### TabsRoot Events

| Event | Payload | Description |
|-------|---------|-------------|
| `update:modelValue` | `string` | Emitted when active tab changes |

### TabsList Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `loop` | `boolean` | `true` | Loop focus from last to first |
| `variant` | `"underline" \| "button"` | `"underline"` | Visual style — underline tabs or grouped buttons |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Controls trigger padding and font size |
| `color` | `"primary" \| "accent" \| "error" \| "success" \| "warning" \| "info" \| "neutral"` | `"primary"` | Active indicator color |

### TabsTrigger Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Unique identifier (required) |
| `disabled` | `boolean` | `false` | Disable the tab |

### TabsContent Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Matches trigger value (required) |
| `forceMount` | `boolean` | `undefined` | Keep content in DOM when inactive |

### Example Usage

```vue
<script setup lang="ts">
import {
  MizuTabsRoot,
  MizuTabsList,
  MizuTabsTrigger,
  MizuTabsContent,
} from "@mizu/vue";
</script>

<template>
  <!-- Underline variant (default) -->
  <MizuTabsRoot default-value="tab1">
    <MizuTabsList>
      <MizuTabsTrigger value="tab1">Tab One</MizuTabsTrigger>
      <MizuTabsTrigger value="tab2">Tab Two</MizuTabsTrigger>
      <MizuTabsTrigger value="tab3" disabled>Tab Three</MizuTabsTrigger>
    </MizuTabsList>
    <MizuTabsContent value="tab1">Content for tab one.</MizuTabsContent>
    <MizuTabsContent value="tab2">Content for tab two.</MizuTabsContent>
    <MizuTabsContent value="tab3">Content for tab three.</MizuTabsContent>
  </MizuTabsRoot>

  <!-- Button group variant -->
  <MizuTabsRoot default-value="daily">
    <MizuTabsList variant="button">
      <MizuTabsTrigger value="daily">Daily</MizuTabsTrigger>
      <MizuTabsTrigger value="weekly">Weekly</MizuTabsTrigger>
      <MizuTabsTrigger value="monthly">Monthly</MizuTabsTrigger>
    </MizuTabsList>
    <MizuTabsContent value="daily">Daily stats.</MizuTabsContent>
    <MizuTabsContent value="weekly">Weekly stats.</MizuTabsContent>
    <MizuTabsContent value="monthly">Monthly stats.</MizuTabsContent>
  </MizuTabsRoot>

  <!-- Small button group -->
  <MizuTabsRoot default-value="a">
    <MizuTabsList variant="button" size="sm">
      <MizuTabsTrigger value="a">One</MizuTabsTrigger>
      <MizuTabsTrigger value="b">Two</MizuTabsTrigger>
    </MizuTabsList>
    <MizuTabsContent value="a">Small content.</MizuTabsContent>
    <MizuTabsContent value="b">Small content two.</MizuTabsContent>
  </MizuTabsRoot>
</template>
```

## Implementation Notes

1. Each `MizuTabs*` component is a thin wrapper around the corresponding Reka UI `Tabs*` primitive.
2. CSS follows the Mizu convention of `mizu-tabs__*` BEM classes applied via computed property.
3. The active underline trigger renders a 2px accent underline via `::after` pseudo-element in horizontal orientation, and a 2px left border in vertical orientation.
4. The optional `MizuTabsIndicator` component provides an animated sliding indicator alternative.
5. `data-orientation` attribute drives layout differences between horizontal and vertical orientations.
6. `data-variant="button"` on `MizuTabsList` applies button-group styles. The active tab gets a filled background from the `color` prop (defaults to `--color-brand-primary`) with white text.
7. `data-size` on `MizuTabsList` controls trigger padding, font size, and (for button variant) border-radius and container padding.
8. Use `activationMode="manual"` to require click (not just focus) to activate a tab — useful for forms with unsaved changes.
9. The vertical layout uses `display: flex` with `flex-direction: column` on the list and a `gap: 16px` row layout wrapping root + content.
10. Disabled tabs are not focusable via keyboard, have reduced opacity, and use `pointer-events: none`.
