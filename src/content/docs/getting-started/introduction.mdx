Mizunagi is a multi-framework design system built on DTCG tokens. It serves as both a documentation site (Astro + Tailwind v4) and a component library (Vue via Reka UI, React via shadcn/ui + ReUI).

## What is Mizunagi?

Mizunagi provides:

- **Design tokens** in DTCG format for consistent styling
- **Vue components** built on Reka UI primitives
- **React components** (coming soon) via shadcn/ui + ReUI
- **Documentation** with comprehensive specs for each component

## Quick Start

### Install the tokens package

```bash
pnpm add @mizunagi/tokens
```

### Use tokens in your code

```typescript
import { COLOR_BRAND_PRIMARY, FONT_FAMILY_SANS } from '@mizunagi/tokens';
```

### Install the Vue component library

```bash
pnpm add @mizunagi/vue
```

### Use components in your Vue app

```vue
<script setup>
import { MizunagiButton } from '@mizunagi/vue';
</script>

<template>
  <MizunagiButton variant="primary" size="md">
    Get Started
  </MizunagiButton>
</template>
```

## Token System

Mizunagi uses a comprehensive token system with 13 categories:

- **Colors**: brand, surface, foreground, feedback (success/error/warning/info)
- **Typography**: fontFamily (sans, mono, serif), fontSize, fontWeight, lineHeight, letterSpacing
- **Spacing**: xs, sm, md, lg, xl, xxl
- **Border Radius**: tight, default, card, feature, large, full
- **Shadows**: ring, whisper
- **Duration**: fast, normal

Learn more about [tokens overview](/tokens/overview).
