## Versioning

This project follows **semantic versioning** (SemVer) during pre-1.0 development (`0.x.y`):

| Bump | When |
|------|------|
| **Patch** (`0.2.x`) | Bug fixes, documentation updates, minor refactors, dependency bumps |
| **Minor** (`0.x.0`) | New features, new components, breaking token/API changes |
| **Major** (`1.0.0`) | Stable production release |

Changes that require a minor bump: adding a new component, renaming tokens, changing component APIs, adding new packages (e.g. React).
Changes that keep the patch version: renames, copy edits, styling tweaks, build config changes, favicon updates.

### Fixed

### Changed

- Added semi-transparent border (25% opacity) to all tag variants matching label color
- Added Status workflow section to TagDemo (Pending, Draft, In Progress, Success, Done, Rejected, Cancelled)

## 0.2.0 (2026-06-04)

### Changed

- Renamed project from **Mizunagi** → **Mizu** across all packages, docs, and code
- Renamed npm scope from `@mizunagi/*` → `@mizu/*`
- Renamed `MizunagiButton` component → `MizuButton`
- Updated favicon with new glyph and `prefers-color-scheme` theme switching
- Removed color swatch palette from hero section

### Added

- Theme-aware favicon with light/dark variants
- `MizuTag` component with 6 variants, closable option, and pill shape
- Tag documentation page with anatomy, variants, status mappings, and token spec
