## Versioning

This project follows **semantic versioning** (SemVer) during pre-1.0 development (`0.x.y`):

| Bump | When |
|------|------|
| **Patch** (`0.2.x`) | Bug fixes, documentation updates, minor refactors, dependency bumps |
| **Minor** (`0.x.0`) | New features, new components, breaking token/API changes |
| **Major** (`1.0.0`) | Stable production release |

Changes that require a minor bump: adding a new component, renaming tokens, changing component APIs, adding new packages (e.g. React).
Changes that keep the patch version: renames, copy edits, styling tweaks, build config changes, favicon updates.

## 0.12.11 (2026-06-30)

New component: MizuNavigationMenu — horizontal/vertical navigation bar with dropdown content panels.

### Added

- **`MizuNavigationMenu`** — compound component with 9 sub-components: `MizuNavigationMenuRoot`, `MizuNavigationMenuList`, `MizuNavigationMenuItem`, `MizuNavigationMenuTrigger`, `MizuNavigationMenuContent`, `MizuNavigationMenuLink`, `MizuNavigationMenuIndicator`, `MizuNavigationMenuViewport`, `MizuNavigationMenuSub`. Wraps Reka UI NavigationMenu primitives for accessible keyboard navigation, ARIA roles, and focus management. Props: `orientation` (`horizontal`/`vertical`), `modelValue` (v-model active item), `delayDuration` (ms hover delay, default 200), `skipDelayDuration` (default 300), `disableClickTrigger`, `disableHoverTrigger`, `disablePointerLeaveClose`. Features: hover and click trigger modes, content panel enter animation (opacity + translateY, 200ms, respects prefers-reduced-motion), active link highlighting (`brand-accent-subtle` bg + `brand-primary` text), focus-visible ring, indicator arrow pointing from content to trigger, viewport with smooth size transitions, nested sub-menus.

### Documentation

- New MDX page: `navigation-menu.mdx`.
- New demo file: `NavigationMenuDemo.vue` (4 sections: Basic Navigation, With Active Link, Icon Triggers, Vertical Orientation).

## 0.12.8 (2026-06-30)

MizuSkeleton rewritten with vue3-skeleton-inspired features, then deferred for future polish.

### Changed

- **`MizuSkeleton`** — fully rewritten with a content-wrapping `loading` prop (skeleton shows when loading, `<slot>` content reveals when ready), `::after` pseudo-element shimmer animation (`translateX`-based sweep), CSS custom property theming (`baseColor`, `highlightColor`, `animationDuration`, `animationDirection`, `customHighlightBackground`), and a new `MizuSkeletonTheme` provider for global defaults via `provide`/`inject`. Animation hardening: pulse uses locally-defined `@keyframes` instead of the Tailwind `animate-pulse` utility (which silently dropped its keyframes from the bundle); shimmer replaced `background-position` animation with a `::after` sliding gradient.

### Removed

- **`MizuSkeleton` deferred** — removed from the Starlight docs sidebar and active component list. The current shimmer/pulse animation pipeline doesn't yet meet the visual bar for a loading indicator. Component files, demo, types, and docs page are kept in the repo for future reference. See `.agents/plans/PLAN.md` — Deferred section for the retained API design.


## 0.12.7 (2026-06-29)

New component: MizuSkeleton with visible shimmer and pulse loading animations.

### Added

- **`MizuSkeleton`** -- loading placeholder for text, avatars, cards, and lists. Single SFC, no Reka UI primitive. Props: `variant` (`text`/`circle`/`rect`), `width` (string|number), `height` (string|number), `radius` (string|number), `animation` (`shimmer`/`pulse`/`none`), `lines` (number for multi-line text). Features: text variant uses `height: 0.85em` to track surrounding font size, `lines > 1` renders a stack with last line at 60% width (mimics natural prose), shimmer animation sweeps a gradient highlight via `background-position` (1500ms, `ease-in-out`), pulse animation fades opacity 1 → 0.5 → 1 (2000ms, matching shadcn's `animate-pulse`), explicit gradient colors make shimmer visible in both light and dark modes, honors `prefers-reduced-motion`, hidden from assistive tech via `aria-hidden="true"`.

### Documentation

- New demo file: `SkeletonDemo.vue` (9 sections: Variants, Sizes, Custom Dimensions, Animation, In Card Placeholder, Multi-line Text, Conditional Loading with interactive toggle, List Placeholders).

## 0.12.5 (2026-06-29)

Batch 2b — compound inputs: MizuSlider added. Toast fixes: hydration, animations, z-index, overflow.

### Added

- **`MizuSlider`** — numeric range input for selecting a value or range within a bounded interval. Compound component with 4 sub-components: `MizuSliderRoot`, `MizuSliderTrack`, `MizuSliderRange`, `MizuSliderThumb`. Wraps Reka UI `SliderRoot`/`SliderTrack`/`SliderRange`/`SliderThumb` primitives. Props: `modelValue` (`number | number[]`), `defaultValue`, `min`, `max`, `step`, `orientation`, `disabled`, `size` (`sm`/`md`/`lg`), `inverted`, `dir`. Events: `update:modelValue` (`number | number[]`). Features: single-thumb and range (two-thumb) modes depending on whether `modelValue` is a number or two-element array, three sizes controlling track height (4/6/8px) and thumb diameter (14/18/22px), horizontal and vertical orientations, step-based increments, disabled state with 50% opacity.

### Fixed

- **`MizuToast` hydration mismatch** — removed `<Teleport to="body">` and re-added with `v-if="mounted"` using an `onMounted` ref instead of a module-level `const`, preventing SSR Teleport markers from conflicting with client hydration.
- **`MizuToast` z-index** — bumped viewport `z-index` from `9999` to `2147483647` to ensure toasts always render on the topmost layer.
- **`MizuToast` overflow** — changed viewport `overflow-y: auto` to `overflow: hidden` to prevent horizontal scrollbar during slide-in animation.

### Changed

- **`MizuToast` animations** — slide direction now adapts to the toast position: right-side positions slide from right, left-side from left, top-center from top, bottom-center from bottom. Uses CSS custom properties `--toast-slide-from-x` / `--toast-slide-from-y` computed from the `position` prop.

### Documentation

- New MDX page: `slider.mdx`.
- New demo file: `SliderDemo.vue` (6 sections: Basic, Range, Steps, Sizes, Vertical, Disabled).

## 0.7.0 (2026-06-05)

### Added

- **`MizuDivider`** — horizontal rule with optional `label`, `labelPosition` (`start` / `center` / `end`), and 4 color variants (`default` / `muted` / `strong` / `accent`). Implemented as a `<div>` with `flex` + `::before`/`::after` pseudo-elements (a labeled `<hr>` is impossible because `<hr>` is a void element). Token-driven spacing, color, and typography.
- **`MizuProgress`** — determinate and indeterminate progress bar. Props: `value` (0–100, `-1` for indeterminate), `max`, `size` (sm/md/lg), `color` (default/success/warning/error), and an optional `label` slot. Indeterminate variant animates an `inset` block; determinate variant uses `transform: translateX(...)` for smooth 60fps fills.
- **`MizuQuote`** — semantic `<figure>`/`<blockquote>`/`<figcaption>` with `cite` URL, `author`, `source` (e.g. "Mizu Design Docs"), and `align` (`start` / `center`). 4px accent left-border in 3 colors (`neutral` / `primary` / `accent`), inheriting body typography. No keyboard interactions, fully static.
- **`MizuSwitch`** — boolean toggle with `label`, `helperText`, `disabled`, `required`, 3 sizes (sm/md/lg), and custom `trueValue` / `falseValue` for non-boolean bindings. Built on Reka UI `SwitchRoot` for accessibility (keyboard, screen reader announcements). State wired through `v-model`.
- **`MizuTextarea`** — multi-line text input with `label`, `helperText`, `error`, 3 sizes (sm/md/lg), `disabled`, `required`, `rows`, `placeholder`, and `autosize` (auto-grow via `scrollHeight`). Native `<textarea>` for full form integration; aria-invalid and aria-describedby wired to error/helper text.
- **`MizuRadio`** — radio group with inline label, `helperText`, `error`, horizontal/vertical `orientation`, and Reka UI primitive accessibility. Items emit `update:modelValue` with a string value; handler casts via `String(value)`.
- **`MizuSelect`** — native `<select>` with `label`, `helperText`, `error`, 3 sizes, `disabled`, `required`, `placeholder`, `options` array (`{ value, label, disabled? }`), and a custom SVG chevron icon. `appearance: none` + `box-sizing: border-box; line-height: 1` to ensure consistent 28/36/40px heights.
- **`MizuDashList`** — semantic `<dl>`/`<dt>`/`<dd>` for key-value pairs with `items` array (`{ term, description }`), `orientation` (`vertical` / `horizontal`), and `termWidth` (px/em/rem string for the term column when horizontal). Inherits body typography.
- **`MizuMetric`** — display component for stats: `label`, `value`, optional `previous` value with auto-computed `trend` (`up` / `down` / `neutral`) and `trendValue` (percentage delta), and 6 color variants (`default` / `primary` / `accent` / `success` / `warning` / `error`). Subdued label, prominent value, optional trend pill.

### Fixed

- **MDX tables** — root cause: Astro v6 changed `markdown.gfm` from `.default(true)` to `.optional()`; Starlight's `updateConfig` doesn't set `gfm`, so `@astrojs/mdx` sees `undefined` and skips `remarkGfm`. Fix: added `markdown: { gfm: true }` to `astro.config.mjs`. Tables in all component docs now render correctly.
- **Sidebar summary visibility in light mode** — `<summary>` text in the left sidebar was using Starlight's default `var(--sl-color-white)`, which is invisible on the white page background. Added `summary .large { color: var(--sl-color-accent-high) !important; }` in `starlight.css`.
- **Page h1 visibility in light mode** — `h1#_top` (Starlight's constant page title ID) was also white-on-white. Added `h1#_top { color: var(--sl-color-text) !important; }` in `starlight.css`. Old rules targeting the dead `.astro-n5dwoyeh`/`.astro-vv6wmhbp` classes (from Astro 4) were removed; Starlight 0.39.3 uses `data-astro-cid-*` attribute scoping instead.
- **`MizuCheckbox` custom values** — removed redundant `internalValue` ref layer; pass `modelValue`, `trueValue`, `falseValue` directly to Reka UI `CheckboxRoot`. Root cause: Reka UI's `isChecked` only compared against its default boolean `trueValue`, so custom values like `"yes"` were never recognized as checked. Custom-value bindings now work.
- **`MizuSwitch` toggle** — fixed wrong Reka UI prop/event names. Changed `:checked` → `:model-value` and `@update:checked` → `@update:model-value`; also removed redundant `internalValue` ref. Switch now toggles correctly.
- **`MizuSelect` / `MizuInput` height** — added `box-sizing: border-box` and `line-height: 1` to ensure native `<select>`/`<input>` user-agent styles don't push height beyond the spec'd 28/36/40px.
- **`MizuAvatar` broken image** — improved error detection by adding `handleImageLoad` that checks `img.naturalWidth === 0 || img.naturalHeight === 0` in addition to the existing `@error` handler. Some broken images don't fire `error` but report 0×0 dimensions; the new check catches them and falls through to the initials fallback.
- **`MizuAvatar` "EL" demo** — changed `name="Extra Large"` to `name="Eli Lin"` in both the "Sizes" and "Sizes With Image" sections of `AvatarDemo.vue` (initials "EL", keeps `size="xl"`). Now demonstrates the XL size with realistic 2-character initials.

### Changed

- **Component CSS loaded globally** — `@mizu/vue/style.css` is now imported once via Starlight's `customCss: ["@mizu/vue/style.css"]` config. No more per-demo manual imports; component styles are guaranteed to be on the page in both SSR and client.
- **`@mizu/vue` exports 16 components** (up from 9) — full alphabetized list: `MizuAlert`, `MizuAvatar`, `MizuButton`, `MizuCard`, `MizuCardContent`, `MizuCardDescription`, `MizuCardFooter`, `MizuCardHeader`, `MizuCardImage`, `MizuCardTitle`, `MizuCheckbox`, `MizuDashList`, `MizuDivider`, `MizuInput`, `MizuMetric`, `MizuProgress`, `MizuQuote`, `MizuRadio`, `MizuSelect`, `MizuSwitch`, `MizuTag`, `MizuTextarea`.
- **Sidebar** updated with 7 new component entries (alphabetical): DashList, Divider, Metric, Progress, Quote, Radio, Select, Switch, Textarea.

### Documentation

- 9 new MDX pages following the skill-spec skeleton: `dashlist.mdx`, `divider.mdx`, `metric.mdx`, `progress.mdx`, `quote.mdx`, `radio.mdx`, `select.mdx`, `switch.mdx`, `textarea.mdx` — each with anatomy, variants, color/state maps, token mapping, Vue component API, and implementation notes.
