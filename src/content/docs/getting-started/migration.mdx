## Overview

Mizu v0.16.0 migrates from **Reka UI** to **Nuxt UI v4** as the base component library. Instead of wrapping every UI primitive in a `Mizu*` component, Mizu now acts as a **theme extension layer** — providing design tokens (colors, fonts, spacing, radius) that automatically style Nuxt UI components.

## Quick Start

### 1. Install Nuxt UI

```bash
npm install @nuxt/ui
# or
pnpm add @nuxt/ui
```

### 2. Update Imports

Replace `Mizu*` component imports with their Nuxt UI equivalents:

| Before (v0.15.x) | After (v0.16.x) |
|---|---|
| `<MizuButton>` | `<UButton>` |
| `<MizuCard>` | `<UCard>` |
| `<MizuDialog>` | `<UModal>` |
| `<MizuInput>` | `<UInput>` |
| `<MizuTextarea>` | `<UTextarea>` |
| `<MizuSelect>` | `<USelect>` |
| `<MizuCheckbox>` | `<UCheckbox>` |
| `<MizuSwitch>` | `<USwitch>` |
| `<MizuBadge>` | `<UBadge>` |
| `<MizuAvatar>` | `<UAvatar>` |
| `<MizuAvatarGroup>` | `<UAvatarGroup>` |
| `<MizuTabs>` | `<UTabs>` |
| `<MizuTooltip>` | `<UTooltip>` |
| `<MizuPopover>` | `<UPopover>` |
| `<MizuDropdownMenu>` | `<UDropdownMenu>` |
| `<MizuDrawer>` | `<USlideover>` |
| `<MizuToast>` | `<UToast>` (*see note below) |
| `<MizuProgress>` | `<UProgress>` |
| `<MizuBreadcrumb>` | `<UBreadcrumb>` |
| `<MizuPagination>` | `<UPagination>` |
| `<MizuKbd>` | `<UKbd>` |
| `<MizuCollapsible>` | `<UCollapsible>` |
| `<MizuDivider>` | `<UDivider>` |

### 3. Update Toast Usage

The `useToast` composable has been removed. Use Nuxt UI's auto-imported `useToast`:

```ts
// Before
import { useToast } from "@mizu/vue";
const toast = useToast();
toast.show({ title: "Success", description: "Saved!", variant: "success" });

// After
const toast = useToast();
toast.add({ title: "Success", description: "Saved!", color: "success" });
```

### 4. CSS Import

```ts
// Keep this if you had it
import "@mizu/vue/style.css";
```

This bundles Mizu tokens and the Nuxt UI theme. Your Nuxt UI components will automatically use Mizu colors, fonts, and spacing.

## Components That Stayed

These Mizu components are **still available** — they solve unique UI problems not covered by Nuxt UI:

| Component | Description |
|---|---|
| `MizuAlertDialog` | Custom alert dialog for destructive/critical actions |
| `MizuDashList` | Definition list for label-value pairs |
| `MizuDataTable` | TanStack Table wrapper with sorting, selection, pagination |
| `MizuMetric` | KPI/stat display with color variants |
| `MizuQuote` | Blockquote with default and accent variants |
| `MizuSkeletonTheme` | Skeleton theme engine via provide/inject |

## Composables

| Composable | Status |
|---|---|
| `useForm` | Kept — Zod-based form validation |
| `useToast` | Removed — use Nuxt UI's `useToast` |

## Theme Preset Setup

Mizu provides a theme preset (`@mizu/vue/theme`) that overrides Nuxt UI's component defaults — sizing, spacing, radius, and typography — to match Mizu's design language. Apply it once in your app config:

```ts
// app.config.ts
import { mizuTheme } from "@mizu/vue/theme";

export default defineAppConfig({
  ui: mizuTheme,
});
```

With the theme preset applied, components like `<UButton>`, `<UInput>`, `<UBadge>`, and `<UCard>` automatically use Mizu sizing (SM: 28px, MD: 36px, LG: 40px), radius (6px), and spacing without any wrapper components.

### Components with active theme overrides

| Component | Override |
|---|---|
| Button | Sizing (28/36/40px), padding, icon sizes, gap |
| Badge | Sizing (16/20px), padding, font size, radius |
| Input | Sizing (28/36/40px), padding, gap |
| Card | Border radius (6px), default outline variant |
| Modal | Content border radius (6px) |
| Select | Sizing (28/36/40px), padding, gap |
| Textarea | Sizing (28/36/40px), padding, gap |

### Components using Nuxt UI defaults

These components match the Mizu design scale without overrides:

| Component | Notes |
|---|---|
| Avatar | Sizes 3xs-3xl match Mizu scale |
| Checkbox | Default indicator sizes match Mizu |
| Switch | Default track/thumb dimensions match Mizu |
| Tabs | Pill variant, sizes match button scale |
| Tooltip | Compact dimensions (6px height) |
| Popover | Rounded-md panels match Mizu radius |
| DropdownMenu | Rounded-md, item sizes match Mizu |
| Kbd | Compact sizes (18/22/26px) |
| Progress | Sizes 2xs-2xl match Mizu |
| Breadcrumb | Text-sm, size-5 separator icons |
| Pagination | Inherits from button/input scale |

## Customizing Colors

Mizu maps its design tokens to Nuxt UI's semantic color system. You can further customize via the `app.config.ts`:

```ts
// app.config.ts
import { mizuTheme } from "@mizu/vue/theme";

export default defineAppConfig({
  ui: {
    ...mizuTheme,
    colors: {
      primary: "custom-blue",
      neutral: "custom-gray",
    },
  },
});
```

For full token reference, see the [Tokens overview](/tokens/overview).
