Nagi uses design tokens as the single source of truth for all visual design decisions. Tokens are stored in `tokens.json` using the DTCG (Design Tokens Community Group) format.

## Token Categories

Nagi includes 13 token categories:

| Category | Description | Examples |
|----------|-------------|----------|
| **color** | Brand, surface, foreground, feedback colors | `brand-primary`, `surface-base`, `error-subtle` |
| **fontFamily** | Typeface definitions | `sans`, `mono` |
| **fontSize** | Type scale values | `display`, `h1`, `body`, `caption` |
| **fontWeight** | Font weight values | `regular`, `medium`, `semibold`, `bold` |
| **lineHeight** | Line height scale | `display`, `h1`, `body`, `tight` |
| **letterSpacing** | Tracking values | `tight`, `snug`, `wide` |
| **spacing** | Spatial values | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` |
| **borderRadius** | Corner radius values | `tight`, `default`, `card`, `full` |
| **shadow** | Elevation shadows | `ring`, `whisper` |
| **sizing** | Component dimensions | `icon-inline`, `card-visual` |
| **zIndex** | Stack order values | `nav` |
| **duration** | Animation timing | `fast`, `normal` |
| **breakpoint** | Responsive breakpoints | `sm`, `md`, `lg`, `xl` |

## Using Tokens

### In CSS

```css
.my-component {
  background: var(--color-surface-base);
  color: var(--color-foreground-primary);
  border-radius: var(--radius-default);
  padding: var(--spacing-md);
}
```

### In Tailwind CSS

Nagi tokens are mapped to Tailwind v4 utility classes:

```html
<div class="bg-surface-base text-foreground-primary rounded-default p-md">
  Content
</div>
```

### In JavaScript/TypeScript

```typescript
import { 
  COLOR_BRAND_PRIMARY,
  SPACING_MD,
  RADIUS_DEFAULT 
} from '@nagi/tokens';
```

## Naming Convention

Tokens follow a consistent naming pattern:

| Type | Pattern | Example |
|------|---------|---------|
| Surface colors | `--color-surface-{variant}` | `bg-surface-base` |
| Foreground colors | `--color-foreground-{variant}` | `text-foreground-primary` |
| Brand colors | `--color-brand-{variant}` | `bg-brand-primary` |
| Feedback colors | `--color-{type}-{variant}` | `bg-error-subtle` |
