Mizu uses design tokens as the single source of truth for all visual design decisions. Tokens are stored in `tokens.json` using the DTCG (Design Tokens Community Group) format.

## Token Categories

Mizu includes 14 token categories:

| Category | Description | Examples |
|----------|-------------|----------|
| **color** | Brand, surface, foreground, feedback colors | `brand-primary`, `surface-base`, `error-subtle` |
| **fontFamily** | Typeface definitions | `sans`, `mono`, `serif` |
| **fontSize** | Type scale values | `display`, `h1`, `body`, `caption` |
| **fontWeight** | Font weight values | `regular`, `medium`, `semibold`, `bold` |
| **lineHeight** | Line height scale | `display`, `h1`, `body`, `tight` |
| **letterSpacing** | Tracking values | `tight`, `snug`, `wide` |
| **spacing** | Spatial values | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` |
| **borderRadius** | Corner radius values | `tight`, `default`, `card`, `full` |
| **shadow** | Elevation shadows | `ring`, `whisper` |
| **sizing** | Component dimensions | `icon-inline`, `card-visual` |
| **zIndex** | Stack order values | `nav` |
| **duration** | Animation timing | `fast`, `normal` |
| **ease** | Animation easing curves | `default`, `emphasized`, `entrance` |
| **breakpoint** | Responsive breakpoints | `sm`, `md`, `lg`, `xl` |

## Easing Tokens

Easing tokens define the motion curves used throughout the design system. Each token maps to a CSS `animation-timing-function` or `transition-timing-function` value, providing consistent motion language across components.

| Token | Value | CSS Variable | Usage |
|-------|-------|-------------|-------|
| `ease/default` | `ease-out` | `--ease-default` | Standard decelerated entrance for overlays, dialogs, and panels |
| `ease/exit` | `ease-in` | `--ease-exit` | Accelerated exit for notifications and closing elements |
| `ease/interaction` | `ease-in-out` | `--ease-interaction` | Hover, focus, and form interaction transitions |
| `ease/emphasized` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | `--ease-emphasized` | Expressive spring-like overshoot for accordion and playful entrances |
| `ease/entrance` | `cubic-bezier(0.16, 1, 0.3, 1)` | `--ease-entrance` | Decelerated entrance for popover and tooltip reveals |

### Usage in CSS

```css
.my-element {
  transition: transform 300ms var(--ease-emphasized);
  animation: slideIn 400ms var(--ease-entrance);
}

@keyframes slideIn {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### Usage with Tailwind v4

Easing tokens are available as `@theme` variables in Tailwind:

```css
@theme {
  --ease-default: ease-out;
  --ease-emphasized: cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

```html
<div class="transition-all duration-fast ease-emphasized">
  Content
</div>
```

### Usage in JavaScript/TypeScript

```typescript
import { EASE_EMPHASIZED, EASE_ENTRANCE } from '@mizu/tokens';

// Use in a animation library or inline styles
element.style.animationTimingFunction = EASE_EMPHASIZED;
```

## Using Tokens

### In CSS

```css
.my-component {
  background: var(--color-surface-base);
  color: var(--color-foreground-primary);
  border-radius: var(--radius-default);
  padding: var(--spacing-md);
}
```

### In Tailwind CSS

Mizu tokens are mapped to Tailwind v4 utility classes:

```html
<div class="bg-surface-base text-foreground-primary rounded-default p-md">
  Content
</div>
```

### In JavaScript/TypeScript

```typescript
import { 
  COLOR_BRAND_PRIMARY,
  SPACING_MD,
  RADIUS_DEFAULT 
} from '@mizu/tokens';
```

## Naming Convention

Tokens follow a consistent naming pattern:

| Type | Pattern | Example |
|------|---------|---------|
| Surface colors | `--color-surface-{variant}` | `bg-surface-base` |
| Foreground colors | `--color-foreground-{variant}` | `text-foreground-primary` |
| Brand colors | `--color-brand-{variant}` | `bg-brand-primary` |
| Feedback colors | `--color-{type}-{variant}` | `bg-error-subtle` |
