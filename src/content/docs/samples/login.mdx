This sample page demonstrates a complete login form using Mizu components and the `useForm` composable with Zod validation.

## Features

- **Email validation** - required field with email format check via `z.email()`
- **Password validation** - required field with `z.string().min(8)`
- **Remember me** - optional checkbox
- **Loading state** - submit button shows spinner during simulated API call
- **Error handling** - server-side errors displayed via `MizuAlert`
- **Success state** - success alert shown on valid login

## How It Works

The login form uses:

1. **`z.object()`** - defines the shape and validation rules
2. **`useForm(schema)`** - creates reactive form state with field-level errors
3. **`handleSubmit(fn)`** - wraps the submit handler, only calls `fn` when all fields pass validation
4. **`MizuInput`'s `error` + `helperText` props** - bind validation error messages to the UI
5. **`onBlur()`** - marks field as touched and triggers per-field validation

See [Validation Patterns](/components/forms/validation-patterns/) for the full API reference.
